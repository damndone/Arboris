## What shipped

  - `upload_store.py` — content-addressable uploads at `<project_root>/data/uploads/<sha256>`
    (`store_upload_bytes` / `resolve_upload` / `verify_upload`). Upload lifecycle decoupled
    from run lifecycle; reruns reference the parent upload by sha256 only.
  - `hashing.py` — `canonicalize`, `override_hash`, `dag_hash`, `PIPELINE_VERSION`
    (`"v1.6.0-pipeline-1"`). `dag_hash`/`override_hash` are the future hash-skip cache-key
    contract; **caching is NOT implemented** this slice.
  - `run_inputs.py` — `run_inputs.json` read/write (`run_input_schema_version=1`) + secret
    redaction (`_SECRET_MARKERS` → `***`). Written outside the engine ⇒ golden never drifts.
  - `op_contract.py` — `resolve_operation_contract` (node stage → OperationContract),
    `resolve_overrides_target` (schema-switch order), `validate_overrides` (layer-1
    structural only). Zero per-estimator branches.
- **`engine/capabilities.py`** — per-model `params` + `schema_id` (`"{key}@v1"`) +
  top-level `editable_stages=["model"]`; `schema_version` 2→3. 4-way synced (contract

- **`api.py`** — `_submit_run` shared dispatch helper (create + rerun share ONE path);
  `POST /runs` rewired to store CAS upload + write `run_inputs.json`; new

- **`orchestrator/_manifest.py`** — `rerun_of` added to the manifest payload.

## Key findings / gotchas (for future slices)

1. **`editable_stages = ["model"]` only.** Imputation has no graph node — the graph nodes
   are `stage:raw`, `stage:cleaned`, `var:{name}:cleaned|dropped`, `model:{model_id}`,
   `report:html` (see `engine/stages/recording.py`). Imputation becomes editable only when
   it has its own node.
2. **`effective_model_type` is an engine id, not a capabilities key.** A completed ols run
   records `model_routing.effective_model_type = "ols_robust"`, `effective_model_id =
   "ols_1"`, `requested_model_type = "ols"`. The resolver (`op_contract._model_op_type`)
   therefore prefers `requested_model_type` and falls back to longest-prefix normalization
   of the effective id (`"ols_robust"` → `"ols"`). Locked by regression tests.
3. **Kept the capabilities field named `schema_version`** (NOT `capabilities_schema_version`)
   to avoid breaking the contract test (`additionalProperties:False`) + FE field. Only
   `tests/test_capabilities_v1542.py` pinned it (2→3); other `schema_version: 2` hits belong
   to unrelated schemas (graph_store, artifacts index) and were left untouched.
4. **CSV fixture must be ≥ ~35 rows** to reach the model stage; a 4-row file gets `blocked`
   before estimation (no model node). Terminal-status set for rerun includes `blocked`.
5. **409 vs 429 are distinct guards.** 409 = parent run not terminal; 429 = run slot busy.
6. **Guardrail #7 verified:** serve-layer annotation is response-time only — `graph.json`
   on disk has no `editable*` keys (`test_annotation_not_written_back_to_graph_json`).
