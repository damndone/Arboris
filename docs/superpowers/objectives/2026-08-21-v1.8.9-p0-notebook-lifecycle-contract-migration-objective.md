# Workbench v1.8.9 P0 Notebook Lifecycle Contract Migration

## Objective

Migrate the remaining Notebook lifecycle, freshness, materialization, route,
source, and trace tests to the server-owned compiler/admission contract. A
legacy option must not be executed as if it were materialized; successful
Notebook execution must carry current scope, compiler, confirmation, and host
evidence bindings.

## Scope

- `tests/test_notebook_freshness_gate.py`
- `tests/test_notebook_materialization.py`
- `tests/test_notebook_option_lifecycle.py`
- `tests/test_notebook_routes.py`
- `tests/test_notebook_source_materialization.py`
- `tests/test_notebook_trace_chain.py`

## Acceptance

- Focused tests pass with explicit typed materialization or typed fail-closed
  rejection.
- Freshness, revision, proposal-pin, source materialization, route, and trace
  assertions remain meaningful under the current server contracts.
- No production admission/confirmation gate is weakened.
- Compile, diff check, formal verify, and retrospective pass.
