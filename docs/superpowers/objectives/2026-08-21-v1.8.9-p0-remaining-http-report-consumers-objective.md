# Workbench v1.8.9 P0 Remaining HTTP and Report Consumers

## Objective

Close the remaining HTTP/report consumer tests that still expect unbound
`report.html`, raw model packets, or legacy `table_1`/statistical projections.
Use the current typed evidence and unavailable contracts. If a durable typed
artifact already exists but the HTTP surface is missing a safe projection,
implement that projection through the server-owned boundary; never restore
raw-file authority.

## Scope

- `tests/test_prediction_models.py`
- `tests/test_results_service.py`
- `tests/test_statistical_tests_reachability_v186.py`
- `tests/test_statistics_api_e2e_v186.py`
- `backend/workbench/http/runs_routes.py` (only if a typed projection is
  demonstrably supported by the current contract)

## Acceptance

- Focused tests pass without making raw HTML/model files authoritative.
- Statistical and prediction results are either projected from durable typed
  evidence with identity/status bindings or explicitly `UNAVAILABLE`.
- Invalid legacy packets remain fail-closed without leaking raw payloads.
