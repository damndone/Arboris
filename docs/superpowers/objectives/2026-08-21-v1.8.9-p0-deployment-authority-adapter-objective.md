# v1.8.9 P0 deployment authority adapter objective

Close the application-side production bootstrap gap for the shared
Agent/Notebook compiler. The embedding service must be able to admit a
deployment-owned external host authority handle and install an identity
resolver that validates every Agent/Notebook scope through that handle. A
missing handle, missing principal resolver, dead handle, or mismatched host
claim must fail closed before application state is mutated. The adapter must
not create an in-process authority, infer identity from a request, or accept a
wire-reconstructed binding.

The external authority server and OS supervisor remain deployment-owned. This
slice supplies the typed application adapter and its tests; it does not fake a
provider, supervisor, or browser acceptance.
