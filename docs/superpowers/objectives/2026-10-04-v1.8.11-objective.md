# v1.8.11 — 对标 Stata/SPSS：七族后估计、负二项、ARMA–GARCH 复现、脚本导出

基线：main `75481d7a`（v1.8.10 + devline 发版记录）+ Codex 工单 B 的 8 个提交（`65d771b0..3b43f003`）+ 本文件。
来源：`followups/BACKLOG.md` §0.3、§0.2；交接 `handoffs/2026-10-04-v1.8.11-kickoff.md`；工单 B 报告 `handoffs/2026-10-04-codex-v1811-admission-oracles-report.md`（均在 `docs/superpowers/`）。

## 一句话目标

让 Stata/SPSS 用户日常会用到的东西在 Workbench 里数字一致、能复现、Agent 能做：

- 剩下 7 个模型族登记准入，开放后估计（Wald、LR、lincom、边际效应）；
- 负二项像 Stata `nbreg` 一样估计离散参数 α；
- 用户的 VIX 时间序列报告（ARMA(1,1)–GARCH(1,1)）能在 Workbench 里按原步骤复现，与 Stata 逐项一致；
- 任何一条分析路径可以导出成 Stata do-file / R / Python 脚本，在对应软件里跑出同样的数字；
- Agent 能在一个方案里先拟合再检验，并说清楚为什么换了标准误。

界面重做顺延到下一版（v1.9.0）。

## 硬约束

- **正确性**：统计数字只由确定性代码产生；不适用的方法明确拒绝，不静默降级（含 α 固定为 1、z 当 t 用）。
  每个新数字都有 R 或 Stata 对照；对照比较最终报告的量（统计量、自由度、p），不只比中间量。
- v1.8.10 教训：引擎替换了方差，所有读推断元数据的地方读替换后的；规划器里拒绝的组合，HTTP / CLI / Agent 流水线里也拒绝。
- **声明而非分支**：共享代码不写模型族名字字面量（lint 测试检查）；后估计的开放由准入表推导。
- **自然语言可达**：新选项（NB 离散形式、固定 α、ARMA–GARCH 复现口径、脚本导出）全部登记进能力目录，可达性守卫覆盖。
- **分析诚信**：手动模式的警告不能被 Agent 省略；脚本导出不能产生与 Workbench 不同的数字；看到结果后更换标准误或设定，作为新分析记入台账。
- **性能预算**：

  | 项 | 预算 |
  |---|---|
  | 新族上的 Wald / lincom / LR | 读推断核心，< 0.5 s，不重拟合 |
  | 新族上的边际效应（10 万行） | < 3 s |
  | 负二项 NB2（10 万行、10 个自变量） | < 5 s |
  | 面板聚类标准误（10 万行、1,000 个个体） | < 3 s |
  | ARMA(1,1)–GARCH(1,1) 联合 MLE（N = 2540） | < 10 s |
  | 经典复现口径：509 次滚动重估 + 一步预测 | < 3 min |
  | 脚本导出（50 个节点的血缘，不含快照写盘） | < 1 s |
  | 后端测试总时长 | ≤ v1.8.10 的 1.25 倍（16:07 → 上限 20:09） |

## 确认记录

- 2026-10-04（交接时）：v1.8.11 先对标 Stata/SPSS，界面推后；负二项默认像 `nbreg` 估计 α（NB2），NB1 与固定 α 可选；脚本导出从 v1.9.2 提前；Claude + Codex 并行。
- 2026-10-04（objective 评审）：
  - **A. 面板 / DID 默认按个体聚类**：CR1 + t(G−1)，K 不计被吸收的固定效应（同 `xtreg`）。理由：不聚类的异方差稳健标准误固定 T 下不一致（Stock & Watson 2008）；DID 不聚类时名义 5% 检验实际拒绝率可超 40%（Bertrand, Duflo & Mullainathan 2004）；固定效应嵌套在聚类内不计入 K（Cameron & Miller 2015）；CS、SA、dCDH 本来按个体聚类，改后 DID 家族口径统一。
  - **B. 脚本导出**：覆盖表 + 数据快照接续 + 末尾自检断言，见第 7 步。
  - **C. 准入第 5 项**：本版 7 族 + 准入表里计划在 v1.8.11 补用例的 10 族都补真机 Agent 用例（`deepseek-flash`，先查余额）。
  - 性能预算采用用户版本：联合估计 < 10 s，509 次滚动重估 < 3 min，后端测试总时长 ≤ 1.25 倍。
  - 合并时对照代码修正：没有面板随机效应族；`event_study` 也默认不聚类，一并纳入；聚类数阈值两处并一处。
