### 4.1b v1.6.9 评审新增留痕（2026-07-09）

> 来源：v1.6.9 三级评审（每任务两阶段子代理评审）+ 收尾真机 smoke 过程中确认的新债。

- [ ] **【真机 smoke 抓到,P1】auto-mode run 的 draft 无法保存任何修改**：base run 以
  `model_type=auto` 提交时，from-node draft 的 `params.model_type="auto"`，而
  `editable_schema` 的 model_type options 只含具体家族（无 `auto`）。DraftEditorSection
  Save 时全量回传 params（UI 明知只改了 covariance，"Changed fields" 都标出来了）→ 后端
  `PATCH /pipeline-drafts/{id}` 逐参数校验 → 422 `INVALID_PARAM_OPTION`。**效果 = 从任何
  auto-mode run（旧 Submit 表单/API/CLI 默认）fork 的 draft 完全不可编辑**；Genesis 向导
  显式发 model_type 所以不受影响（这也是它一直没被发现的原因）。v1.6.7 预存，非 v1.6.9
  回归（本版未触此路径）。候选修法（择一，涉 v1.6.4 draft 契约需 spec）：①FE 只回传
  changed fields；②后端 PATCH 对「值未变的参数」跳过 option 校验；③editable_schema
  为继承值补 `auto` 合法项。2026-07-09 真机复现：draft_82b538d59b5f4d0687d326842f0ccb2a。

- [ ] **并发 draft-execute 单槽搁浅**：`pendingRerunRun` 是单槽状态（沿袭 genesis 单例形状）。draft A execute 进入 index-wait（分钟级）期间 `draftBusy` 已复位，再 execute draft B 会覆盖 A 的 pending + focus ref → A 永久卡 "executing"（不移除、不聚焦、后端 draft 不删；无数据丢失，reload 可 rehydrate 后手动 discard）。修法=按 draftId 键控的 pending 集合。Task 7 评审确认，Important 但不阻塞。
- [ ] **forest refetch 卸载整个 shell 子树（loading 闪烁）**：`useForestData.refetch()` 会 `setLoading(true)+setForest(null)`，容器 `if (loading||...) return <Loading/>` → 每次 30s 轮询/pending 轮询都整树 unmount+remount（rail 每次重挂重拉 `/runs`）。这掩盖了 rail 延迟、也是闪烁与浪费；修法=refetch 保留旧 forest（stale-while-revalidate）。Task 9 实现与评审双方独立确认。
- [ ] **`handleRerun`（顶栏 context rerun）focus 4s 残留**：超长 run 下 `pendingFocusTarget` 20×200ms 耗尽后聚焦不落（无 draft 消失、无错数）。与 draft-execute 不同源（无 draft 中心可复用 usePendingRun），spec §7 已记，低优先。
- [ ] **`WorkbenchRouteContainer` Escape/modal 预存 flake**：全量 vitest 偶发（观测 1/10）`S1: Escape with modal open closes only the modal` 红。与 useCapabilities flake 无关，独立根因未查。

> v1.6.9 收尾已清（做完即删）：①6 个测试文件裸 `global.fetch=` 无恢复 → 统一 `vi.stubGlobal` +
> 只还原 fetch（`fe65cad`；注意 `vi.unstubAllGlobals()` 会连带清掉 setup 里一次性装的
> ResizeObserver，故只还原 fetch）。②`did_mode` 值拼写核查 → UI 全对（DID `cohort/two_by_two/status`、
> CS `never/not_yet` 均正确无误），无需改，仅内部 `EstimatedEquationSection` 有个 `modelType.includes("twfe")`
> 的 OR 死分支（无 model_type 含 "twfe"，不给用户看、有家族测试钉着，不值得碰）。
