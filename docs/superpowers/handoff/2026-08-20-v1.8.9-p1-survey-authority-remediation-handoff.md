## Review findings closed

1. Receipt and source factories now require an internal server issuer. A
   caller cannot invoke the metadata-only factory to turn forged artifact,
   digest, and identity values into a validated projection.
2. Run capability issuance now requires the server issuer and a verified
   server-owned artifact manifest. A directory shaped like `runs/<id>` without
   a persisted manifest is rejected before capability creation.
3. The supported OLS/Logit path remains Agent/Notebook-compatible through the
   same central service.
4. Unsupported model families now retain the persisted status, reason, and
   bounded Survey design metadata under `source_status`/`source_reason`, while
   the consumer status is typed `unavailable` with
   `SURVEY_MODEL_FAMILY_UNSUPPORTED`.
5. Malformed JSON discriminator shapes such as list/object `model_type` values
   are rejected into the same typed unavailable path instead of raising a
   Python `TypeError`.
