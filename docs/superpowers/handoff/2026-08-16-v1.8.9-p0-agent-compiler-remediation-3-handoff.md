## Remediation completed in this line

- Scope authority now requires the package's server proof at both resolver
  construction and snapshot bootstrap. A normal caller-created
  `ServerScopeBindingV1` has no issuer token, a binding cannot be rebuilt from
  JSON, and a resolver can issue only its own sealed binding objects.
- The public `PlanCompiler.compile` path requires a server-issued discovery
  selection tied to the current manifest, natural-language allowlist, scope
  binding digest and exact manifest entry. Typed drafts, JSON drafts, forged
  selections, `CompiledWorkflowV1` aliases and legacy compiled objects fail
  closed before compilation.
- The historical `ServerCompilationRecordIssuerV1` remains callable in the
  locked C0 contract, but a workflow or JSON produced by that issuer is
  rejected by the new public compiler. Removing or isolating the old issuer is
  an explicit C0 contract/cutover dependency, not silently marked complete.
- `CompilationStore` admits an existing non-symlink reservation directory by
  FD with `O_NOFOLLOW`, creates exclusive durable reservation markers, and
  retains stable `IDEMPOTENCY_CONFLICT` on an existing marker. The public
  compiler now rejects a pure in-memory store with
  `DURABLE_RESERVATION_REQUIRED`; the host must configure the same admitted
  reservation root for all workers that share an idempotency domain.
- The internal registry QA seam is separated from the public path by a
  non-constructor-settable proof. It is not an Agent/Notebook natural-language
  entry point.

## Direct probe evidence

Red failures were recorded through the formal CLI for:

- caller-created/reconstructed authority;
- typed/JSON draft selection bypass;
- caller-selected discovery scope;
- independent in-process stores reserving the same key;
- proofless authority bootstrap;
- public compile using an in-memory store.

The cross-process probe starts an owner and a contender against the same
durable root and observes exactly one `owner` and one
`IDEMPOTENCY_CONFLICT`. The legacy-issuer probe proves the old C0 issuer can
still create its own object, then proves the new public compiler rejects both
that object and its JSON representation.
