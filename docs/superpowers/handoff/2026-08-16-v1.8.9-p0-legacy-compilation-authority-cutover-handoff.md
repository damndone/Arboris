# Workbench v1.8.9 — P0 Legacy Compilation Authority Cutover

## Status

`PACKAGE_LOCAL_COMPLETED` — formal line verified and retrospective generated.

This handoff is deliberately not a claim that the production host, Agent/
Notebook cutover, provider, browser, full gate or release is complete.

## What changed

- Retired `ServerCompilationRecordIssuerV1` as a security authority. Its
  constructor and every legacy stage (`register_draft`, `compile_workflow`,
  `compile_record`, `issue`) now return the typed
  `HOST_COMPILER_INTEGRATION_REQUIRED` failure.
- Removed the old compilation capability maps, sequence counters, local
  compiler identity registry, and process-local issuer token. The compatibility
  symbol is no longer in `planning.__all__`, so an old import can only reach a
  typed rejection guard.
- Made `CompilationRecordStoreV1` read-only in this C0 line. Local issue,
  server issue, client-reference resolution and server-reference resolution
  all fail closed until a supervisor-backed host store is wired.
- Kept historical `CompilationRecordV1.from_dict()` parsing available as an
  untrusted read path. Parsing a record, a draft reference, a server reference
  or a host receipt never upgrades it into runtime authority.
- Removed the local `_from_server_compiled` mint path and the
  `object.__new__`-based server reference/draft-reference minting path.
- Added the explicit typed integration seam:
  `HostCompilationAuthorityPortV1` and the untrusted carrier
  `HostCompilationReceiptV1`. Receipt wire parsing is supported for a future
  host channel, but the C0 store does not accept the carrier as proof.
- Migrated C0 contract fixtures away from the retired issuer. Admission tests
  use an explicitly named test-only non-authoritative fixture; it is not
  imported or used by production code.

`backend/workbench/agent/plan_compiler.py`,
`backend/workbench/agent/planning_contracts.py` or
`backend/workbench/agent/compilation_store.py`; they remain in the separate

3. update `PlanCompiler` so it no longer constructs or calls the retired
   legacy issuer;
4. remove the legacy issuer from `planning_contracts.py` re-exports/aliases;

remain `NOT VERIFIED`.
