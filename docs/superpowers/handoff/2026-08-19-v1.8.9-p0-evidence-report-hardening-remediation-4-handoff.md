## Outcome

Remediation-4 is GREEN for the package-local Evidence/Report boundary. The
Report view, facts, writer, and render entrances require the exact live C0
server-admitted owner and its identity-bound request object. Missing owners,
caller-selected identity, caller-created request identity, object.__new__ or
serialized projection shapes, forged wires, foreign roots, raw table rows, and
forged owners fail closed before typed facts or filesystem/writer IO.

The index reader now distinguishes absent from present-invalid values and
rejects outer/nested disagreement without truthy fallback. The controlled HTTP
path returns an independent server receipt bound to the projection digest,
complete identity, and canonical provenance. The frontend accepts available
facts only when that receipt matches; a caller-recomputed digest is not a
trust decision. Missing, partial, or tampered provenance is typed unavailable.
Raw classification/artifact JSON remains display-only and NON-CITABLE and is
excluded from selected Report facts and LLM context.
