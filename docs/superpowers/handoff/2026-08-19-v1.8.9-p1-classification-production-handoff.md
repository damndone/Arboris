## 本轮实现

1. Production entrypoint now dispatches the typed task into the classification protocol. The declared IID/group/temporal/panel profile, entity/time columns, availability arrays/columns, label windows, purge and embargo metadata are bound before fitting; no production path forces `iid_stratified`.
2. Group folds are entity-level; temporal and panel folds carry explicit training row refs strictly before validation windows. Holdout, development, entity, time, availability, label-window and embargo violations fail with typed `ContractError` codes.
3. Numeric feature handling no longer coerces unsupported strings. Classification preprocessing is fold-local, supports weighted fit state, and emits receipt/hash data bound to the split hash and fit row refs.
4. Declared weights flow through estimator fit, preprocessing statistics, threshold curves, calibration, OOF metrics, baselines and holdout metrics. Unsupported stages/models fail typed before fitting.
5. Model selection uses development OOF metrics at a fixed evaluation threshold; threshold policy is selected from a disjoint OOF-derived calibration-evaluation slice; Platt and isotonic calibration are real typed fits; final holdout is transformed only after model/policy selection.
6. Holdout release uses the one-time seal guard and a release plan containing task, split, model, calibration and policy identities. No holdout arrays are returned.
7. Producer evidence uses the typed consumer shape: `baselines` is an array, metrics contain explicit OOF/holdout structures, calibration/holdout/release-plan receipts are present, SHAP remains typed unavailable, and unavailable explanations/stability/shift append blockers so the top-level result is `degraded`, never falsely `validated`.
