## 本轮实现

1. Production entrypoint now dispatches the typed task into the classification protocol. The declared IID/group/temporal/panel profile, entity/time columns, availability arrays/columns, label windows, purge and embargo metadata are bound before fitting; no production path forces `iid_stratified`.
2. Group folds are entity-level; temporal and panel folds carry explicit training row refs strictly before validation windows. Holdout, development, entity, time, availability, label-window and embargo violations fail with typed `ContractError` codes.
3. Numeric feature handling no longer coerces unsupported strings. Classification preprocessing is fold-local, supports weighted fit state, and emits receipt/hash data bound to the split hash and fit row refs.
4. Declared weights flow through estimator fit, preprocessing statistics, threshold curves, calibration, OOF metrics, baselines and holdout metrics. Unsupported stages/models fail typed before fitting.
5. Model selection uses development OOF metrics at a fixed evaluation threshold; threshold policy is selected from a disjoint OOF-derived calibration-evaluation slice; Platt and isotonic calibration are real typed fits; final holdout is transformed only after model/policy selection.
6. Production holdout release uses C0 `HoldoutMetricBundleStoreV1.issue`, a complete `HoldoutSealV1`, server-owned `HoldoutSealStoreV1.issue`, and one typed `HoldoutAccessRequestV1` passed to `store.consume`. The result checks `allowed`, reason, closed status and one ledger entry; the helper-only `HoldoutSealGuardV1` remains only on the no-task legacy path.
7. The production entrypoint now requires the factory-created `TrustedExecutorRegistry`, exact contribution/callable/validator identity, and the bound catalog digest. It performs a real registry dispatch preflight through a server-owned `ProviderRuntimeContextV1`; a same-ID/digest fake registry with a malicious executor is rejected before invocation.
8. Strict validation-fold class support and development label-window purge overlap fail closed for every fold. DecisionPolicy consumes an explicit selected threshold, selects `min_log_loss` by log-loss, enforces `max_recall_at_precision`, and returns typed unavailable when no feasible threshold exists; `SCENARIOS_ONLY` never releases holdout or threshold.
9. Ordered no-lookahead metadata is always derived from the task-declared frame availability/origin columns; caller arrays are checked claims and cannot mask an unsafe or mismatched frame. Negative purge/embargo gaps fail before interval overlap arithmetic with typed reasons.
10. Backend C0 projection now requires exact task/split/model/holdout/release-plan refs, explicit envelope/projection/foundation status, exact Agent/Notebook/Report slots, and status monotonicity. Legacy C0 synthesis was removed; degraded/unavailable packets cannot be promoted to validated or coexist with an available projection.
11. `ClassificationEvidence` exports the strict typed packet guard and `ReportWorkspaceContext` consumes the same guard. Malformed C0 envelopes, stale refs, arbitrary records, unsupported schema versions, missing indexed artifacts, and failed downloads remain unavailable. SHAP remains typed unavailable by design.
