## Outcome

The package-local Evidence authority boundary now fails closed when deployment
trust material is absent. Public admission no longer accepts a caller-selected
endpoint path, device/inode, peer uid/pid, scope, session or bootstrap value as
the trust root.

`admit_host_authority_endpoint(...)` and `admit_host_authority_fd(...)` retain
the old keyword shape only to return a typed rejection when a caller supplies
`deployment_config`. With the keyword omitted, admission asks the
deployment-owned `_deployment_config_from_supervisor()` seam for a snapshot.
The default seam raises `EVIDENCE_HOST_AUTHORITY_REQUIRED`; the package does
not generate a fallback configuration, hidden module key, or local authority
server. Only a resolver-provided immutable snapshot reaches endpoint identity
and handshake validation.

This means a caller-created socket, socketpair, self-authored protocol, fake
configuration, wrong endpoint/peer/inode/handshake, or arbitrary FD cannot
reach registry, persistence or projection success. Package-local tests model a
valid external host by patching the resolver seam around an independently
running test Unix peer. That fixture is test plumbing, not production trust
evidence.

## RPC containment

- Every authority request uses a fixed 1.0 second socket timeout and restores
  the prior socket timeout after the request.
- Timeout failures use `EVIDENCE_HOST_AUTHORITY_TIMEOUT`.
- Transport closure/read/write failures use
  `EVIDENCE_HOST_AUTHORITY_UNAVAILABLE`.
- Malformed request objects fail with `EvidenceHostAuthorityError` before I/O.
