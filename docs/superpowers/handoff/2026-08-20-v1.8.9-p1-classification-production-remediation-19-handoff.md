## Remediation

The generic artifact route now strictly parses every present `Range` header
before applying the existing `If-Range` freshness fallback. Empty and malformed
present values therefore remain explicit `400` responses even with stale
`If-Range`; a valid Range with stale `If-Range` still falls back to the existing
complete `200` response. Missing Range continues through the ordinary full
download path and is asserted to have no `Content-Range` header.

The Workbench-owned parser, same-FD bounded streaming, compatibility headers,
cleanup, integrity/TOCTOU checks, and classification contracts are unchanged.
