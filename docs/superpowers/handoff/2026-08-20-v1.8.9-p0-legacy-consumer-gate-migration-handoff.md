## What changed

1. The ARMA-GARCH deliverable test no longer passes a family `Mapping` to
   `render_html_report`, `export_pdf`, or `export_xlsx`. The local test asserts
   that these raw mappings are rejected and no presentation files are created.
   Host-bound typed writer rendering remains a separate acceptance boundary
   because this sandbox cannot create the required Unix host-authority socket.
2. The legacy run-detail test now uses the real HTTP route and central
   prediction projection. It no longer monkeypatches the removed raw
   `runs_routes._model_results` seam.
3. Analysis-loop lifecycle tests use the server-issued route proposal-store
   capability for proposal creation. The old direct confirmation facade is
   explicitly tested as fail-closed; valid confirmation/execution belongs to
   the central Agent/Notebook compiler and is covered by its own v1.8.9 tests.
4. Fifteen pre-cutover golden snapshots now reflect the actual fail-closed
   direct-workflow state: no false `report_html` artifact and an explicit
   `REPORT_RENDER_FAILED` error when no host-issued Report capability is
   installed. Existing model and guardrail evidence is unchanged.
