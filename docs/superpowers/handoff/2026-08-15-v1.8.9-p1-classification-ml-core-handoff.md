## Implemented owned contribution

- Added typed task/class mapping, information-set, label, weight-capability,
  decision-policy, and package-local clarification contracts. Missing target,
  positive class, horizon, availability, primary metric, or cost policy is
  represented as typed clarification; no default is invented.
- Added Logistic Regression and Random Forest adapters behind one registry and
  one fail-closed adapter contract. Parameters, class order, probability
  shape, single-class fit, unsupported input, nonconvergence, and weights are
  explicit receipts/errors; unknown models do not fall back.
- Added IID/group/temporal/panel split receipts. Label-window purge and
  temporal embargo mutate executable assignments to `partition="purged"`,
  retain row refs and explicit purge/embargo basis, rebuild IID folds after
  purge, and fail closed when support or basis is insufficient.
- Added fold-local preprocessing receipts and strict development OOF/model
  selection/final holdout separation. Only the selected development OOF model
  receives the one-time final holdout release; non-selected candidates are
  marked `not_evaluated`.
- Added known-answer metrics with explicit denominator, scope, validation,
  numerical-method, evaluation-design, undefined-reason, calibration-bin,
  threshold, majority-baseline, and negative-control evidence.
- Negative controls preserve the declared exchangeability unit
  `row_within_development_fold`. Label controls use an exact seeded
  value-level derangement that preserves counts. If a fold cannot be
  deranged under the strict support constraint, the control returns typed
  `status="blocked"`, reason
  `CLASSIFICATION_CONTROL_DERANGEMENT_INSUFFICIENT_SUPPORT`, and
  `evidence_level="insufficient"`; no adapter constraint is relaxed and no
  control is forced through.
- Added descriptive permutation explanations, stability/support/shift
  helpers, artifact identity and FD-only admitted persistence, Graph
  selection-vs-holdout operation records, typed evidence projection, schema
  registration, and the additive classification entrypoint.
- Added package-local provider declaration and an unmounted typed
  `ClassificationEvidence` renderer contribution. The renderer is read-only:
  it displays supplied evidence and explicit unavailable/blocked states and
  does not recompute metrics or synthesize zeros.
