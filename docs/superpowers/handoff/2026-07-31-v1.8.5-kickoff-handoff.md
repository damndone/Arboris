## 本轮重点根因修复

此前收集到的多条报错并非需要逐模型枚举修复，而是四类边界未统一：

- **服务器拥有的 envelope 被 provider 猜测。** 现在由当前 Notebook context
  统一绑定 source upload、preconditions、evidence 和 option identity。
- **能力标签与实际模型族可能漂移。** 现在以嵌套 executable `model_type` 绑定
  family contract；旧的 wrapper label 不再决定 model_options policy。
- **族间参数和产物词表被混用。** 现在从注册表投影 Notebook manifest，移除不适用
  的 OLS covariance/branches，并由服务端生成该族的 published expected artifacts。
- **通用 fallback 把注册默认值重复或错误放行。** 现在按已发布 target/family
  过滤、合并和预选；无匹配时仍保持安全的 `no_eligible_memory`，不会把无主默认值
  注入 Agent。

允许模型继续决定的内容只有分析意图、变量、用户可见 rationale 和比较说明；
上述服务器事实不能由自然语言猜测覆盖。
