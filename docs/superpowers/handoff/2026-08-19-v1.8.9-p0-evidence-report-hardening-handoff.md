## Outcome

The round-three blockers are remediated behind the server-owned C0 boundary.
The FastAPI lifespan starts with a deployment-injected
`ServerOwnedReportEvidencePersistenceV1`; when no host capability is injected,
the pre-start state is empty and startup produces only the explicit typed
`UnavailableReportEvidenceCapabilityV1` result. A real TestClient HTTP probe
injects the C0 owner as host state, performs `/runs/{run_id}`, and receives an
available typed projection without calling the legacy configure helper.

`EvidenceProjectionV1`, `ReportEvidenceWriterV1`, and
`ReportDocumentWriterV1` reject direct construction/factory calls. Projection,
document, table writer, commit, envelope digest, identity, receipt, and file
hash are issued or checked through the C0 owner. `render_typed_xlsx`, HTML, and
PDF export accept only the owner-issued typed capability. Report output parents
reject symlinks before the durable write.

The frontend no longer stores figure `preview_json` in Report figure state or
loads time-series JSON for Report facts. `buildFigureFacts`,
`buildPostEstimationFacts`, and `buildTimeSeriesFacts` fail closed; only the
validated bounded `report_evidence` projection supplies citable facts. Raw
family artifacts remain UI-only compatibility data and are never sent through
the Report writer packet.

Historical reporting/export assertions remain active and pass through the
owner-issued typed test seam. The run-stage HTML compatibility surface is
retained by a separate legacy renderer; it is not accepted by the typed Report
writer. Statistical exploration persists its authoritative JSON result but
does not manufacture HTML/PDF/XLSX from an unavailable projection.
