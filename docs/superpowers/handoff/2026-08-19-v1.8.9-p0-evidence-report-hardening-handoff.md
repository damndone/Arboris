## Outcome

The indexed Report boundary is fail closed. An indexed post-estimation
artifact without a canonical committed `EvidenceCommitBindingV1`/`EvidenceEnvelopeV1`
path returns typed `UNAVAILABLE`/`BLOCKED` with no facts;
raw payloads, legacy `model_results`, and recursive scalar extraction cannot
create citable facts.

Report persistence is now owned by the real C0
`EvidencePacketStoreV1` + `EvidenceRegistryV1` + registry-issued
`EvidenceRegistryReceiptV1`. The retired `PersistedEvidenceResultsFacadeV1`
name rejects arbitrary object-with-`load` ports. The owner capability validates
the complete project/session/scope/run/model/artifact/commit/file-hash identity,
registry admission, receipt, packet, binding, content hash and admission ref.
Copied valid binding/envelope pairs under a foreign artifact or project/scope
are rejected by the server-owned registry rather than trusted from index fields.

The `/runs/{run_id}` route no longer reads artifact JSON for Report evidence and
does not use post-estimation results as a fallback. Missing, malformed,
tampered, partial, and rehashed index/payload cases remain HTTP-available only
as typed unavailable/blocked projections. Multi-artifact bundles fail closed
with `UNAVAILABLE` identity/digest and empty facts unless a future owner seam
provides a canonical per-projection binding.

The Report projection now carries validation independently from execution,
availability and completeness. `ReportWorkspaceContext` parses that typed
projection; the real `ReportView` passes it to `FamilyEvidence`, which displays
status, envelope digest, validation, provenance and bounded facts. Legacy
compatibility fields remain explicitly non-authoritative/unavailable and are
not used to build Report facts.
