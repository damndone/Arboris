## What Tasks 0–5 implemented

Task 0 froze the Plan Lock baseline, objective and Work Order, and started formal line `v1-8-9-contract-lock` with the exact affected/allowed/protected scope.

Task 1 added strict `ContractRefV1` and one resolver error model. It requires kind, logical ID, `MAJOR.MINOR` semantic version and lowercase SHA-256 digest; duplicate, unresolved, digest mismatch and incompatible-major references fail closed without coercion or last-write-wins behavior.

Task 2 added orthogonal foundation status axes and the public evidence/persistence contracts. `EvidenceEnvelopeV1` and `NumericFactV1` preserve execution, availability, completeness, numerical method, inference, evaluation design and validation independently. Numeric facts bind their denominator, scale/inference, source and validation identity. Immutable persistence bindings cover artifact admission, projector ref/version, envelope digest, idempotency, supersession/invalidation and failure receipts.

Task 3 added workflow state and port bindings, planning/compiled/compilation/confirmation/failure schemas, the execution-admission receipt choke point, the provider-bound context-egress gateway/receipt, semantic-plan and execution-instance hashes, and the holdout seal/access ledger. Server authority is required for compilation, admission, confirmation, egress materialization and holdout release; client-shaped payloads cannot mint authority.

Task 4 added `AdapterDeclarationV1`, `ProviderContributionV1` and the deterministic repository-local builtin catalog. Catalog discovery reads only `backend/workbench/providers/builtin/*.json`, normalizes and sorts filenames/provider identities, rejects duplicate/unresolved/versionless/path-like/digest-invalid declarations, and treats executor IDs as opaque. It produces manifest/path/descriptor inputs only and does not import or execute feature code.

Task 5 added the canonical producer/consumer compatibility matrix, legacy/unknown-major/corrupt/blocked/not-applicable packets, adversarial provider injection and property-like declaration variants. It also hardened ordinary namespace, instance-field and tuple-index mutation surfaces for contract/catalog projections. The current live operation identity set is asserted unchanged before and after catalog discovery.
