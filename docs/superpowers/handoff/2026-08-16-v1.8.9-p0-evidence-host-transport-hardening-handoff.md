# Workbench v1.8.9 — Evidence Host Transport Hardening Handoff

## Status

`PACKAGE_LOCAL_COMPLETED / PRODUCTION_NOT_READY`

This line closes the package-local transport hardening boundary. It does not
claim that the real deployment supervisor, Workbench startup lifecycle or
release integration is ready.

## What changed

- The inherited supervisor control descriptor is duplicated with explicit
  ownership tracking, made non-inheritable, and closed on wrapping and fixed-FD
  failure paths.
- All received `SCM_RIGHTS` descriptors remain tracked until the complete
  bounded control frame is validated; unsupported ancillary data, malformed
  rights, truncation, extra FDs, parse errors, timeout and admission failures
  close every received descriptor.
- Control `SOCK_STREAM` input is accumulated across bounded reads, accepts a
  fragmented single frame, and rejects extra bytes after the first frame.
- The received endpoint descriptor and admitted authority channel are made
  non-inheritable before the handle is returned.
- `admit_host_authority_fd` now closes its duplicate if descriptor wrapping or
  admission fails.
- Authority RPC response framing rejects newline tails instead of silently
  discarding extra frames.
- Control transport timeout and unavailable paths use the existing typed
  `EVIDENCE_HOST_AUTHORITY_TIMEOUT` and
  `EVIDENCE_HOST_AUTHORITY_UNAVAILABLE` codes.
