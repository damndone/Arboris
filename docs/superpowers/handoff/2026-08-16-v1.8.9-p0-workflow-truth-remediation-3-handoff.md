## 本轮实现

### 1. Admission snapshot 与 TOCTOU

- `WorkflowExecutor` 只接受精确的 server receipt-gated callback；普通 callback 在创建 workflow state 前拒绝。
- admission 后、callback 进入前重新校验完整执行快照：workflow id/template、target、scope、preconditions、bindings、完整 plan、plan fingerprint、step body、step contract fingerprint 和 receipt authority。
- 任一快照变更在 callback 之前以 `WORKFLOW_ADMISSION_MISMATCH` 拒绝，callback 不被调用，也不写 artifact/evidence。

### 2. Evidence completion gate

- completion 重新读取当前 project registry，而不是相信 callback 返回的 artifact id。
- 每个 artifact 必须证明：当前 project/run 所有权、唯一 registry 记录、相对路径、无 traversal/symlink escape、文件存在、文件 digest 与 registry 一致、binding digest 一致（如有）、step/canonical producer contract 一致。
- expected artifacts 缺失、未注册 artifact、路径逃逸、symlink、内容篡改都会 fail closed。
- 统计探索、derive boolean/numeric 等既有 canonical registry step 名称通过显式 alias map 接入；没有 wildcard 放行。

### 3. Model branch 与 legacy boundary

- `model_run_id` 只接受项目内 opaque reference；拒绝 `..`、绝对路径和 symlink run。
- model branch source artifact 重新打开并计算实际文件 SHA-256，同时校验 registry digest 和 branch digest；不再把 artifacts index 中的 digest 当作事实。
- model artifact 也校验相对路径、symlink、存在性和 registry digest。
- `_execute_model_auto`、Genesis family workflow 和 `_execute_ols_branches` 统一接收 admitted receipt/evidence port；无 receipt 的 legacy helper 在任何写入前以 `WORKFLOW_ADMISSION_RECEIPT_REQUIRED` 失败。
- 未加入 OLS fallback；model family 仍由已注册 family contract 选择和执行。

### 4. Worker/restart 与 evidence path lock

- receipt/completion 的 process-owned authority 在新 worker/restart 中没有持久 proof 时明确以 `WORKFLOW_RESTART_AUTHORITY_REQUIRED` fail closed。
- workflow evidence transaction 改为锁 workflow directory inode；evidence append 使用目录锁下的 `O_APPEND|O_NOFOLLOW`，不依赖可被替换的 sibling pathname lock，并 fsync 文件和目录。
