## Outcome

Evidence no longer accepts a raw Unix socket, anonymous socketpair, caller-
shaped Python object, or self-described issue/validate protocol as host
authority. A raw channel must first be admitted through a deployment-owned
endpoint configuration or a supervisor-passed FD paired with that configuration.
The configuration binds the pathname, socket inode/device, peer uid/pid,
scope, session, purpose prefix, and an externally supplied bootstrap secret.

The endpoint admission performs:

- pathname Unix stream validation; anonymous and abstract sockets are rejected;
- peer uid/pid verification using the platform Unix peer-credential APIs;
- deployment-owned parent-directory and socket-owner checks;
- endpoint pathname inode/device verification and re-verification on every use;
- a host-only challenge/response attestation before issuing a process-local
  endpoint capability;
- owner-PID, exact-object, channel identity, immutable config snapshot and
  session checks on every authority request;
- explicit rejection of copy, deepcopy, pickle, JSON serialization,
  `object.__new__` field copies and forked endpoint reuse.

Evidence does not start an authority server and does not generate the
deployment handshake secret. The test host is an external test fixture only.
