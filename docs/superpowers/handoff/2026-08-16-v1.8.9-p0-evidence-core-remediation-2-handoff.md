## Implemented controls

- `EvidencePacketStoreV1.commit` now takes a POSIX `flock` on a server-admitted
  FD-backed lock file before packet, commit, and index mutation. The lock is
  cross-instance and cross-process; the instance-local `RLock` remains only an
  in-process guard.
- Commit bindings are derived by one deterministic `_binding_for` function from
  the immutable artifact admission. `load` recomputes that binding, so changing
  both packet and commit binding files with a valid new request digest is
  rejected instead of being accepted merely because the two files agree.
- ContractRef `kind`/`logical_id`, validator identities, and nested structured
  provenance references use the closed opaque-ref grammar. Only exact
  `ContractRefV1` or C0 `NotApplicableV1` reference objects are accepted;
  relative names, URLs, slash paths, and arbitrary reference dictionaries are
  rejected before admission.
- `EvidenceProjectionViewV1` and `EvidenceProjectionOutcomeV1` require private
  projector-owned construction proofs. The view receipt binds the complete
  normalized payload, and nested mappings/sequences remain recursively frozen.
  Public construction cannot claim `success`/`available` or replace bound data.
- `EvidencePersistenceAdmissionV1` now requires a private server-factory token;
  passing an arbitrary directory FD to the public constructor is rejected.
