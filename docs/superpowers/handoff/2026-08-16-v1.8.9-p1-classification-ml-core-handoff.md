## Implemented package-local capability

The lane now contains one typed, model-agnostic classification protocol backed
by Logistic Regression and Random Forest adapters. It includes:

- explicit class mapping, positive class, feature availability, label and
  DecisionPolicy contracts;
- IID, grouped, temporal, and panel split manifests with information-set,
  purge/embargo, entity and period checks;
- fold-local preprocessing and weighted-stage admission;
- development-only OOF model comparison, paired row/fold prediction refs,
  bounded candidate count, tie freeze and honest cooperative resource receipt;
- known-answer metric evidence with definitions, denominators, weight/effective
  sample size, scope, design, numerical method, inference basis and validation
  level;
- nested Platt/isotonic calibration and OOF-only threshold selection;
- majority/prevalence baselines, negative controls, deterministic permutation
  explanations and bounded multi-seed RF sensitivity evidence;
- immutable, exact, one-shot holdout release plans. Predeclared subgroup and
  shift diagnostics carry their plan body, columns, support threshold, bins,
  statistics and descriptive-only multiplicity policy;
- hash-verified, idempotent, lock-admitted evidence persistence and Graph
  lineage, plus fail-closed packet projection for Agent/Notebook/Report/Table/
  Compare consumers;
- package-local provider declarations for fit, compare, explain and decision,
  and an unmounted typed `ClassificationEvidence` renderer contribution.
