## Delivered

1. Classification artifacts are consumed through one central server-owned wrapper and one opaque source snapshot. Agent and Notebook path inputs no longer mint local authority; they require a server-issued run capability.
2. The projection adapter joins provider, path, and consumer catalog bindings and rejects value-equivalent catalog clones. Registry binding digests are canonicalized before comparison, so loader order cannot change authority decisions.
3. Persisted classification receipts now carry an exact source contract. The source snapshot can only be issued after receipt authorization, artifact/hash/identity validation, and source-contract validation. Direct raw mappings cannot be passed to the adapter.
4. Projection policy is explicit for unavailable evidence, prediction budget, sensitivity, execution order, artifact hash, and lineage. Unknown, damaged, missing, or foreign evidence fails closed with a typed unavailable result.
5. Report uses a closed renderer registry and server identity-bound evidence. Raw artifact JSON and bare fallback payloads are not rendered. HTTP unavailable responses retain the bound server identity.
6. Notebook evidence records freeze nested values and return detached wire copies, preventing post-issuance mutation from changing evidence identity.
