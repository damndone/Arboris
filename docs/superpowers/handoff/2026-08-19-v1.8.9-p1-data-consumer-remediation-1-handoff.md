## Findings closed

### P1-A — verified optional dependency admission

`data_interchange.py` now separates module presence from executable admission:

- `_verified_import` exercises both `importlib.import_module` and the normal import hook.
- pyarrow admission performs an in-memory table/write/read adapter probe; pyreadstat admission checks the required reader/writer callables.
- Capability discovery, writer, reader, read-back, and manifest/native admission return typed `unavailable` / `optional_dependency` outcomes. Broken imports do not fall through to a bare `ModuleNotFoundError` or a silent alternate engine.

### P1-B — bounded Parquet engine parity

`data_operations._read_frame` first uses the shared verified `_parquet_engine` admission and passes the admitted engine to `pandas.read_parquet`. Bounded ingestion uses the same verified adapter boundary. When admission returns `None`, pandas is not called and the result is typed unavailable.

### P1-C — pre-write containment and raw snapshot failure behavior

Before any raw snapshot write, ingestion checks run-root/raw-snapshot containment, symlink/non-regular hazards, target absence, and run/raw/source identities. Copy uses no-follow descriptors, `O_EXCL`, and identity checks.

The quality-review probes now explicitly cover:

- copy failure after one byte: the owned partial target is removed and the artifact index remains empty;
- registration failure before an index record: the unregistered target is removed and the artifact index remains empty;
- an exception after registration has already written the index: the target is retained because it is registered, avoiding a dangling registered artifact;
- source mutation after copy starts: the target is removed and a typed `source_identity` error is raised because the sampled source fingerprint changed.

The source fingerprint is `(st_dev, st_ino, st_size, st_mtime_ns, st_ctime_ns)` and is checked both before and after the copy.

This is deliberately **not** claimed as full atomic ingestion. `copy + register_artifact` is not one crash-atomic transaction. A process crash between target/index commits, a concurrent replacement/race outside the tested identity checks, cleanup failure, source mutation after the post-copy check but before registration, and a same-size mutation that preserves or restores every sampled stat field remain **NOT VERIFIED / known limits**. The implementation only removes a target when the run/raw directory and target identity still prove that it owns the file; it does not delete a replacement or symlink merely because the pathname matches.

### P2-D — deep server-owned metadata

`MetadataRegistryV1` recursively freezes mappings and sequences, owns the caller-provided nested values, and returns recursively thawed compatibility projections for serialization. Caller mutation, internal mutation, and mutation of a serialized projection no longer alter server-owned metadata. Existing JSON-compatible serialization remains supported.

### P2-E — malformed metadata truth

Non-Mapping top-level/column metadata is rejected with typed `InterchangeMetadataError` (`invalid_metadata` or `metadata_loss`). It is not silently filtered and cannot be reported as loss-free verified interchange.

### P2-F — round-trip status truth

Round-trip status now considers value equality, column schema, dtype equality, and metadata-loss evidence. Value-equal but dtype/schema-different frames report `schema_mismatch`; declared metadata loss reports `metadata_loss`; unavailable adapters report `unavailable`; only the complete agreement path reports `verified`.
