## Implemented

- Logit, Probit, and Poisson estimation handlers now invoke the existing shared survey adapter and `estimate_with_design` for both linearization/Taylor and replicate-weight workflows.
- Probit is linked as `Binomial(Probit)` rather than silently using the Logit link. Poisson exposure is carried through the same weighted refit/influence path.
- Survey point estimates, coefficient standard errors, confidence intervals, p-values, `variance_source`, design df, DEFF/ESS, lonely-PSU policy, subpopulation, and replicate attempt/success/failure metadata are retained in the model result.
- Survey adapter estimates replace runner-native naive estimates in the result payload; unsupported survey links, invalid exposure, replicate failure rate, incomplete design, and active FPC declarations fail closed with typed survey errors.
- The historical auto count registry key `poisson_rate` now canonicalizes to the single `poisson` family contract for weight validation, model-family validation, composition checks, and the shared survey adapter. It remains an internal alias and is not advertised as a second capability.
- Capability projection publishes only contract families with a live shared survey adapter path. OLS continues to use the same adapter/variance semantics.
- A clean-process capability probe now returns typed `CAPABILITY_BOOTSTRAP_IMPORT_CYCLE` with an empty survey family list when the pre-existing StatisticalTestsStage/orchestrator cycle prevents builtin-pack bootstrap; it cannot falsely advertise survey support. The underlying central cycle remains outside this survey-owned line.
- FPC remains unavailable in this phase. An active sampling-weight workflow with `survey_fpc_col` returns `SURVEY_FPC_UNSUPPORTED`; it is not silently accepted.
