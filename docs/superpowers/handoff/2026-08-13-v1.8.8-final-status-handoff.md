## P7 execution and product acceptance

- Every registered P7 operation is wired through the generic workflow and
  Agent vocabulary. Automated batch execution covered all 64 operations: 63
  completed and `glm.hurdle_negative_binomial` produced the explicitly expected
  fail-closed `GLM_NONCONVERGENCE` outcome for the frozen fixture.
- The automated batch proves registry coverage, typed admission, execution,
  persistence, and fail-closed behavior. It is not 64 manual browser sessions.
- Report, Notebook, `operation.multi_step`, rejection, and selected high-risk
  browser paths are separate visible browser acceptance evidence. They do not
  prove human identity or resistance to an Agent impersonating a user.
- No concrete remote witness provider is installed. The provider-neutral
  witness core remains fail closed; external identity attestation is deferred
  until a networked product and threat model are selected.

## Statistical truth corrections

- Matching uses `standardized_covariate_euclidean_v1` as its primary matching
  geometry. Absolute logit difference is support evidence and the secondary
  deterministic tie-breaker. The support rule rejects disjoint support and
  does not trim; results publish `trim_applied=false`.
- Hurdle positive-count standard errors are
  `bfgs_inverse_hessian_approximation`; p-values use a normal Wald
  approximation and publish `p_value_status="approximate"`. The label is
  preserved in bounded Agent and Report evidence.
- Independent base R oracles cover the corrected Matching geometry and Hurdle
  positive-count estimates/inverse-Hessian inference.

## QA ledger policy

Only ledgers created with the current write-once `.control.json` authority are
accepted. The development-only legacy migration command and compatibility
implementation were removed. An uncontrolled ledger remains rejected; Git
history is the reference for the deleted prototype.

## Deferred, not missing wiring

- Concrete remote/human-identity witness provider and adversarial prompt-
  injection identity testing: deferred to the networked-product security phase.
- Refactoring family branches in `p7_pack_adapters.py` into handler maps:
  low-priority maintainability work. Current branches are internal to the P7
  adapter boundary and are not orchestrator dispatch leakage.

## Verification boundary

Focused backend/frontend tests, formal devline verification, and the supported
host full gate are distinct evidence. The final source commit must record each
result separately; no focused or sandbox-only result substitutes for the host
full gate.
