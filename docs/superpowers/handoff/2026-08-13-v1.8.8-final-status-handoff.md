## Statistical truth corrections

- Matching uses `standardized_covariate_euclidean_v1` as its primary matching
  geometry. Absolute logit difference is support evidence and the secondary
  deterministic tie-breaker. The support rule rejects disjoint support and
  does not trim; results publish `trim_applied=false`.
- Hurdle positive-count standard errors are
  `bfgs_inverse_hessian_approximation`; p-values use a normal Wald
  approximation and publish `p_value_status="approximate"`. The label is
  preserved in bounded Agent and Report evidence.
- Independent base R oracles cover the corrected Matching geometry and Hurdle
  positive-count estimates/inverse-Hessian inference.

## QA ledger policy

Only ledgers created with the current write-once `.control.json` authority are
accepted. The development-only legacy migration command, `LegacyLedgerMigration`
implementation, `.legacy-migration.json` sidecar, and migration-only tests were
removed earlier in `02904c0`. The current planner-quality commit did not remove
them again; it preserves the already-correct policy. An uncontrolled ledger
remains rejected; Git history is the reference for the deleted prototype.

## Workflow validation/API cleanup already present

- The earlier duplicate workflow-capability validation was removed. The
  `execute_with_context` path performs one request normalization and one result
  validation before persistence; the runtime delegates to that boundary.
- `WorkflowCapabilityOperation` no longer accepts three callable hook fields
  that `__post_init__` would overwrite. Its named methods remain intentional
  thin adapter methods; the misleading constructor injection API is gone.
- These two corrections predate the planner-quality commit and are part of the
  current final tree. The P7 pack branch has its own preflight/execute/result
  contract and is a separate adapter path, not the removed duplicate.
