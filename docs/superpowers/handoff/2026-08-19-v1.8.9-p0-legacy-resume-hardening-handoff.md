## Delivered

- Historical Agent proposal confirmation no longer instantiates the legacy
  `WorkbenchOrchestrator`. It requires a server-owned
  `AgentNotebookCompilerV1` compilation record, scope match, retained server
  confirmation, and typed execution result; absent or mismatched handles fail
  closed while preserving the legacy response envelope.
- Historical Notebook composed-workflow confirmation paths reject the old
  `compile_workflow`/`execute_workflow` authority with the typed
  `NOTEBOOK_LEGACY_COMPILATION_REQUIRED` response. The service boundary has
  the same fail-closed guard for direct callers.
- Resume now rebinds every persisted completed step to its sealed server
  completion, unique admission, persisted artifact admission, and frozen
  server artifact registry before dependency callbacks or new writes. Persisted
  artifact IDs, output bindings, lineage, and row counts must match.
- Persisted model branches are checked against the current compiled model step
  declaration for family, outcome, predictors, and covariance.
