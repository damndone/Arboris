## 已实现

- metadata profile：variable/value labels、measurement role、user-defined missing values、weight、split/group declarations，均有 canonical typed validation；profile 保持 observed/declared/inferred 分离。
- filter：继续使用有 depth/node/list 上限的闭合 AST；user-defined missing values 会参与 `is_missing`、`not_missing` 和值谓词，未引入表达式执行。
- data operations：`data.sort`、`data.split`、`data.recode` 走真实 bounded executor；sort stable、split 返回 group count、batch recode 返回 changed value count。
- metadata mutation：preview fingerprint → server proposal confirmation → deterministic immutable metadata artifact + operation record → graph child/edge → hash-checked reload。重复 confirm 复用同一记录，源 artifact 变化会返回 stale。
- manifest/HTTP/editor：新 operation descriptor 与真实 preview/confirm route 对齐；前端从 request schema 生成 controls；unavailable descriptor 不会生成 executable selector。
- interchange：CSV/XLSX/Parquet 均执行真实 write/read round-trip，并返回 metadata-loss manifest；没有 `pyreadstat` 时 .sav/.zsav/.dta 只返回 `optional_dependency` typed unavailable。
- ingestion：Parquet bounded reader 使用 `pyarrow` batch，不把整表读入后才截断。
