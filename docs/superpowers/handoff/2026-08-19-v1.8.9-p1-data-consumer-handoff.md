## 已实现

- DatasetRef/schema_revision/metadata_revision 从 server-owned `workbench.data-metadata` artifact 读取真实 revision；metadata preview/confirm 生成 immutable metadata artifact，profile route 通过 hash-checked registry reload，源 artifact 或 revision 变化会 fail closed/stale。
- metadata registry/profile 保存 variable labels、value labels、measurement role、user-defined missing values、weight、split/group declarations，并保持 observed/declared/inferred 分离。
- filter 继续使用有 depth/node/list 上限的闭合 AST；`is_missing`、`not_missing` 与值谓词自动消费已确认 registry 的 user-defined missing map；缺失或未确认 metadata typed unavailable/fail closed。
- `data.sort`、`data.split`、`data.recode` 与 `data.aggregate` 走真实 bounded executor。split/group 生成 bounded group child CSV、group manifest、group counts、Graph child/edge/index lineage；child identity 和输出随 group 变化。weight 只在已支持的 weighted mean aggregate 中实际参与计算并写入 method/evidence；其他 weighted function 明确拒绝，不静默忽略。
- transform child 写入并绑定 labels、value labels、user missing、weight、split/group metadata 与 provenance sidecar；profile 可从 child reload。metadata-loss 只记录不可表达字段，不丢失可保留字段。
- metadata mutation 使用 preview fingerprint → server proposal confirmation → deterministic immutable artifact + package OperationRecord/evidence ports → graph child/edge → reload；重复 confirm 复用同一记录。
- package-owned data-consumer runtime adapter 真实 join live provider catalog、manifest declaration、executor 与 `data.agent`/`data.notebook`/`data.report` consumer slots；direct operation response 进入 OperationRecord 的 derived/operation_record/evidence ports。central Agent/evidence、sectionRegistry、Notebook/Report central mount 未越权修改。
- manifest/HTTP/editor 的 advertised descriptors 与真实 preview/confirm route、runtime adapter 和 typed output ports 对齐；unavailable descriptor 不生成 executable selector，前端 controls 从 request schema 生成。
- CSV/XLSX/Parquet 执行真实 write/read round-trip 并返回 metadata-loss manifest；当前环境没有 `pyreadstat`，所以 `.sav/.zsav/.dta` 保持 `optional_dependency` typed unavailable，没有假 reader/writer。
- remote data context 默认不发送 raw rows 或 restricted columns；本线没有放宽既有 egress boundary。

## 边界

- `.sav/.zsav/.dta` 的本地 optional dependency `pyreadstat` 当前不可用，因此三者仍 typed unavailable；不声称 native interchange。
- central sectionRegistry mount、central route、central Agent/evidence integration、Notebook/Report central cutover、browser-visible acceptance、full provider gate、release/merge/tag 均保持 `NOT VERIFIED`；本线只交付 package-owned integration seam 和真实 OperationRecord/evidence projection。
- 当前支持的 weighted operation 仅为 `data.aggregate` 的 weighted mean；未支持的 weighted operation 返回 typed rejection/unavailable。
- split/group 有界为最多 128 个 group；超限或无法表达的形态 typed unavailable，并保留 metadata-loss/provenance 说明。
