## Implemented slice

The slice is port-based and consumes only a committed `EvidenceCommitBindingV1`
plus an injected persisted `EvidenceEnvelopeV1`. It rejects client-supplied
facts, checks commit state and envelope digest, and does not recalculate any
statistical result.

- `backend/workbench/evidence/consumer_adapters.py`
  - Adds immutable `PersistedEvidenceEnvelopeV1`, `ConsumerProjectionSpecV1`,
    `ConsumerProjectionRegistryV1`, `EvidenceProjectionV1`, and audit records.
  - Preserves the envelope's persisted fact order and exact `fact_id`/value
    identity. Budget truncation walks that same order; it does not sort or
    recompute.
  - Emits `unavailable`, `degraded`, and `blocked` states with omitted and
    redacted fact IDs; remote projection requires a server egress receipt.
- `backend/workbench/evidence/coverage.py`
  - Derives raw-key rows from provider exposure paths and declared projection
    refs. Missing or mismatched projections become `blocked` rows instead of
    disappearing; no expected-count constant is introduced.
- `backend/workbench/services/results_service.py`
  - Adds `PersistedEvidenceResultsFacadeV1` over injected persistence/envelope
    ports.
- `backend/workbench/agent/context_tools.py`
  - Adds a bounded Agent contribution that delegates to the shared registry.
- `backend/workbench/agent/notebook/evidence.py`
  - Adds a bounded Notebook contribution over the same persisted projection.
- `backend/workbench/report_view_model.py`
  - Adds a typed report view builder that copies persisted fact fields and
    preserves unavailable statuses.
- `backend/workbench/providers/builtin/consumer_projection.json`
  - Declares results, Agent, Notebook, report, and UI projection refs plus
    adapter/renderer/policy refs through the package-local provider catalog.
- `frontend/src/report/reportEvidence.ts`
  - Preserves the existing report evidence grouping/capability exports and
    adds typed persisted projection parsing.
- `frontend/src/report/FamilyEvidence.tsx`
  - Adds an explicit typed contribution prop. It renders status labels and
    `UNAVAILABLE` rather than fabricating missing values; `ReportView.tsx` and
    the section mount remain untouched.
- `frontend/src/notebook/evidenceContracts.ts`
  - Adds a typed Notebook envelope copy boundary with no calculation.
- Tests:
  - `tests/test_v189_consumer_projection.py`
  - `tests/test_v189_consumer_coverage.py`
  - `frontend/src/report/FamilyEvidence.test.tsx`
