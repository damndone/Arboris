## Delivered behavior

- Model-producing workflow steps publish one canonical typed
  `output_bindings["model_branches"]` binding.
- Each branch carries server-bound run, artifact, evidence and source refs,
  family identity, workflow identity and a branch execution key.
- Completion rejects live legacy-only branch aliases, forged branch semantics,
  evidence refs, source digests and source refs that do not match the admitted
  target before writing a completion record.
- Resume reads the canonical binding first. The lineage-only legacy shape is
  accepted only through the explicit persisted compatibility path and is never
  converted to an empty branch map.
- Genesis child-run reuse requires the exact workflow, source, family,
  covariance and plan identity; the branch execution key prevents duplicate
  child runs after an interrupted parent completion.
- `model.auto` now has two closed variants under one public operation id:
  selector (`branches`) and generic capability
  (`input_mode`/`column_bindings`/`options`). Mixed or partial shapes fail
  closed and dispatch through the matching trusted adapter.
- Source and model artifact authority checks use a no-follow directory-FD walk.
  Digest and JSON parsing for a model artifact use bytes read from the same FD;
  platforms without no-follow support fail closed.
