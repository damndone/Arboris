## Implemented controls

- `load` and `load_packet` require the owning `EvidenceRegistryV1` and its
  registry-issued receipt. The persisted packet must exactly equal the record
  resolved from that registry; missing receipt, a forged receipt, an unrelated
  registry, and a self-consistent persisted file set without trusted admission
  fail closed.
- Registry receipts remain process-local capabilities. They are not pickleable,
  and a new worker without a server-rehydrated proof cannot load persisted
  evidence. Cross-process acceptance is intentionally not claimed.
- Evidence index serialization now locks a duplicated FD for the admitted root
  directory inode. Replacing `.evidence-index.lock` cannot create a second lock
  domain.
- `oracle_checks.reference`, `*_reference`, `references`, and the existing
  nested `*_ref`/`*_refs` fields use the same closed opaque-reference grammar.
  Local paths, URLs, slash/backslash values, filenames, and path-like
  `ContractRefV1` identities are rejected before admission.
- Commit writes record which packet/commit files were newly created. If index
  admission fails, newly created files are removed; if compensation itself
  fails, the operation returns a write-failure quarantine error and the index
  remains the consumer-visible authority.
