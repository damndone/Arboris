## Outcome

Remediation-7 closes the independent P1-D integration gap from remediation-6.
The real `_run_workflow` context boundary now consumes only the application
state's exact server-owned Report capability, verifies its canonical run-root
binding, issues the opaque server projection, and places the exact owner and
projection pair in `ctx.artifacts` before the traced stage pipeline. No
caller-shaped fallback is synthesized when the capability is absent, stale, or
bound to another run.

ARMA-GARCH raw deliverable builder/read path. Missing admission reaches the
existing typed unavailable Report view and never calls
`build_arma_garch_deliverables`; a valid owner-issued pair preserves the native
ARMA builder and renderer path.
