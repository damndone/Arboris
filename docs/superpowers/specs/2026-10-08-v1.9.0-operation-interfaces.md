# v1.9.0 请 v1.8.13 线提供的接口（草案）

> 出处：`objectives/2026-10-08-v1.9.0-objective.md`。以 v1.8.13 线的合同提交为准；按并行规则单独提交、重新生成类型、过漂移测试、记入两条线的 devline。

1. **操作目录** `GET /operations`：列出全部工作流步骤操作（与 Agent、命令行同源），每项给出 `operation_id`、类别、显示名、一句话说明、
   参数声明（字段名、类型 / 控件种类、是否必填、默认值、取值范围、枚举项、列选择的约束）、适用条件（需要数据集还是模型，需要哪些
   模型性质）。可选 `?target=` 参数：返回对该目标逐项的可用 / 不可用及原因。
2. **直接执行** `POST /operations/run`：输入目标（运行、节点或数据集）与一个或多个步骤（`operation_id` + 参数），经与命令行
   `run_postestimation` 相同的 `compile_workflow` + `WorkflowExecutor` 执行，不调用模型；记入分析台账（来源 = 界面）；返回步骤状态、
   产物引用与新节点。只读操作直接执行；改动数据的操作沿用现有预览 / 确认两段式。
3. **报告手写保存**：允许保存不来自模型的报告记录（作者 = 用户，起点 = 计算得出的草稿），沿用现有报告历史与导出；
   可以是放宽 `POST /runs/{id}/ai-reports` 的来源约束，或新增等价接口。
