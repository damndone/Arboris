# v1.8.2 objective: Raw-node statistical exploration

Deliver the complete Class 3 Stata teaching workflow in v1.8.2 as several
internally sequenced slices. Reuse the existing OLS/model execution capability,
and add the remaining first-class Workbench capabilities: pre-model filters and
descriptive statistics, missingness and detailed percentiles, typed percentile-
based derived indicators, scatter plots, OLS confidence-interval presentation,
residual/fitted-value diagnostics, and reproducible log/report/PDF export.

All actions must be evidence-backed and visible in Graph. Raw data remains an
immutable fact source; derived variables are typed transform nodes; model runs
remain immutable; plots and reports retain their source, scope and parameters.
Users must not need to write Python for the workflow.

The v1.8.1 release line, tag, and published worktree are protected. This line
starts from the merged v1.8.1 baseline `418b040b` and must not modify or retag
v1.8.1.
