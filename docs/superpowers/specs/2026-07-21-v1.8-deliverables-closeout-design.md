# v1.8 Deliverables Closeout Design

## Decision

v1.8 must ship one truthful, inspectable delivery path for each completed run.
The existing generic run summary remains a deterministic fallback, but it must
not be labelled or linked as the user-facing ARMA-GARCH report.  The generated
DeepSeek report becomes a durable project artifact, and a deterministic
time-series appendix supplies model tables and charts without asking the model
to invent values.

## User-facing artifacts

| Artifact | Owner | Required content |
| --- | --- | --- |
| `reports/report.html` | deterministic report assembler | run identity, data/transform, model selection, parameters, diagnostics, rolling validation, forecast, limitations, key chart appendix |
| `reports/report.pdf` | deterministic PDF exporter | the same headings, facts and tables as HTML; no generic causal copy |
| `reports/ai-report.json` | Report endpoint | report record, fact snapshot, model, source run and generated Markdown |
| `exports/tables.xlsx` | time-series workbook adapter | Overview, candidates, parameters, diagnostics, rolling forecasts, next forecast, acceptance |
| Compare node | comparison builder + UI | same-sample status, specification deltas, metric table, conservative conclusion and link to raw JSON |
| Agent audit bundle | server-side exporter | parent/child session entries plus terminal operation records in chronological human-readable form and original JSON references |

The HTML and PDF remain deterministic and usable even when no provider is
called.  The AI report is a distinct, durable narrative layer whose exported
HTML uses the same Markdown and figure inventory shown in the UI.  It never
replaces deterministic facts.

## Report and chart policy

The report uses the existing `ts.*` artifact envelopes.  It shows the complete
model evidence in compact tables and embeds only the key time-series charts in
the printable appendix: transformed series, ACF/PACF, conditional variance,
conditional volatility, residual diagnostics, rolling interval and model
comparison.  The full 17-chart gallery remains accessible from the run/table
view and each chart keeps its original artifact lineage.

## Compare policy

`data_diff.changed` means data or sample-membership changed.  A
contract-bound split hash changing solely because model configuration changed
is reported separately as `split_contract_changed`; it must not claim that the
underlying data changed.  Automatic winner selection stays disabled unless
the existing integrity and decision policy explicitly permits it.

## Agent audit policy

JSONL remains the immutable machine audit source.  The new bundle is a read
only projection: it follows operation records into their child session, never
edits prompts, tool results or confirmations, and states when a session has no
terminal result.  It is not presented as a provider-authored report.

## Joint ARMA-GARCH boundary

v1.8 supports sequential ARMA-GARCH and joint AR-GARCH only.  Exact joint
ARMA(p,q)-ARCH/GARCH likelihood with `q > 0`, joint IC tables, Stata-compatible
conditioning semantics and numerical oracle tests are a separate future
estimator work package.  The release notes and backlog must state this plainly;
no v1.8 screen or export may call sequential likelihood values joint ICs.

## Verification

Tests prove each artifact has non-empty, finite, run-owned data; report export
round-trips durable AI records; workbook sheets contain expected rows; Compare
does not call identical membership a data change; and an Agent bundle includes
its confirmed child completion.  Browser QA uses VIXCLS and verifies visible
report, Excel sheet content, Compare summary and Agent audit bundle.
