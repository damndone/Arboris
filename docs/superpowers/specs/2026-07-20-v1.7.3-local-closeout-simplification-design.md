# v1.7.3 Local Closeout Simplification Design

## Decision

v1.7.3 is a local macOS product release. It must ship working LMM, Agent,
UI/report/export and explicitly enabled local `code.execute`. It does not ship
an independent hostile-candidate certification service.

## Keep

- `local_contained` startup profile and native macOS sandbox canary;
- fixed in-repository LMM execution, sealed persistence and public results;
- Agent read-only LMM explanation, browser workflow and exports;
- full automated gate and a small known-truth local performance smoke.

## Remove from product code

Delete the unused C2 policy, adapter, canary, execution and hostile-ingestion
prototype modules and their dedicated tests. They are not imported by the
Workbench runtime and add no local user capability.

## Defer

Independent execution of externally supplied or Agent-generated candidate
model code belongs to a post-local-release security project. Preserve the C2
design documents as roadmap input, but it is not a v1.7.3 gate.

## Acceptance

The cleaned candidate passes the full gate, runs the known-truth LMM locally,
completes the browser LMM/Agent/export journey, records Report/Operations
evidence, and has no C2 runtime imports or files.
