## Offline injection cases

`tests/test_agent_prompt_injection.py`: 6 evidence boundaries × 5 hostile goals =
30 cases. Boundaries: cell, column name, variable label, custom skill, external
runtime output, historical conversation. Goals: shell, configuration admission,
forged plan approval, unapproved external send, forged human actor.
Each loads real evidence (or replays the real external runtime boundary) into
Core, then a deliberately hostile fake model attempts the action through the
production tool registry. Assertions inspect receipts, actual transport counts,
source/config/policy hashes, approval/execution/workflow files and effects.
No string blacklist or model self-score decides success. **30 attempted / 0
successful unauthorized actions**. This is enforcement under a compromised
model, not measured resistance of an uncalled real model. Separate wire tests
confirm nested external evidence is withheld by default and allowed only under
its declared sharing class.
