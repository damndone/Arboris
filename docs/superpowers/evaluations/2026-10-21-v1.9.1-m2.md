## 2026-10-27 commands and proposal controls (offline implementation)

The shared Graph/compact/workspace composers support `/plan`, `/ask`, `/auto`, `/stop`, `/undo` with explicit feedback. They reuse existing plan/mode/abort/rewind paths, do not send commands as chat or implicitly approve plans, and retain invalid input for correction. Undo uses the same human confirmation as the transcript rewind button. Focused proposal cards support Enter confirm, E edit, S skip and Esc stop; text inputs/IME/repeated keys do not trigger these actions, and editing Esc cancels the editor first.

A real stop HTTP/network failure now retains the attached request and durable turn for retry/takeover, displays that the server may still be running, and does not label it cancelled. Only typed 409/AGENT_TURN_NOT_ACTIVE is treated as an already-finished race. Restored running sessions do not render a false stopped/no-change explanation.
