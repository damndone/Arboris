### Verified AR method and original sources

- Higham, *Numerical stability of algorithms at extreme scale and low precisions*,
  ICM 2022, §2: https://ems.press/content/book-chapter-files/33331?nt=1
  (deterministic dot-product bounds and blocked reduction; no probabilistic
  sqrt(n) replacement is used).
- Rump, *Error estimation of floating-point summation and dot product*, author
  manuscript accepted 2011, published BIT 52 (2012), §§2–4:
  https://www.tuhh.de/ti3/paper/rump/Ru11alt.pdf
  (unit roundoff, underflow allowance, and the distinction between an exact
  absolute sum and its floating approximation).
- SageMath 10.8 real-root-isolation implementation reference:
  https://doc.sagemath.org/html/en/reference/polynomial_rings/sage/rings/polynomial/real_roots.html
  (Bernstein-basis interval signs). Arboris does not depend on Sage or treat its
  midpoint roots as an independent original-input oracle.

Implementation proof chain: stream original binary64 degree-four feature
moments in 16384-row blocks; use gamma_(4n+16) and an additive underflow
allowance, including rounding of the absolute-sum bound itself. Reject product
underflow/overflow envelopes. The operation count is a conservative bound for
the two feature multiplications, dot product and block accumulation under
IEEE binary64 round-to-nearest/gradual-underflow arithmetic. Rational outward
192-bit dyadic intervals propagate through Gram inversion, residual/instrument
quadratic forms and bordered determinants. Only small sufficient-statistic
matrices use Python rational arithmetic; no observation-wise rational work is
on the verified path.

A midpoint Sturm decomposition proposes boxes. Acceptance additionally proves
opposite endpoint signs and a fixed derivative sign in each box, uniform
Bernstein signs on every complementary cell, a positive covariance determinant
on the whole real line and uniform Cauchy tail bounds. These statements hold
for every coefficient vector in the error box, so they enclose the unique set
specified by the original input digest and formula. Double roots, uncertain
degree, overlapping boxes and unproved signs fall back to original exact row
arithmetic. The certificate retains moment/inverse/coefficient bounds and sign
proofs for independent recomputation.

**Root identity is not equality of different polynomials' displayed decimal
endpoints.** Each verified box isolates an original-input root; displayed
midpoints are approximations. Exact original-input oracle roots must lie in
those boxes and the acceptance cells/components must agree. Verified boxes may
be wider than the exact path's 2^-44 boxes; their actual rational bounds are
recorded, never falsely labelled 2^-44. The existing R/Stata numeric comparison
tolerances remain fixed; global topology does not certify coverage or an exact
transcendental chi-square quantile.

## Compact JSON investigation — no serializer change

`artifacts.write_json` still uses `indent=2`; this investigation does not change
it or rewrite historical artifacts.

| Identity / reader | Consequence of compact serialization |
|---|---|
| `artifacts.register_artifact` / `sha256_file` | Every changed artifact byte digest changes, even when parsed values agree. Index records must bind the bytes actually written. |
| Native completion `diagnostic_artifact_sha256`, source SHA and LMM `terminal_sha256` | Re-serialization invalidates existing byte bindings. Referencing companions cannot be retained unchanged. |
| Pinned FD readers, terminal receipts and content-addressed diagnostic paths | Byte digests, receipt identity and digest-derived paths must remain consistent; the LMM writer uses its own contract and must not be implicitly reformatted. |
| `agent.context_compiler.read_completion_artifact` and result adapters | They parse JSON independently of whitespace, but verify the registered raw-byte digest first; changed files with an old index fail verification. |
| Approval/evidence packets and persisted provenance referencing artifact SHA | New artifact hashes propagate into their bindings; old approvals must not be silently rebound. |
| `sha256_canonical(payload)`, canonical plan/operation/research-specification fingerprints | Unchanged when the parsed values and canonical algorithm are unchanged. File-byte hashes and canonical object hashes are distinct. |
| Replay fixture manifests, byte-identity tests and exports containing evidence SHA | Raw checksum manifests and displayed references need the corresponding new hashes; never regenerate historical evidence to hide a mismatch. |

An in-memory formatting-only comparison (no file rewritten) on a repaired panel
run gave primary JSON 1909→1533 bytes, completion 3094→2537, index 8798→6703.
Both byte hashes changed in each comparison. These small artifacts do not show
an across-the-board 2x saving: the saving depends on nesting and row counts.
A future decision could apply compact JSON to **new writes only**, retaining
old readers and hashes. That serializer change requires the user's decision.
