# Legacy/Resume Remediation-3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make persisted ProposalStore identity and canonical content the only
authority for legacy Agent confirmation, with fail-closed route probes for
incomplete, cross-scope, tampered, forged, and replayed state.

**Architecture:** Keep the existing AgentNotebookCompiler boundary and add a
single server-owned persisted-proposal validator in the scoped Agent modules.
The validator rereads the latest ProposalStore revision, recomputes the exact
ProposalStore fingerprint, requires the complete `server_compilation` record,
and compares proposal content to the compiler record before any binding. The
legacy route calls the same persisted validator through its route-owned
proposal lookup before authority or mutation; receipt/replay checks remain
strict and server-retained.

**Tech Stack:** Python 3, dataclass ProposalStore/AgentNotebookCompiler,
FastAPI route helpers, pytest, formal `devline_control.py`.

- [ ] **Step 1: Require a complete server compilation record**

Add one typed helper used by `bind_proposal()` and
`compile_for_proposal()` that requires a mapping under
`proposal.preconditions["server_compilation"]` with non-empty exact fields:
`compilation_record_id`, `confirmation_id`, `semantic_plan_hash`, `actor_ref`,
`session_ref`, `project_ref`, `target`, `chain_id`, and `operation_id`. The
outer persisted `ProposalRevision` remains the sole source of proposal id,
revision, and fingerprint; if a duplicated proposal identity is present in
the compilation metadata it must match that outer revision. This avoids a
self-referential fingerprint field while keeping receipt proposal identity
server-owned. Reject missing, wrong-type, empty, or cross-scope fields before
setting `_proposal_bindings`.

```python
server_compilation = proposal.preconditions.get("server_compilation")
if type(server_compilation) is not dict:
    raise CutoverCompilerError("SERVER_PROPOSAL_COMPILATION_REQUIRED")
for field_name in REQUIRED_SERVER_COMPILATION_FIELDS:
    if field_name not in server_compilation:
        raise CutoverCompilerError("SERVER_PROPOSAL_COMPILATION_REQUIRED")
```

- [ ] **Step 2: Recompute canonical fingerprint and compare all content**

`operation_id`, proposal id/revision/fingerprint, actor/session/project, and
semantic hash to the server compilation record and compiler record. Do not
accept caller-provided proposal objects or envelope identity as authority.

`_cutover_authority`, compiler `record`/`execute`, or any claim/write. Keep
typed receipt digest/serialization/tamper/replay checks after this proposal
