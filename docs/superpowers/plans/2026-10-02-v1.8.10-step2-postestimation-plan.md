# v1.8.10 第 2 步：按接口做后估计（实施计划）

依据：objective 第 2 步；设计文档 §3.3、§3.6。分五个子步骤，每个子步骤先写失败测试，走完实现 → 测试审查 → 评审之后单独提交。

## 摸底结论（2026-10-02）

- **现有后估计**是三个工作流步骤：`model.joint_f_test`、`model.white_test`、`model.quadratic_stationary_point`。
  - 它们只认同一工作流里 `model.genesis` 声明的 OLS 分支，执行时从源数据**重拟合**。
  - 结果落成 `post_estimation` 产物，台账记为 inferential，报告的事实表已经会读。
- **只读执行**：Agent 把只读步骤组成 `operation.multi_step`，由 `read_only_policy` 直接执行、记入台账；每个会话 30 个检验之后需要用户确认。后估计接在这条路上，不另开旁路工具。
- **工作流目标是数据集节点**（`resolve_statistical_source`）。后估计的对象是模型节点，因此步骤用 `model_ref` 字段指向目标运行里的模型节点；目标数据集就是该模型的估计数据，边际效应要用它。
- **推断约定**：Workbench 的稳健（HC1）与聚类 OLS 按 z 报告 p 值（`use_t=False`），推断核心如实记为 z。所以这两种模型的 Wald 检验给 χ²(q)，与界面显示的 p 值自洽。Stata 的约定是 t(n−k)、t(G−1)。要不要改估计量的推断约定，单独提给用户决定，本步不改。
- **对照工具**：本机没有 Stata；R 有 `car`、`lmtest`、`sandwich`、`MASS`、`nnet`、`survival`，没有 `marginaleffects`、`mice`。
- **族名字面量**：`"ols_1"` 和 `model_type in (...)` 约 60 处。其中 `engine/stages/estimation.py` 和 `engine/packs/*` 是各族自己的拟合代码，写族名合理；共享路径里的要清理。

## 2a 推断核心上的后估计运算（纯函数）

新包 `backend/workbench/postestimation/`，只读推断核心，不碰数据、不重拟合。

| 运算 | 输入 | 推断规则 |
|---|---|---|
| `wald` | 线性约束 `R β = r`（按参数名给出） | 核心声明 t 时用 F(q, df_resid)，声明 z 时用 χ²(q) |
| `lincom` | 参数名到权重的映射，常数 | t(df_resid) 或 z |
| `nlcom` | 受限表达式（参数名、四则运算、幂、exp、log、sqrt），以 AST 白名单解析 | delta 方法，中心差分数值梯度；z 或 t(df) |
| `lr` | 两个核心 | χ²(Δk)；以下情况拒绝并说明原因：任一方没有 `loglik` 接口、协方差不是模型协方差（稳健、聚类、复杂抽样）、带概率权重、估计样本指纹不同、参数不是嵌套、族不同 |

- 拒绝一律给出**性质**层面的原因，例如“这个模型用聚类标准误，似然比检验不适用”。
- 约束矩阵奇异（重复或线性相关的约束）时拒绝，不静默降秩。
- 只引用核心里 `vcov_scope` 覆盖的参数；`focal` 范围之外的参数明确拒绝。
- 测试：与 R `car::linearHypothesis`（lm 用 F，glm 用 χ²）、`lmtest::lrtest`、手写 delta 方法对照，误差 1e-8。对照数据由 `tests/fixtures/postestimation/generate_oracle.R` 生成并提交。
- 性能：k = 300 时 Wald < 0.5 s。

## 2b 族 × 操作开放表（由对照数据决定）

- 开放表是数据：`postestimation/oracles/`（或测试 fixture）里每一组“族 × 操作”的对照用例通过，才开放。
- 没有对照的组合，拒绝文本是“尚无对照数据，暂不开放”，并说明缺的是对照，不是能力。
- 首批：OLS、logit、probit、Poisson 的 Wald、lincom、nlcom、LR；负二项、有序、多项的 Wald 与 lincom。
- 测试：故意删掉一组对照，对应组合关闭，且拒绝文本正确。

## 2c 边际效应

- AME 与在均值处的边际效应（MEM），连续变量用导数，因子变量用离散变化。
- 需要接口：`coef_vcov`、`predict`（按族声明的连接函数与尺度），以及估计数据。估计数据从血缘取回，用核心里的样本指纹核对行；对不上就拒绝。
- delta 方法给出标准误。
- 对照：R `marginaleffects::avg_slopes` 与 `slopes(newdata = "mean")`，需要用户同意从 CRAN 安装；否则退回按定义手写的 R 实现，并在对照文件里如实写明验证等级。
- 性能：10 万行 < 3 s。
