# Structured Evidence Implementation Plan

> **For agentic workers:** Use subagent-driven-development with disjoint write sets and spec/quality review. No worker commits or new worktrees; final candidate commit follows acceptance.

**Goal:** Close the approved structured-result and source-integrity gaps without reintroducing legacy reads.

**Architecture:** Versioned sections contain bounded typed trees and exact NumericFact references. Committed dependency manifests are checked through host-admitted FDs. Shared projection performs atomic section selection before any renderer or Agent receives content.

**Tech Stack:** Python dataclasses, existing EvidenceEnvelope/C0 store and host FD admission; pytest; existing React consumers and HTML/PDF/XLSX writers.
