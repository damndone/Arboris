# Provider Model Discovery Implementation Plan

> **For agentic workers:** Integration executes this central-file task with test-driven-development and verification-before-completion. Design authority is the user's autonomous objective authorization.

**Architecture:** A read-only HTTP endpoint uses the existing fetch_models parser and sanitized errors. The editor discovers from draft credentials while new, keeps persisted refresh behavior while editing, and only admits a response for the current draft identity.
