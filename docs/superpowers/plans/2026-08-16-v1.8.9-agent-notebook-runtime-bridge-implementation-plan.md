## 2. Implement three disjoint seams in parallel

### A. Runtime/bootstrap

- Add a small composition helper that accepts only server-owned runtime contributions and
  constructs the existing trusted registry/catalog join.
- Add explicit application-instance configuration and an exact-scope public lookup for the
  shared compiler. Keep unbound behavior fail-closed. Require the HTTP host identity resolver
  for both Agent and Notebook cutover routes; request actor/session/project fields are
  assertions only.
- Test missing/duplicate/mismatched contributions, no-op/fixture non-production behavior,
  bootstrap install, app-instance scope isolation, forged authority rejection, and
  scope-bound typed evidence receipts whose digest matches the canonical dispatched result.

### B. Notebook adapter

- Add a thin `/notebooks/{notebook_id}/cutover/compile` adapter that verifies the Notebook
  exists and delegates to the shared compiler with `entrypoint="notebook"`.
- Derive or require server-bound Notebook scope; do not trust a client project to widen it.
- Resolve actor/session from the server-owned host binding keyed by the persisted Notebook;
  reject mismatched client assertions before compiler lookup.
- Test equivalent Agent/Notebook semantic hashes, missing clarification, scope mismatch,
  unbound 503 and rejection of client authority fields.

### C. Report consumer

- Register the classification packet in `artifacts_index` through the FD-admitted persistence
  boundary, then extend the existing artifact loader with the classification artifact identity.
- Validate index path containment, server-side artifact hash, schema version and typed envelope
  before putting it in `familyEvidenceArtifacts.classification_evidence`.
- Test present, absent, stale-hash, malformed and unsupported packet cases; never expose raw
  payload content.

## 3. Integrate and verify

- Review each subagent diff for ownership, append-only historical tests and protected-path
  compliance.
- Run focused new tests, existing cutover/Notebook regressions, frontend full test suite if
  time permits, typecheck, compileall and diff check.
- Append material failures/gaps/gates to the formal event stream as they occur.
- Generate the handoff with implemented/tested, browser-accepted, released and known-limit
  claims separated.
