# v1.8.2 Class 3 Agent Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make one natural-language Agent request produce a locked, auditable, nine-step Class 3 workflow over the selected Raw data node without `code.execute`.

**Architecture:** Add a workflow-local append-only exploration log and report aggregator first. Then expose existing statistical exploration and OLS behavior through server-owned typed operation templates. A workflow compiler accepts only evidence-backed column/group bindings, creates a dependency DAG, and executes each step under one durable workflow confirmation with per-step fingerprints, artifacts, blocked dependents, and resumable idempotency.

**Tech Stack:** Python 3, FastAPI, Pydantic, pandas, statsmodels, existing artifact/index/report/export seams, React, TypeScript, Vitest, pytest, `scripts/gate.sh`, and the in-app browser.
