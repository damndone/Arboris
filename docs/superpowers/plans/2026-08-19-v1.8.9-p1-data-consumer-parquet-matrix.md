> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Parquet capability, writer/read-back, and bounded ingestion agree for every optional-dependency matrix without weakening the existing bounded contract.

**Architecture:** Keep one private engine-admission function in `data_interchange.py`; conservatively admit only pyarrow because its bounded batch semantics are implemented and verifiable in the current environment. Make ingestion consult that function before its pyarrow import, and use controlled module-discovery monkeypatches plus real pyarrow artifacts to test the complete matrix.

**Tech Stack:** Python, pandas, pyarrow when already installed, pytest monkeypatch, existing typed interchange result/error contracts, Vitest frontend regression suite.
