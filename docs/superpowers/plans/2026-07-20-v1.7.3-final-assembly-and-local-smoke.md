- [ ] **Step 3: Implement the smallest closed profile service**

```python
class ExecutionProfile:
    def require_lmm_admission(self) -> None:
        if not self.lmm_admitted:
            raise ExecutionProfileError("LMM_FROZEN_CONTAINMENT_REQUIRED")

def startup_execution_profile() -> ExecutionProfile:
    raw = os.getenv("WORKBENCH_EXECUTION_PROFILE", "default").strip()
    if raw not in {"default", "local_contained"}:
        raise ExecutionProfileError("LOCAL_CONTAINMENT_PROFILE_INVALID")
    if raw == "default":
        return ExecutionProfile.default()
    return ExecutionProfile.local_contained(run_local_containment_canary())
```

The canary must use `run_python_sandboxed`, assert a permitted output write,
and require denied outside-write and denied networking observations.  Startup
must fail if the canary cannot prove all assertions.
