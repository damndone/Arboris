# Classification Artifact Bounded Streaming Remediation 15 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the generic indexed artifact download stream from one verified descriptor with bounded memory, FD cleanup, mutation fail-closed behavior, and the compatibility headers/range semantics previously supplied by `FileResponse`.

**Architecture:** Keep path grammar, no-follow traversal, regular-file checks, and descriptor metadata in `repository/file_integrity.py`. Extend its opened-file object with chunked hash/stream primitives that use `pread` plus per-chunk `fstat` checks. Let `runs_routes.py` perform index digest verification and response/range shaping, then return a `StreamingResponse` whose generator owns and closes the already-open descriptor. Classification wrapper, repository list validation, and all protected producers/consumers remain unchanged.

**Tech Stack:** Python 3, FastAPI/Starlette `StreamingResponse`, `pytest`, POSIX `O_NOFOLLOW`/`O_DIRECTORY`/`fstat`/`pread`, existing `file_integrity` seam.

### Task 3: Extend the shared opened-FD seam with bounded primitives

**Files:**
- Modify: `backend/workbench/repository/file_integrity.py`

- [ ] **Step 1: Define the explicit streaming policy**

Add constants:

```python
MAX_ARTIFACT_STREAM_CHUNK_BYTES = 64 * 1024
MAX_ARTIFACT_STREAM_BYTES = 512 * 1024 * 1024
```

Reject a regular opened artifact whose initial `fstat().st_size` exceeds the
maximum with `OSError("indexed artifact exceeds the bounded stream size")`.

- [ ] **Step 2: Replace whole-file hashing for generic streams**

Add an internal stable-stat snapshot and an iterator that uses `os.pread` at
explicit offsets. Before and after each chunk, compare `st_dev`, `st_ino`,
`st_mode` regularity, and `st_size` to the initial snapshot. Stop without
yielding the changed chunk and raise `OSError` when any comparison changes.
Implement `sha256()` with the bounded iterator and `hashlib` updates; keep
`read_bytes_and_sha256()` only for small typed JSON consumers and preserve its
existing contract.

- [ ] **Step 3: Add a stream iterator with a caller-owned descriptor**

Expose `iter_bytes(start=0, end=None)` on `OpenedRunFile`, where `end` is
exclusive, every yielded block is at most the chunk constant, the expected
range is bounded by the initial size, and no pathname is reopened. The route's
generator, not the helper iterator, must own the context lifetime and close
the descriptor in `finally`.

- [ ] **Step 4: Run helper-level RED tests again after each minimal change**

Run the new selector after implementing each helper method. Expected: helper

### Task 4: Migrate generic download to safe bounded streaming with old semantics

**Files:**
- Modify: `backend/workbench/http/runs_routes.py`

- [ ] **Step 1: Parse optional Range and If-Range headers without breaking direct callers**

Add optional FastAPI `Header` parameters with aliases `Range` and `If-Range`,
both defaulting to `None` so existing direct unit calls with three positional
arguments continue to work. Implement the old `bytes` parser for single and
multiple ranges, returning explicit 400 malformed and 416 unsatisfiable
responses with `Content-Range: bytes */<size>` where required. If `If-Range`
does not match the descriptor-derived ETag or Last-Modified value, ignore the
Range and return the full 200 stream.

- [ ] **Step 2: Build compatibility headers from the opened descriptor**

Use `mimetypes.guess_type(opened.name)[0] or "application/octet-stream"`,
`Content-Disposition`, `Content-Length`, `Accept-Ranges: bytes`, and the same
stat-derived `Last-Modified`/ETag convention as Starlette `FileResponse`.
For one range return 206 with `Content-Range`; for multiple ranges stream a
multipart/byteranges body with deterministic headers and exact calculated
length. Do not call `FileResponse` or reopen by pathname.

- [ ] **Step 3: Make the response generator own cleanup**

Open once, hash from the opened FD, compare the indexed digest, compute the
range plan, then return `StreamingResponse`. The body generator must wrap all
range iteration in `try/finally: opened.close()`. Hash/open errors before the
response is returned map to the existing typed 409 integrity errors; read-time
mutation errors propagate out of the iterator after cleanup and never yield
further bytes.
