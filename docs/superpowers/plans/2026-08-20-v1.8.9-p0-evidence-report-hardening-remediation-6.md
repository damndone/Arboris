# Evidence/Report hardening remediation-6 Implementation Plan

> **For agentic workers:** This plan is executed inline in the target worktree with TDD checkpoints; the formal devline Context Pack and the user prompt are the controlling scope.

**Goal:** Close the four independent remediation-5 P0/P1 findings without weakening the server-owned Report boundary or restoring raw fallbacks.

**Architecture:** Establish one pre-IO admission helper for HTTP/report export that resolves the exact host-admitted owner from server request identity before artifact reads. Add an exact-object issuer registry for projections and revalidate it at every consumer/writer seam. Make ReportStage pass only an owner-issued projection from explicit stage context; absent admission becomes typed unavailable.

**Tech Stack:** Python 3, FastAPI, pytest, dataclasses, existing C0 EvidencePacketStore/Registry/receipt/host-authority contracts, Jinja2 report writer.
