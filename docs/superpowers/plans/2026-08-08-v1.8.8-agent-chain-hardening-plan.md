## Architecture and ownership

The implementation has four ownership seams:

1. `report_contract.py` and the Report route own narrative validation,
   deterministic figure binding, and the bounded Report-only transport retry;
2. `agent/notebook/artifact_contract.py` and `agent/notebook/service.py` own
   the distinction between the contract projection and the ambient run index;
3. a new declaration-driven missing-capability adapter registry owns the
   eighteen workflow steps, while `workflow_contracts.py` projects schemas and
   `workflow_runtime.py` dispatches one generic adapter key; and
4. `draft_materialization.py`, `pipeline_drafts.py`, the draft route, and
   `GenesisWizard` own the two-phase Genesis editor schema and its hash.

The Agent remains responsible for discovery, rationale, and composing a
proposal. The server remains responsible for closed schemas, confirmation,
method validity, numerical execution, artifact provenance, and fail-closed
errors. No module may add a per-operation branch to the orchestrator.

## Verification and mutation protocol

For every new assertion:

1. assert the mutation anchor exists before editing;
2. apply a behavior-changing mutation, not a no-op mutation;
3. assert the target file hash changed and the intended behavior changed;
4. run the smallest focused test and capture the exact red error;
5. restore the file and assert the original hash/content is back; and
6. rerun the focused test green.

If a mutation is green, investigate whether it was behaviorally inert before
calling the guard dead. A missing file, wrong worktree, no-op condition, or
wrong operation ID is a failed verification, not evidence.

Before declaring completion:

- run `git diff --check`, all focused suites, frontend typecheck/build, and the
  repository full gate from the repository root on the host terminal;
- run FMS verification and regenerate the retrospective through
  `scripts/devline_control.py`; and
- write a handoff that separates implemented/tested, browser-accepted,
  released/merged, and `NOT VERIFIED` claims. Include live matrix denominator,
  optional-dependency blocks, retry evidence, artifact projection evidence,
  P2 counts, and any known numerical limitations.
