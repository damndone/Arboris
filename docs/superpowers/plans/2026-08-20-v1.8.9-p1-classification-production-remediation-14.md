# Workbench v1.8.9 P1 Classification Production remediation-14 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close every in-scope artifact byte-read TOCTOU boundary by sharing one bounded-path, no-follow, stable-FD integrity seam across list validation, HTTP download, and classification artifact/receipt consumers.

**Architecture:** Add `repository/file_integrity.py` as the only owner of bounded relative-path parsing, descriptor traversal, regular-file checks, same-FD digesting, and same-FD byte snapshots. The repository validator, HTTP route, and classification consumer call that seam; none performs a second pathname lookup. Generic downloads return a `Response` built from bytes read from the opened descriptor, while classification downloads return the already validated typed wrapper.

**Tech Stack:** Python 3.14, FastAPI `Response`/`JSONResponse`, POSIX `os.open`/`os.openat`/`os.pread`/`os.fstat`, pytest, the existing Workbench typed contracts and formal devline CLI.

### Task 3: Implement one shared opened-FD integrity seam

**Files:**
- Create: `backend/workbench/repository/file_integrity.py`

- [ ] **Step 1: Define the bounded path grammar once**

Implement `validate_run_relative_path(value) -> tuple[str, ...]` with the
existing server-owned ASCII component grammar, 128-byte component limit, 64
component limit, 512-byte total limit, no empty/dot/dot-dot/backslash parts,
and no path resolution.

- [ ] **Step 2: Define the opened regular-file object**

Implement `open_run_relative_file(run_root, relative_path)` using
`O_NOFOLLOW|O_DIRECTORY` for the root/intermediate directories and
`O_NOFOLLOW` for the final file. `fstat` every opened directory and the final
descriptor; reject non-directories and non-regular files; close every
descriptor on all error paths. Return a context-managed object that owns only
the final descriptor and normalized relative name.

- [ ] **Step 3: Read and hash from the same descriptor**

Implement methods equivalent to:

```python
def read_bytes_and_sha256(self) -> tuple[bytes, str]:
    data = self._read_snapshot_from_fd()
    return data, hashlib.sha256(data).hexdigest()

def sha256(self) -> str:
    return hashlib.sha256(self._read_snapshot_from_fd()).hexdigest()
```

Use `os.pread`/`os.fstat` on the owned descriptor, reject a changed inode or
size during the snapshot, and never reopen or hash a pathname.

validated JSON wrapper.

receipt, evidence, and projection validation/error codes.

make it use the shared bounded grammar only and do not use it from the download
endpoint. Do not add a second containment or hashing implementation.
