# v1.8 Deliverables Closeout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every v1.8 ARMA-GARCH run produce truthful, non-empty and human-inspectable reports, workbooks, comparisons and Agent audit exports, while recording joint MA-GARCH as a future estimator boundary.

**Architecture:** Reuse the existing `ts.*` artifact envelope as the only source for time-series deliverables. Add pack-specific projection helpers instead of changing the generic model packet, persist provider-generated report records under the run, and keep JSON/JSONL as evidence with human-readable projections layered above them.

**Tech Stack:** Python/FastAPI, Jinja2, ReportLab, openpyxl, React/TypeScript, Vitest, pytest.
