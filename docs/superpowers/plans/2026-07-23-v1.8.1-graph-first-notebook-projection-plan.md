# Graph-first Notebook Projection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Notebook a Graph-/Dataset-bound narrative projection whose Agent recommendations are backed by bounded, traceable data evidence; select an option by materializing an existing PipelineDraft (rerun-child or pre-run genesis), without adding a second execution path.

**Architecture:** A default Notebook is atomically bound to a persisted RunFamily and an immutable source: either the caller's focused run or a verified pre-run Dataset upload. A bounded Evidence Pack is compiled from registered read-only inspections; a dedicated Notebook planning adapter submits typed option batches, and a batch-level RecommendationDecision gate may choose one winner or return tied/insufficient evidence. Confirming an option only creates a provenance-pinned PipelineDraft through the existing rerun-child or genesis draft path.

**Tech Stack:** Python, FastAPI, dataclasses/Pydantic contracts, existing OpenAI-compatible Agent adapter, JSONL/content-addressed project storage, React/TypeScript, Vitest, pytest.

---

## Scope and non-goals

This plan implements the first trusted vertical slice approved in the Graph-first design:

```text
focused Graph/Run ─┐
                    ├→ bounded context + evidence → typed Agent option batch
verified Dataset ───┘  → evidence-gated decision → selected option
                       → rerun-child / genesis PipelineDraft visible in Graph
```

It deliberately does not add a Notebook-specific executor, automatic Run/Artifact result return, or Notebook Compare UI. Existing Draft validate/execute remains the only execution route. A later slice can observe that existing route and project its results back into Notebook.

- [ ] **Step 3: Implement protocol and decision validation.**

  Define a protocol boundary with no global score:

  ```python
  class RecommendationProtocol(Protocol):
      protocol_id: str
      def evaluate(self, candidates: tuple[OptionDraft, ...], evidence: DataEvidencePackV1) -> ProtocolResult: ...
  ```

  `RecommendationValidator.decide` must first apply hard capability/input/diagnostic blocks, then use only declared common-cohort protocols. It returns `recommended` only when one candidate exceeds the protocol’s declared margin or every alternative is blocked. It returns `tied` for results inside the margin and `insufficient_evidence` for missing, failed, truncated, or incomparable evidence.
