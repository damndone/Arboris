# Legacy/Resume Remediation-4 Implementation Plan

> **For agentic workers:** Execute this plan only inside the target worktree and
> use the active formal remediation-4 line. Keep every `.agent/devlines` change
> under `scripts/devline_control.py`.

**Goal:** Close the server-owned ProposalStore capability and synthetic legacy
proposal bypasses while retaining Resume safety evidence.

**Architecture:** A compiler-owned opaque ProposalStore capability is issued
only by the server authority and is checked by identity, process generation,
root identity, and owner token before persisted reads. The legacy route receives
only a route-owned canonical proposal reference produced by a persisted reread;
it rejects all caller-shaped proposal objects before extracting preconditions or
touching authority/record/claim/write state.

**Tech Stack:** Python, immutable dataclasses, append-only JSONL ProposalStore,
pytest, the existing AgentNotebookCompilerV1 and FastAPI route seams.
