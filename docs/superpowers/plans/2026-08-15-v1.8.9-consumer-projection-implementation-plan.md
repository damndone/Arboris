> **状态（2026-09-27）：部分采纳，不按本文件执行。** v1.8.9 已按 `objectives/2026-09-25-v1.8.9-objective.md` 在 `.worktrees/workbench-v1.8.9` 重建交付；本文件的并行 lane / Contract Lock / 独立 Evaluation Lane 组织方式未采用。下述条目的去向记录在 `followups/BACKLOG.md` §0.2（v1.8.9 延后与未实现）。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. This line consumes persisted evidence and must never recompute statistical results.

**Goal:** 为 Results、Agent、Notebook、Report 与 UI 建立同源、受限、可追踪的 evidence projection，使所有消费者引用同一 artifact/fact identity，同时按消费场景实施数据最小化、敏感性和可用性约束。

**Architecture:** `EvidenceEnvelopeV1` 是唯一统计事实来源；consumer adapters 只做 schema-versioned selection/redaction/render mapping。Coverage 按 capability × exposure path × operation version × IO contract × result/evidence shape × consumer 计算。该线发布 projection contributions，但不修改中央 Agent/Notebook planner 或 Report mount。

## Ownership boundary

- 依赖 C1：Contract Lock、Workflow Truth Core、Evidence Core、Agent Compiler Core 已完成。
- 可与 Data Consumer Core、Classification ML Core 并行。
- 不修改 workflow runtime、planning compiler、central capability registry、Notebook planner、ReportView 或 section registry。
- 任何缺失、不支持或受限事实必须保留 `UNAVAILABLE`、`DEGRADED`、`BLOCKED`，不得补零或由 LLM 推测。

## Exit criteria

- All consumers preserve one persisted fact identity/value; divergence tests fail before release.
- LLM/remote contexts are bounded and sensitivity-aware with auditable omission/redaction receipts.

- No central Agent/Notebook/Report mount file is changed.
