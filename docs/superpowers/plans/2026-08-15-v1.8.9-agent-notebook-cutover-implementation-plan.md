# Workbench v1.8.9 Agent and Notebook Cutover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. This is the sole Wave C writer for central Agent/Notebook/UI routing files.

**Goal:** 把 Workflow、Evidence、Data Consumer、Classification ML 与 consumer projection 的 package-local contributions 接入同一个 server-side compiler/catalog，使 Agent 与 Notebook 通过自然语言使用同一能力、同一确认边界、同一 runtime authority 和同一结果证据。

**Architecture:** Central files become thin catalog/admission/mount facades. Provider declarations are discovered and checked against Contract Lock; compiler persists `CompilationRecordV1`; execution accepts only server-bound record ID plus valid confirmation. Agent and Notebook share AnalysisIntent → clarification → compile → preview/diff → confirm → execute → persisted evidence, but retain different presentation projections.

## Preconditions and ownership

- C2 must prove Contract Lock + all three P0 cores + Data Consumer Core + Classification ML Core + Consumer Projection Core are compatible.
- This line starts only after Wave B feature writers stop; maximum one writer owns central cutover files.
- Integration/evaluator may inspect but may not edit this worktree.
- No statistical formulas, model fitting or data computation are implemented here; cutover only binds registered providers and public facades.
