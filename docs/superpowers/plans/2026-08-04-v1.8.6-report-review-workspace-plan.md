+# Report review 工作区 Implementation Plan
+
+> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
+
+**Goal:** 将 Report review 实现为与节点标签同级的工作区系统标签，统一 Report/Graph/Table 右侧面板宽度，并让 Float review 跨页面保持悬浮，同时保留报告证据不可变和用户主动导出边界。
+
+**Architecture:** 在 Workbench shell 增加可判别的 workspace panel tab 与统一 PanelHost；将 ReportView 的报告状态抽取到按 project/run 惰性初始化的 ReportWorkspaceProvider，使中心 Report 页面和右侧 ReportReviewPanel 共用同一份 report record、evidence packet、revision 和导出动作。Float 面板通过 shell 根级 portal 挂载，Docked Collapse 折叠整列为可恢复把手；`report:review` 是不占节点 8 个名额的系统 tab。
+
+**Tech Stack:** React 18, TypeScript, React Router URL state, Vitest, Testing Library, existing WorkbenchStateProvider/DetailDrawer, existing ReportView/reportClient/reportHistory.
