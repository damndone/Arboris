> **For agentic workers:** Execute this plan task-by-task in the active formal remediation-5 line. Every production change must follow RED then GREEN, and every formal record must be appended through `scripts/devline_control.py`.

**Goal:** Remove direct WorkbenchOrchestrator ProposalStore mutation bypasses while keeping legitimate server-route and Resume safety boundaries intact.

**Architecture:** The orchestrator receives only a server-issued `ProposalStoreCapabilityV1` for proposal persistence. A default/direct instance has no writable proposal store and raises a typed boundary error before reads that could lead to writes. Agent routes issue a route-owned capability for the repository root and inject it explicitly; scope and capability admission are checked before proposal mutations.

**Tech Stack:** Python 3.14, pytest, append-only JSONL ProposalStore, FastAPI route adapters, formal `devline_control.py` event chain.
