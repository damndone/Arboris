# Workbench v1.8.9 Contract Lock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在任何并行 feature lane 启动前，建立版本化公共 refs/schemas、确定性 provider catalog、canonical fixtures、authority/hash 和兼容性测试，形成 v1.8.9 唯一可消费的 Contract Lock C0。

**Architecture:** 公共合同位于 `backend/workbench/contracts/**`，ProviderContribution 只组合版本化 refs，不复制算法或形成超级 CapabilityContract。Catalog 只读取仓库内固定 builtin manifest 目录，稳定排序并对 duplicate、unresolved、digest/version mismatch fail closed；现有执行 registry 在 Agent/Notebook Cutover 前仍是权威，Contract Lock 不提前双写或切换 runtime。

**Tech Stack:** Python dataclasses、JSON、`canonical_json_v1`/SHA-256、pytest、formal devline control、YAML release-train manifest。
