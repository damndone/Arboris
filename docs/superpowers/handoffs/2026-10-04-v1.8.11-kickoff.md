## 四、做法与已知坑（v1.8.10 学到的）

- **gate 运行期间不要改工作区**：第一次 gate 因为中途改了对照数据，结果作废重跑。
- **在规划器里拒绝的组合，流水线里也要拒绝**：HTTP / CLI 直接请求绕过了 Agent 规划阶段（A03）。
- **对照比较最终报告的量**（F、自由度、p），不要只比中间量（W）；R `glm` 的标准误取自上一轮迭代，需要时从最优点再拟合一次。
- **一个引擎替换了方差，所有读推断元数据的地方都要读替换后的**（抽样设计结果曾被描述成 HC1、t(77)）。
- 独立评估（Codex 评估线）在 gate 之前做；工单要写清“误写文件 → 核对 → 继续”的规则，否则它会过度停止。
- DeepSeek V4.1 Flash 的 API id 是 `deepseek-flash`；本机 `llm.env` 与 `llm-providers.json` 已改（各有 `.bak-2026-10-04`）。
  真机评测用 Flash，先查余额（`/user/balance`）。
- 子 agent 用 opus；`PYTHONPATH=backend`；gate 在宿主终端跑、先停 Vite、独占机器。
