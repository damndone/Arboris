## Browser-discovered defects fixed

1. **Original VIX file could not complete.** The run path now supports the declared `drop_missing_confirmed` analysis policy while keeping the uploaded source immutable. The blocking policy still produces a structured, auditable failure.
2. **Failure rendering lost useful identity.** Failed ARMA-GARCH runs now keep a configured-not-fitted model tombstone and truthful terminal artifact state.
3. **Genesis and run surfaces drifted.** The graph-native form now exposes the time column, value column, time semantics, missing policy, confirmed transform, selection mode, estimation strategy, distribution, validation window, refit cadence, and advanced manual orders.
4. **Stage audit identity was incomplete.** Generated time-series stage nodes now retain the node hash, operation identity, owning stage, and artifact lineage needed by node drawers and Agent context.
5. **Four Stata sequence charts were absent.** Conditional variance, standardized residuals, squared standardized residuals, and squared mean-residuals were added from existing structured series without recomputation.
6. **Chart download was not browser-safe.** SVG export now attaches the temporary anchor before click and revokes the Blob URL after the browser has consumed it.
7. **Report facts were too generic.** The fact table now includes transform, missing policy, estimation semantics, analysis observations, and excluded observations from `ts.analysis_contract` and `ts.data_audit`; the real DeepSeek report was regenerated after the fix.
8. **Agent precheck and execution merged nested patches differently.** `model_options` sections now merge key-wise, so changing `q` or missing policy cannot silently erase `p` or other sibling keys.
9. **Valid reruns were rejected as stale.** Project-wide shared-node membership remains available for display and Compare, while mutation fingerprints now use only the selected rerun family, matching backend validation.
10. **Compare could not resolve a shared parent node.** Read-only comparison resolution now selects the nearest owning ancestor of the active run instead of becoming ambiguously unresolvable.
11. **Persisted Compare falsely reported sample mismatch.** The public artifact reader now loads `ts.train_validation_split`; identical frozen row IDs produce the same membership hash even when contract-bound split hashes differ.
12. **The Table view showed only four charts.** Table classified only legacy `figure` PNG artifacts as figures, while all 17 ARMA-GARCH chart artifacts are structured `time_series_json`. Table now reuses the existing ARMA-GARCH loader and gallery, using its already-fetched artifact listing rather than duplicating requests or calculations.

## Delivery artifact truth after browser acceptance

The successful browser workflow proves that the structured results exist; it does **not** prove that every downloaded deliverable is fit for human review. A post-run artifact audit found four release blockers:

| Deliverable | Current truth | Required closure |
| --- | --- | --- |
| `reports/report.html` and `report.pdf` | Run-owned files are basic legacy summaries. The materially richer DeepSeek report shown in the browser is browser-local, so the two surfaces are not the same durable report. | Persist one run-owned report fact source and render browser/HTML/PDF from it, with deterministic facts and provider prose clearly separated. |
| `exports/tables.xlsx` | Successful ARMA–GARCH VIX runs produced only an empty `coefficients` sheet because the exporter receives traditional coefficient rows, not `ts.*` artifacts. | Export non-empty overview, candidates, parameters, diagnostics, rolling forecasts, next forecast and acceptance sheets with artifact provenance. |
| Compare JSON | The comparison calculation is evidence-bearing, but its JSON is too large and technical for direct human review. A contract-bound split hash can differ despite identical row membership. | Add a human summary of sample membership, model changes, metric/diagnostic changes and why an automatic winner was or was not chosen; retain JSON as audit data. |
| Agent transcript | Parent session JSONL preserves prompts/proposals/tool calls, but successful execution can live in child-session and operation records. | Export a read-only aggregate from question through proposal, confirmation, child run and terminal outcome, with links to raw records. |

These are delivery-layer defects, not evidence that the VIX model run or its 17 chart artifacts failed. They block publication until fixed and independently accepted.
