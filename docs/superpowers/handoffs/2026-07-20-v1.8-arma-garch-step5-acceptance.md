## 2. Defects found by independent verification and fixed (minimal, in-scope)

1. **Full-suite collection crash (blocker).** The new `tests/models/arma_garch/test_diagnostics.py`
   collided (same basename, no `__init__.py`, prepend import mode) with the pre-existing
   `tests/models/linear_mixed_effects/test_diagnostics.py`, aborting collection of the whole
   backend suite. The focused runs never exercised both together, so this was invisible to the
   prior "156 focused passed" evidence. Fix: renamed the new file to
   `test_arma_garch_diagnostics.py` (unique basename; only a v1.8 untracked file touched).

2. **Capability-vocabulary regression (blocker).** The pack registers a new, spec-mandated
   capability group `Time Series`, but `tests/test_engine_capabilities.py::test_groups_match_known_vocabulary`
   was not updated, failing the full suite. Fix: added `Time Series` to the known-vocabulary allowlist.

3. **Misleading "Run failed" trust banner on a successful run (UI correctness).** The generic
   `diagnostic_summary_preview` derived `has_results` from a `coefficients`-filtered projection,
   which excludes the ARMA–GARCH result (it has no classic coefficient table). A completed,
   `ACCEPTED` run was therefore labelled **run failed** on the legacy overview surface, violating
   the "UI must not mislead" completion rule. Fix: `backend/workbench/diagnostic_preview/_entry.py`
   now honours the backend's already-persisted `run_status.model_results_available`. Regression
   tests added in `tests/test_diagnostic_preview.py` (positive: coefficient-less completed run →
   `ready_to_interpret`; negative: genuinely result-less completed run → `run_failed`).
   Verified live: banner flipped `Run failed` → `Ready to interpret`, report link `Report
   unavailable` → `View report`.

## 8. Known statistical limitations (by design)

- Sequential two-stage reports only per-stage IC; no composite ARMA–GARCH likelihood/AIC.
- Predictive intervals are plug-in conditional (exclude parameter uncertainty); non-linear
  back-transforms provide point/median + bounds only, never an original-scale conditional variance.
- q>0 joint estimation is unsupported by contract (blocked, not downgraded).
- 5% conditional quantile is never auto-labelled VaR.
