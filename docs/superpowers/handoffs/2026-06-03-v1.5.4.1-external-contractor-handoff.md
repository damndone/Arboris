## 3. ⚠️ 命名警告:`recommended_actions` 同名不同 schema

**前端 `runResult.tsx:298` 已经在消费另一个 `preview.recommended_actions`**:
```typescript
// 现有:来自 preview/run_summary(不是来自 errors.json)
preview?.recommended_actions: Array<{action_key, severity, message}>
```

**V1.5.4.1 在 `failure_evidence` 里加的是另一个 schema**:
```typescript
// V1.5.4.1 新加:来自 errors.json 的 BLOCKER 项
issue.evidence.recommended_actions: Array<{key, label, severity, form_overrides?, hint?}>
```

**同名,不同 schema,不同来源,不同语义。**

- `preview.recommended_actions` = 一般建议(行动 key 为 `action_key`)
- `issue.evidence.recommended_actions` = 失败恢复(行动 key 为 `key`)

**FailureCard 组件名字是独占的、只渲染失败 evidence 的 actions。不要在 FailureCard 里用 preview 的 action schema,反之亦然。** 如果你在做 FailureCard,字段是 `key` 和 `label`;如果你看到 `action_key` 和 `message`,那是另一个东西。

- **响应预期**:你 ping → controller 24h 内回。不阻塞时建议你**先做下一个 task**(任务之间独立)。
