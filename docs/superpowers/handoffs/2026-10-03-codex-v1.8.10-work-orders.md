3. 测试：跑真实流水线，比较系数（容差 1e-8）和标准误（1e-6，GLM 用 1e-6，LMM 用 1e-4 并写明是 REML 优化器差异）。
4. R 无法复现 Workbench 的协方差估计器时：写清楚原因，标为“未决”，**不要**改用别的估计器凑数。

参考设定（只作起点，以第 2 步读到的推断核心为准）：
- `iv_2sls`：`AER::ivreg` 或 `fixest::feols(y ~ x | endog ~ instr)`。
- `panel_ols`：`plm(..., model="within")` 或 `fixest::feols(y ~ x | entity)`。
- `did`：两期 2×2 的 TWFE，`fixest::feols(y ~ treat:post | unit + time)`。
- `linear_mixed_effects`：`lme4::lmer(y ~ x + (1|g), REML=TRUE)`。
- `glm:*`：`glm(..., family=binomial/poisson)`、`MASS::glm.nb`，`glm.control(epsilon=1e-14)`。
