## 行为

移除带版本的内建模型预设和环境显示名映射，历史用户配置仍按原 ID 读取。新增只读 draft discovery：URL 与 API key 足够即可 GET /models，无需先猜模型保存。新增/复制服务商离开凭据或 URL 输入后自动发现，手动 Refresh models 也可使用；不自动选择或更改默认模型。已有服务商仍走原来的持久配置刷新。请求失败或空列表明确提示手填，保留用户输入；凭据变更后的旧响应不会污染当前列表。
