## 不可破坏的边界

- 不手改 `.agent/devlines`；事件、rescope、verify 一律走
  `scripts/devline_control.py`。
- `backend/workbench/model_terms.py` 与 `figure_context.py` 受
  allow-path 深度校验限制：`rescope-context` 会拒绝
  `backend/workbench/*.py` 这一层级。要改它们必须**新开一条开发线**，在
  `start` 时把路径放进 allowlist（`v1-8-4-model-term-reuse` 就是这么开的）。
  不要为了绕开而去改受保护的 `context_pack.py`。
- workflow 保持 typed、服务端校验、受 Proposal/Risk 确认约束；不引入任意
  公式、代码执行或原始数据浏览。
- post-estimation 结果必须从已完成分支推导并带 provenance；不得为可用性
  放宽语义前置条件。
- Action 模式不得使用排序/推荐措辞；那是 Agent 未被要求做出的判断。
