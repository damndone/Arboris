## P2 follow-ups (next sprint, not blocking)

### P2.1 — GraphCanvas: no empty-state when all nodes are filtered out
**File**: `frontend/src/lineage/GraphCanvas.tsx`  
**Detail**: If `foldVariableClusters` returns zero real nodes (edge case: graph with only variable nodes all folded), ReactFlow renders an empty canvas with no message. Add a guard:
```tsx
if (rfNodes.length === 0) {
  return <div className="ln-empty-state">Nothing to display.</div>;
}
```

### P2.2 — Inspector: `created_at` timestamp shown as raw ISO string
**File**: `frontend/src/lineage/Inspector.tsx` (line 117)  
**Detail**: `node.created_at` is rendered verbatim (`2026-05-19T00:00:01Z`). Should be formatted as locale date string (`new Date(node.created_at).toLocaleString()`). Low visual polish cost.

### P2.3 — LineageTab: Cmd+J shortcut not scoped to when inspector is open
**File**: `frontend/src/lineage/LineageTab.tsx`  
**Detail**: Cmd+J opens Raw JSON even if no node is selected (no inspector dialog visible). The handler should early-return when `selectedNodeId === null`. Prevents confusing UX where the shortcut appears to do nothing visible.

### P2.4 — NodeTooltip: not keyboard-accessible
**File**: `frontend/src/lineage/NodeTooltip.tsx`  
**Detail**: Tooltip is shown only on pointer hover; screen-reader / keyboard users cannot trigger it. Consider adding `onFocus`/`onBlur` handlers or switching to a `<details>` disclosure pattern.

### P2.5 — folding.ts: `group:dropped-variables` label not localised
**File**: `frontend/src/lineage/folding.ts`  
**Detail**: Hardcoded English strings `"Variables (folded)"` / `"Dropped variables (folded)"`. Move to a constants file to ease i18n later.

## P3 observations (nice-to-have, low priority)

### P3.1 — `dpRegistry.ts` `whyShort` prose is terse for non-technical users
Example: `"y_unique=32"` for model_type. Could be rendered as `"32 unique outcome values"`.

### P3.2 — `buildBranchPath` multi-parent tie-break is lex order
Deterministic but arbitrary. Future improvement: prefer the edge with the earliest `created_at` on the source node.

### P3.3 — `GraphCanvas` dagre `nodesep`/`ranksep` not adjustable
Hard-coded to 40/60. Add user-facing zoom or layout density controls in a future sprint.

### P3.4 — `LineageTab` does not refresh when `runId` prop changes
Fetch effect only runs once on mount. If the parent re-renders with a new `runId` (e.g. navigation within the same route), the graph will not update. Add `runId` to the effect dependency array (currently relies on the router unmounting/remounting the tab, which works for now).

## Process notes

- **Commit hygiene issue**: commit `555dcb6` accidentally swept pre-staged backend index changes into the frontend stream. Fixed via `git reset --hard` + selective cherry-pick + force-push. Root cause: `git commit -a` used while unrelated backend edits were in the working tree. Mitigation: always use explicit `git add <paths>` before committing.
- **Worktree locale**: Chinese path `/项目规划/` caused mojibake in pytest output under `LC_ALL=C`. Fixed with `export LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8 PYTHONIOENCODING=utf-8` in shell profile.
- **Stray `package-lock.json`**: created at repo root by running `npm` outside `frontend/`. Removed; `package-lock.json` lives only under `frontend/`.
