# v1.7.3 Repeated Measures Analysis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver one bounded Repeated Measures Analysis loop based on Linear Mixed Effects: inspect design, create a confirmed run or recovery rerun, validate it, compare source and child, and explain only deterministic facts.

**Architecture:** Integration freezes packet contracts, canonical fixtures, generic model-options transport, and thin registries before any feature lane starts. Agent, Model Pack, UI/UX, and Independent Evaluation then work in separate worktrees from one contract-lock commit. Model Pack owns statistical facts; Agent owns constrained proposals and explanations; UI owns presentation; Evaluation owns acceptance evidence; Integration only wires declarations and resolves mechanical integration work.

**Tech Stack:** Python 3.14, pandas, NumPy, statsmodels 0.14.6 MixedLM already available in the shared virtual environment, FastAPI, React 18, TypeScript, Vitest, pytest, and the existing local browser acceptance workflow. No new public dependency or real LLM/API call is required.

## Scope and locked semantics

This plan implements ADR-PD-001. Writing or approving it does not create a branch/worktree, call a real provider, push, open a PR, merge, tag, or release. Each of those actions needs explicit user authorization at execution time.

The first vertical slice is exactly:

~~~text
repeated-measures source context
→ deterministic design inspection
→ Agent proposal plus PlanDiff
→ user confirmation
→ initial run or child rerun
→ ValidationPacket and DiagnosticPacket
→ one bounded recovery proposal when valid
→ source/child ComparePacket
→ constrained explanation and visible UI state
~~~

| Concern | v1.7.3 rule |
| --- | --- |
| Model type | `linear_mixed_effects` |
| Outcome | one continuous numeric outcome |
| Subject identifier | non-null, at least four subjects after filtering |
| Group | binary and constant within a subject |
| Time | numeric continuous variable |
| Fixed effects | intercept, group, time, group × time, then optional numeric controls sorted by column name |
| Random effects | random intercept; optional random time slope |
| Default fit method | REML |
| Optional method | explicit ML |
| Inference | statsmodels asymptotic Wald z, two-sided 95% normal CI |
| Missing policy | subject null blocks; outcome/group/time/control nulls are complete-case filtered and counted |
| Primary result id | `group_time_interaction` |
| Recovery | only random-slope near-zero/singular diagnostic can propose `random_slope: false` |

The contract must enforce the following:

1. The formula is `outcome ~ C(group, Treatment(reference=reference_group)) * time + controls`, using the existing quoted-term helper for all column names.
2. The reference group is the lexicographically first observed retained group; the result records both group labels.
3. The interaction result has stable id `group_time_interaction` regardless of statsmodels display naming.
4. REML is default; ML is explicit. Every result records the fit method.
5. Different fit methods return restricted comparison with `LMM_FIT_METHOD_DIFFER` for likelihood/AIC-style comparison.
6. Two REML runs with different fixed effects return restricted comparison with `REML_FIXED_EFFECTS_DIFFER`. UI/report never names a winner based on likelihood, AIC, or LRT.
7. Same sample, fixed effects, fit method, and primary target with random-slope removal is target-comparable.
8. Result identity is SHA-256 of dataset fingerprint, analysis unit, outcome, fixed effects, random effects, group/reference group, fit method, missing policy, estimator version, and contract version.
9. Non-convergence is terminally failed for substantive interpretation and yields `LMM_CONVERGENCE_FAILED`.
10. A random-effects covariance matrix is singular when its smallest eigenvalue is less than or equal to `max(1e-8, 1e-6 * largest_eigenvalue)`.

Out of scope: categorical time, more than two groups, random slopes for other covariates, nested/crossed effects, GLMM, arbitrary model selection, custom code, autonomous branching, dataset replacement, broad graph rewrites, a models-platform rewrite, a new browser-test dependency, and a real provider as release gate.

This plan does not reopen or overwrite `docs/superpowers/plans/2026-07-18-v1.7.3-report-ops-closeout.md`. The final release ledger records Report/Operations and Repeated Measures evidence independently; neither work package can be represented as complete merely because the other has evidence.

The public API must contain:

~~~python
class ContractError(ValueError):
    pass


def require_exact_keys(value: Mapping[str, object], required: set[str], name: str) -> None:
    unknown = set(value) - required
    missing = required - set(value)
    if unknown:
        raise ContractError(f"unknown {name} field: " + ", ".join(sorted(unknown)))
    if missing:
        raise ContractError(f"missing {name} field: " + ", ".join(sorted(missing)))


@dataclass(frozen=True)
class PacketEnvelope:
    contract: str
    contract_version: str
    producer_version: str
    payload: Mapping[str, Any]

    def to_dict(self) -> dict[str, Any]:
        return {
            "contract": self.contract,
            "contract_version": self.contract_version,
            "producer_version": self.producer_version,
            "payload": thaw_json(self.payload),
        }

    @classmethod
    def from_dict(cls, value: Mapping[str, Any]) -> "PacketEnvelope":
        require_exact_keys(
            value,
            {"contract", "contract_version", "producer_version", "payload"},
            "envelope",
        )
        return cls(
            contract=value["contract"],
            contract_version=value["contract_version"],
            producer_version=value["producer_version"],
            payload=value["payload"],
        )


@dataclass(frozen=True)
class LmmModelInput:
    subject_id: str
    time: str
    group: str
    fit_method: Literal["reml", "ml"]
    random_slope: bool

    def to_dict(self) -> dict[str, object]:
        return {
            "subject_id": self.subject_id,
            "time": self.time,
            "group": self.group,
            "fit_method": self.fit_method,
            "random_slope": self.random_slope,
        }

    @classmethod
    def from_dict(cls, value: Mapping[str, object]) -> "LmmModelInput":
        require_exact_keys(
            value,
            {"subject_id", "time", "group", "fit_method", "random_slope"},
            "LMM input",
        )
        if any(type(value[key]) is not str or not value[key] for key in ("subject_id", "time", "group")):
            raise ContractError("subject_id, time, and group must be non-empty strings")
        if value["fit_method"] not in {"reml", "ml"}:
            raise ContractError("fit_method must be reml or ml")
        if type(value["random_slope"]) is not bool:
            raise ContractError("random_slope must be a bool")
        return cls(
            subject_id=value["subject_id"],
            time=value["time"],
            group=value["group"],
            fit_method=value["fit_method"],
            random_slope=value["random_slope"],
        )


@dataclass(frozen=True)
class LmmDiagnostic:
    code: str
    severity: Literal["info", "warning", "error"]
    status: Literal["complete", "blocked", "failed"]
    evidence: Mapping[str, object]
    action_candidate: Mapping[str, object] | None

    def to_dict(self) -> dict[str, object]:
        return {
            "code": self.code,
            "severity": self.severity,
            "status": self.status,
            "evidence": thaw_json(freeze_json(self.evidence, "evidence")),
            "action_candidate": (
                thaw_json(freeze_json(self.action_candidate, "action_candidate"))
                if self.action_candidate is not None
                else None
            ),
        }


def build_lmm_result_identity(value: Mapping[str, object]) -> str:
    require_exact_keys(
        value,
        {
            "dataset_fingerprint",
            "analysis_unit",
            "outcome",
            "fixed_effects",
            "random_effects",
            "group",
            "reference_group",
            "fit_method",
            "missing_policy",
            "estimator_version",
            "contract_version",
        },
        "LMM result identity",
    )
    return sha256_canonical(dict(value))
~~~

- [ ] **Step 4: Implement input validation and canonical formula**

`prepare_lmm_input` must:

1. parse `ctx.artifacts["_model_options"]` through `LmmModelInput.from_dict`;
2. block an absent/null subject id, non-numeric time, non-binary group, group varying within subject, fewer than four subjects, and fewer than two retained rows for any subject;
3. complete-case filter only outcome, time, group, and selected controls;
4. retain one exclusion count per filtered column;
5. sort controls lexicographically;
6. return a record containing frame, input, reference_group, comparison_group, exclusion_counts, fixed_effects, random_effects, and primary_result_id.

Use this formula builder:

~~~python
from collections.abc import Sequence


def build_lmm_formula(
    *,
    outcome: str,
    group: str,
    time: str,
    reference_group: str,
    controls: Sequence[str],
) -> str:
    quoted_outcome = f"Q({outcome!r})"
    quoted_group = f"Q({group!r})"
    quoted_time = f"Q({time!r})"
    terms = [
        f"C({quoted_group}, Treatment(reference={reference_group!r})) * {quoted_time}"
    ]
    terms.extend(f"Q({control!r})" for control in controls)
    return f"{quoted_outcome} ~ " + " + ".join(terms)
~~~
