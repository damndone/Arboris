# Workbench v1.8.6 Full Scope Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven development for independent lanes, or execute this plan inline with review checkpoints. Every implementation step is test-first and must remain inside the owning formal development line.

**Goal:** Deliver the user-approved v1.8.6 scope expansion as a user-reachable research workbench: predictive correctness foundation, typed data operations, explicit weights, statistical evidence, new model families, labels, and their Graph/Report/Table/Agent consumers.

**Architecture:** Preserve the released v1.8.5 estimator behavior behind an append-only registry. Add typed packets and content-addressed identities at the shared boundary, then expose each capability through the existing Run, Graph, Report, Table, and Agent surfaces. Every new family and weight semantic is admitted by an explicit contract; unsupported combinations fail before result artifacts are written.

**Tech Stack:** Python 3, FastAPI, pandas, scipy, statsmodels, scikit-learn, React/TypeScript, pytest, Vitest, existing Graph/Artifact/Agent contracts, formal `scripts/devline_control.py`, and host-level `scripts/gate.sh`.
