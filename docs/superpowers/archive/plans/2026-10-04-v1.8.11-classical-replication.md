# ARMA–GARCH Classical Replication Implementation Plan

**Goal:** Add an explicit classical replication scope alongside frozen train/validation, preserving the approved numerical gates and diagnostic limitations.

**Architecture:** Declare validation.evaluation_mode = train_validation (default) or classical_replication. Freeze tail membership in both modes. A copied estimation_view determines candidate fitting, final estimation, diagnostics and in-sample chart alignment. Classical mode uses the full transformed sample for these, but each tail forecast reestimates using strictly earlier observations. Full-sample selection makes classic rolling results retrospective, so reports and Agent evidence disclose overlap rather than claim independent validation. Refitting cadence must be one in classic mode; an incompatible explicit cadence is rejected.
