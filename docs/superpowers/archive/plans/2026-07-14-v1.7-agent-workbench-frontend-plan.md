# Agent Workbench Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a durable, visible Agent workflow inside Workbench and repair the four live smoke failures.

**Architecture:** Add a narrow HTTP adapter over the existing AgentCore, then share one React AgentSurfaceProvider between a Graph composer and the bottom Agent panel. Keep context advisory and bounded; keep all mutation authority in the existing typed proposal/rerun executor.

**Tech Stack:** FastAPI, Pydantic, existing AgentCore/OpenAI-compatible adapter, React 18, TypeScript, Vitest, pytest.
