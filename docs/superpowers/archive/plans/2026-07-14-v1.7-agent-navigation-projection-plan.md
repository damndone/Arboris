# Agent Navigation Projection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (\`- [ ]\`) syntax for tracking.

**Goal:** Make Main/Chain/fork, Agent messages, graph nodes, child runs, and operation records mutually navigable through one backend-authoritative typed projection.

**Architecture:** Add a read-only \`backend/workbench/agent/navigation.py\` resolver that derives typed links from the existing session, chain, fork, proposal, operation, and graph context stores. Expose scoped projection routes, then let the Workbench route container own one URL/navigation adapter used by AgentPanel and graph actions. No new state database or execution path is introduced.

**Tech Stack:** Python 3.14, FastAPI, pytest, React 18, TypeScript, Vitest, existing Workbench URL schema and AgentSurfaceContext.

- [x] **Step 3: Implement the minimal read-only resolver**

Expose these stable public shapes. The constructor receives the actual project
root, derives `project_root / "workbench"` for Agent stores, and uses
`project_root / "runs"` for graph/run validation:

~~~python
@dataclass(frozen=True)
class AgentNavigationRef:
    kind: str
    id: str
    label: str
    relation: str
    available: bool
    href: dict[str, str]
    reason: str | None = None

@dataclass(frozen=True)
class AgentNavigationProjection:
    subject: AgentNavigationRef
    links: tuple[AgentNavigationRef, ...]
    last_event_seq: int

class AgentNavigationProjector:
    def __init__(self, project_root: Path | str): ...
    def session(self, session_id: str) -> AgentNavigationProjection: ...
    def operation(self, record_id: str) -> AgentNavigationProjection: ...
    def graph(self, *, run_id: str, node_ref: str | None,
              forest_node_key: str | None) -> AgentNavigationProjection: ...
~~~

Validate each available target against the current project root and existing
record scope. Never write a navigation index, call an LLM, execute a run, or
infer relationships from message text.
