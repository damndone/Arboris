**Goal:** 让用户与 Agent 能安全地发现、理解、预览、组合、修改和复现数据，并让后端已有数据操作通过通用 UI/Notebook/Agent 入口真正可消费。

**Architecture:** 从 C1 消费 locked contracts/catalog；数据集和 metadata 是有 identity/provenance 的 immutable artifact。操作由 package-local manifest/provider 声明输入角色、typed options、preview、effect 和 output port，UI component 根据 schema 生成通用编辑器；所有 mutation 走 preview → confirmation → child node → lineage → reload。data-owned 模块只贡献 sensitivity-aware ContextEgress policy/selector；Agent Compiler 已建立不可绕过的 C0 gateway，Notebook、central registry 和 UI mount 由 Cutover 单一接线。

**Tech Stack:** Python 3.14、pandas、FastAPI、Workbench data operations/Graph/artifacts、React、TypeScript、Vitest、pytest。
