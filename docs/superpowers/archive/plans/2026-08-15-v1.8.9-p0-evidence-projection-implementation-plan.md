**Goal:** 为所有当前能力建立共同、可追溯、fail-closed 的 evidence registry/projection kernel；外部 Agent、Notebook、UI、Report consumer 接线由独立 Consumer Projection plan 完成。

**Architecture:** 从 Contract Lock C0 消费只读 Evidence、PersistencePort、status 和 ContractRef schemas；保留各 family 现有 result payload/validator。Evidence core 建立 registry、artifact admission、projection kernel 和 immutable envelope persistence implementation，并发布 package-local lifecycle/provider declaration；本线不修改 workflow runtime、services、Agent/Notebook/Report/frontend 或 Manifest-derived coverage。

**Tech Stack:** Python 3.14、JSON contracts、artifact index/SHA-256、pytest、formal devline control。

- [ ] **Step 2: implement pipeline**

```text
ArtifactRef
→ index/digest/identity admission
→ resolve result contract and family validator
→ validate original payload without rewriting it
→ resolve EvidenceProjectionDeclaration
→ emit EvidenceEnvelopeV1 + family_payload_ref
```

Kernel 不保存或改写原始 artifact、不改 workflow state、不调用 consumer、不重新估计数字；它只产生待事务提交的 version-pinned envelope。

## Task 4: transactional immutable envelope persistence

- [ ] **Step 1: write persistence failure tests**

- [ ] **Step 2: implement the C0 persistence port**

严格执行：admitted artifact → family validator → projection → transactional immutable envelope commit → artifact/envelope/projector digest binding。相同输入和 idempotency key 返回同一 binding；任何不同 payload/digest 冲突 fail closed。旧 envelope 永不原位覆盖，只能产生 superseding ref。
