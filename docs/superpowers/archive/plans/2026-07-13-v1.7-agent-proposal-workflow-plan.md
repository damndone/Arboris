# v1.7 Agent Proposal Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the first verifiable Workbench Agent workflow from Main→Chain dispatch through an allowlisted tool call that creates a confirmation-gated Proposal without creating a run or operation mutation.

**Architecture:** Keep `AgentCore` provider-neutral. Add an explicit tool-runtime attachment point and per-command tool metadata, then let `WorkbenchOrchestrator` attach its existing chain-scoped `ToolRegistry` during registration. The registry enforces the command's allowed operation set and carries `command_id` into the existing Proposal/session/event stores.

**Tech Stack:** Python 3.14, asyncio, pytest, JSONL session/event/proposal stores, JSON Schema validation.
