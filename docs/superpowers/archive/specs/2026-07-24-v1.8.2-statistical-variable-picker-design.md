# v1.8.2 Statistical Exploration Variable Picker

## Goal

Replace the long vertical list of checked variable checkboxes in the Raw Data
node's Statistical exploration section with a compact, searchable multi-select
control. The control must preserve the existing `selectedColumns` request
semantics and keep the raw node immutable.

## Selected approach

Use a compact popover-style disclosure control (option A from the visual
comparison):

- The collapsed state shows `Variables` and a concise selection summary such
  as `18 variables selected`.
- Clicking the summary expands the selector in place without navigating away
  from the Statistical exploration section.
- The expanded state contains a search field, `All` and `Clear` actions, and a
  scrollable variable list with checkboxes.
- Search filters only the visible list; it never changes the underlying
  selection. `All` selects all variables matching the current search, while
  `Clear` clears all variables matching the current search. With an empty
  search, these actions apply to all source columns.
- The summary reports the total selected count, not only the filtered count,
  so users do not lose track of hidden selections.

## Component and state boundaries

Add a focused `StatisticalVariablePicker` presentational component under the
lineage detail sections. It receives:

- the ordered source columns;
- the current selected column names;
- an `onChange` callback for the next selected names.

The picker owns only transient UI state: expanded/collapsed state and the
search query. The parent continues to own `selectedColumns`, clears the
preview whenever the selection changes, and builds the existing typed
exploration request. No backend contract, artifact schema, graph state, or
model execution flow changes.

## Interaction details

- The disclosure control is a real button with an accessible name describing
  the current selection count.
- The search input has an explicit label and matches variable names
  case-insensitively.
- Each variable remains a native checkbox with its current name and checked
  state.
- The list is constrained in height and scrolls internally, preventing 18+
  variables from pushing filters and Preview below the fold.
- Selecting or clearing variables keeps the picker open and invalidates the
  existing preview exactly as the current checkbox implementation does.
- Empty search results show a short `No variables match` message.
- The picker closes only when the user clicks the disclosure button again; it
  does not close unexpectedly when a checkbox or bulk action is used.

## Visual and accessibility intent

Use the existing Workbench surface tokens and control styling. The compact
summary should read as a control rather than a heading, with a clear expanded
state indicator. The expanded list should have enough contrast and spacing for
keyboard use, visible focus, and reliable checkbox targeting. The control must
work in both light and dark themes without introducing a new color system.

## Tests and acceptance

Add component tests covering:

1. collapsed summary displays the selected count and does not render the full
   checkbox list;
2. opening the picker exposes search, `All`, `Clear`, and the variable list;
3. case-insensitive search narrows visible variables without changing hidden
   selections;
4. bulk actions affect only matching variables, including the empty-search
   all-variable case;
5. changing a checkbox preserves the parent's selected-column request and
   invalidates the preview.

Run the focused Statistical exploration tests, frontend TypeScript checking,
and an in-app browser smoke on the Raw Data node with the 18-column
`newschool9816` dataset. The browser check must show that the collapsed panel
is compact, the expanded picker is usable, and Preview remains reachable.

## Non-goals

- No change to statistical operation behavior or backend payloads.
- No replacement of native checkbox semantics with a custom selection model.
- No persistence of the picker open state or search query in the Graph URL.
- No redesign of filters, grouping, OLS handoff, or Table output in this
  slice.
