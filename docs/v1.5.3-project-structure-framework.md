### 已有基础能力（继承自 V1.5.0-V1.5.2）

- 项目创建、单次运行、批量 y 运行、上传 CSV/Excel、sheet 选择、转置预览、自动推荐 y/x。
- 后端工作流：ingestion → schema → cleaning → profiling → validation → routing → y 类型检测 → 统计检验 → 估计 → diagnostics → visualization/report/export。
- 模型：OLS、Logit、Poisson；Fixed Effects 和 time-series diagnostics 处于部分支持。
- 统计检验：Pearson pairwise、Welch t-test、ANOVA、Chi-square。
- 产物系统：manifest、environment、decisions/errors、artifacts index、HTML/PDF/XLSX、figures/tables/model results。
- FastAPI 运行接口、历史记录、产物下载、HTML report、graph、SSE events。
- Lineage graph 后端：schema v3、GraphStore、GraphRecorder、DecisionPoint、stage/trust/review 元数据。
- 前端 workbench shell：Graph/Table/Pipeline 三视图框架、RunHistoryRail、DetailDrawer、BottomPanel、ContextMenu、SearchPalette、RawJsonModal。
- registry 机制：sectionRegistry、actionRegistry、bottomPanelRegistry。
- 图谱 UI：React Flow + dagre 布局、折叠变量组、hover tooltip、stage legend、review 状态、5 级高亮、上游 focus。

## 5. 运行时层级与数据流

```text
用户
  ├─ CLI: workbench create/run
  └─ Web UI: SubmitRoute
        ↓
FastAPI api.py
  ├─ POST /projects
  ├─ POST /runs / POST /runs/batch
  ├─ GET /runs / /runs/{id}
  ├─ GET /runs/{id}/artifacts / report
  ├─ GET /runs/{id}/graph
  └─ GET /runs/{id}/events
        ↓
orchestrator.py
  ingest → clean → profile → validate → route → model → diagnostics → report/export
        ↓
run directory artifacts
  run_manifest.json / environment.json / errors.json / artifacts_index.json
  processed/ / staged/ / model_results/ / reports/ / figures/ / tables/
        ↓
graph_recorder.py → graph_store.py → graph.json
        ↓
frontend api.ts → graphAdapter.ts → GraphViewModel
        ↓
WorkbenchRouteContainer
  WorkbenchStateProvider + LineageContext.Provider
        ↓
Topbar + RunHistoryRail + WorkbenchMain(Graph/Table/Pipeline) + DetailDrawer + BottomPanel + portals
```

## 6. 状态层级

| 层 | 存储 | 字段/内容 | 位置 |
| --- | --- | --- | --- |
| Tier 1 | URL search params | `view/tabs/active/q/panel/panelOpen/focus/pinned` | `workbench/state/urlSchema.ts`、`tabsSchema.ts`、`WorkbenchStateProvider.tsx` |
| Tier 2 | sessionStorage by runId | layout、viewport、expanded groups、splitter、legacy hint dismissal | `workbench/state/useSessionByRunId.ts`、`lineage/graph/useLayoutMode.ts`、`GraphView.tsx` |
| Tier 3 | React memory | hover、search cursor、context menu | `WorkbenchStateProvider.tsx` |

当前注意点：`useTabs.ts` 仍是旧 URL writer，`useSelectedNode.ts` 仍消费 `useTabs()`；这正是 V1.5.3 计划 F2 要退役的债。
