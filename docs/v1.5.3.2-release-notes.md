# V1.5.3.2 — Integration Release Notes

> **性质：集成版（integration release），不新增功能。**
> 把后端线 `codex/workbench-v1.5.3.1` 的统计/ML 扩展，叠加到已收官的前端
> 地基版 `workbench-v1.5.3` 之上。本版的目的是**证明叠加后无破坏**，不是展示新功能。
>
> 分支：`workbench-v1.5.3.2`（独立 worktree + 独立 venv，base = `workbench-v1.5.3`）。
> 三版 v1.5.3 / v1.5.3.1 / v1.5.3.2 各自独立，互不写回。

---

## 1. 叠加进来的后端能力（来自 1.5.3.1）

- **显式 `model_type` 路由**：`probit` / `negative_binomial` / `glm:<family>` / `panel_ols`，
  在 y-type auto 路由之前判定。
- **扩展统计检验**（`statistical_tests.py`）。
- **MICE 缺失值插补**（`config.imputation_method == "mice"`，统计检验后、估计前）。
- **预测模型**（`config.prediction_enabled`，诊断后；lasso / ridge / random_forest）。
- **Optional extras**：`panel`(linearmodels) / `ml`(scikit-learn) / `imbalanced`(imbalanced-learn) /
  `imputation`(statsmodels)，全部 **lazy import**。
- **结构化失败**：显式模型拟合失败写 `MODEL_FIT_FAILED`（含 engine/model_type/model_id/step），
  缺 optional 依赖写 `OptionalDependencyNotInstalled` —— 不抛裸 traceback。

## 2. 关键合并决策（orchestrator.py）

`_run_workflow` 是工作流总线，v1.5.x 与 1.5.3.1 各自在其中加了东西，合并时**两边都保留**：

- **保留 v1.5.x 血缘记录**：`GraphRecorder` / `_model_summary` / `_robust_se_dp` /
  `_model_type_dp` / decision-point，全部完整保留。
- **保留 1.5.3.1 模型路由**：显式 model_type 分支插在 auto 路由**之前**；`auto` 行为字节不变。
- **`_MODEL_TYPE_MAP`**：`probit→binary`、`negative_binomial→count`、`panel_ols→continuous`；
  **不给 `glm:*` 建映射**——显式 glm 的 y_type 回退到数据驱动的 `data_detected_y_type`，保持数据驱动。
- **§4.6 行为变更（重要）**：**显式** model_type 拟合失败 → 写结构化 `MODEL_FIT_FAILED` 并返回
  `status="failed"`，**不再 silent fallback 到 OLS**。`auto` 模式仍保留 OLS 兜底。
  - 这**取代**了 v1.5.x 旧行为（显式 poisson 失败时悄悄回退 OLS）。原 v1.5.x 测试
    `test_model_fit_failed_fallback_clears_model_type_dp` 已重写为新契约
    （`test_explicit_model_fit_failure_does_not_silently_fall_back_to_ols`）。
- `cli.py`：透传 `--model-type`，同时保留 v1.5.x 的「stdout=run_id / stderr=lineage URL」契约。
