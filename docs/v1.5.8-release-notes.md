# Workbench v1.5.8 — Sun-Abraham estimator-slot validation

**DID Layer 3c.** Adds a minimal, faithful Sun-Abraham (SA) interaction-weighted
event-study estimator (`sa_did`) and, in doing so, **validates the v1.5.6 "swap the
estimator slot" architecture bet**: that any estimator producing an
`EffectEstimateBundle` of the same shape as Callaway-Sant'Anna (CS) inherits the entire
downstream — aggregation, simultaneous sup-t bands, and honest-DID (ΔRM **and** ΔSD/FLCI) —
for free.

## What shipped

- **A self-implemented saturated SA estimator** (`engine/sa_attgt.py`): saturated two-way
  fixed-effects within-OLS (`y ~ unit FE + time FE + cohort×event-time interactions`,
  reference event time −1), with an analytic influence function. Entity- and time-FE are
  absorbed via alternating within transforms over **observed rows only** (never padded);
  the saturated interaction block is reduced by a natural-order sequential
  collinearity removal that reproduces `fixest`'s own column-drop set exactly. CATT(g,e)
  are the surviving interaction coefficients; zero-support and collinear cells are recorded
  in diagnostics and never enter the estimates/IF/aggregation.
- **The same `EffectEstimateBundle`** CS emits → reuses `cs_aggregate` (simple / dynamic /
  group / calendar + multiplier-bootstrap sup-t bands), `cs_inference`, and the honest-DID
  adapter (ΔRM + the v1.5.7.1 ΔSD/FLCI) **unchanged**.
- **`sa_did` as an explicit-only model type**, wired end-to-end through the run form,
  workflow, estimation stage, diagnostics (`sa_did.json` artifact), capabilities manifest,
  and a shared results card. Reuses the CS run-form controls and event-study card (the card
  labels itself "Sun-Abraham" for SA runs).

## The architectural result (the point of this version)

The `EffectEstimateBundle` is the clean seam the architecture claimed. CS and SA now both
route their downstream through one **estimator-agnostic `_finalize_did_bundle`** (att_gt
table, four aggregations + bands, warnings, metadata, honest-DID, serialization). This is a
**behavior-frozen refactor**: CS routed through the shared helper is **golden 0-drift**
(proven — no golden file changed). An **anti-fork guard test** asserts
`_finalize_did_bundle`'s source contains no estimator branch (no `estimator ==`, no
`"cs"`/`"sa"` literal), so the seam cannot silently grow estimator-specific logic. All
estimator-specific work lives in `sa_attgt` / `cs_attgt`; everything past the bundle is
uniform. **The bet holds.**

## Validation (oracle = `fixest::sunab`)

All comparisons use the locked small-sample setting `ssc(adj = FALSE, cluster.adj = FALSE)`
(a bare sandwich, matching our influence-function vcov bare-to-bare), and join on the
canonical `(g, e)` key — never array position. The R oracle is committed JSON; the test
suite never invokes R.

- **CATT coefficients** β_{g,e} vs `sunab`: matched to **~5e-14** (gate 1e-8), on balanced,
  unbalanced, and a zero-support/collinear panel.
- **Cluster vcov reconstructed from the influence function** equals `sunab`'s bare cluster
  vcov (diagonal **and** full off-diagonals) to **~5e-13** (gate 1e-6) — this is the
  honest-DID "free inheritance" linchpin: the IF is scaled (`φ = N · (D̃'D̃)⁺ Σ_t D̃ε̂`,
  never-treated rows zero) so `cs_aggregate`'s SE path and the honest-DID Σ reproduce the
  bare cluster sandwich.
- **Balanced dynamic aggregation** vs `sunab`'s aggregated event study: matched to
  **~4e-14** (gate 1e-6) — confirming that, on a balanced common-support panel, the reused
  `n_g` weighting equals `sunab`'s observed-count weighting.
- **Unbalanced aggregation:** characterized, not aligned. `sunab` weights the event-study
  path by observed counts per relative period (`N_{g,e}`); Workbench keeps `did`-style
  `n_g` weighting (consistent with the shipped CS path) and attaches a **qualitative**
  `interpretation_restrictions` note on unbalanced panels (no quantified figure). The
  per-(g,e) coefficients, vcov, and honest-DID inputs remain exact regardless of balance.
- **honest-DID chain:** SA's dynamic aggregation feeds ΔRM + ΔSD/FLCI, runs finite and
  deterministic, and is frozen in an additive golden — **inherited free**, no SA-specific
  honest code.
- **Collinearity / empty cells:** a zero-support cohort×period is recorded in
  `dropped_cells`, absent from the estimates, and the run completes.

## Notes

- **Zero new Python dependencies** (NumPy/SciPy only). The R package `fixest` is used once,
  offline, to generate the committed oracle fixtures; the suite never calls R.
- **Gate:** backend full suite + golden 0-drift (20 existing + 2 new `sa_did` goldens) +
  frontend vitest + `tsc --noEmit` 0 errors — all green.

## Deferred

DR / IPW / covariate double-robustness (CS's strength; classic SA is uncovariated);
a SA-faithful observed-period unbalanced aggregation (characterized here, built later only
if needed); flexible relative-time binning and alternative reference-period strategies;
user-chosen `l_vec` honest-DID target selection; any large SA-specific UI; new honest-DID
methods.
