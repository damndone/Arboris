- `__init__.py`（400 行）— 薄驱动核心（run_workflow / _run_workflow / run_batch_y_workflow /

## 为什么安全
- helper 逐字搬运（函数体一字不改）+ 显式 re-export → `workbench.orchestrator.*` 命名空间不变。
- stage 懒加载导入、api/cli 导入、所有 monkeypatch 零改动。
- 子模块只做同级 import，绝不反向 import 包（无初始化循环）。
- 每簇一道 `./scripts/gate.sh` 全量门禁，golden 0-drift。
- 新增 `tests/test_orchestrator_namespace.py` 钉死命名空间，防将来再导出漂移。
