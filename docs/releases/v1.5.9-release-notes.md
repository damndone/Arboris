# Workbench v1.5.9 — de Chaisemartin–D'Haultfœuille (dCDH) DID

**DID Layer 3, final piece.** Adds `model_type="dcdh"` — a dynamic DID estimator for
**binary non-absorbing (switching) treatment**, the one DID design CS (v1.5.6) and SA
(v1.5.8) cannot handle (both require absorbing adoption).

## What shipped

- **New estimator** `engine/dcdh_estimator.py` — self-implemented long-difference
  `DID_ℓ` dynamic effects + symmetric placebos + analytic cluster-robust influence
  function. Binary, non-absorbing, "first-up switchers" sample, `same_switchers=TRUE`.
- **New narrow contract** `engine/event_study.py::EventStudyBundle` — a cross-estimator
  event-study seam (`event_times` sole axis, `labels` derived). dCDH **breaks** the
  `(g,t)` `EffectEstimateBundle`; it reuses only `multiplier_bootstrap` (sup-t bands).
- **New input model** `engine/dcdh_spec.py::normalize_treatment_path` — a per-(unit,period)
  treatment-path model (`did_treatment_path`), separate from the cohort-based `did_spec`
  (untouched).
- **`run_dcdh`** assembles `dcdh.json` (event study + experimental overall ATT +
  diagnostics); does NOT touch `_finalize_did_bundle` (CS/SA golden 0-drift).
- **No Honest-DID** for dCDH — placebos are its native pre-trend device
  (`honest_did_supported: false`).
- Frontend: `DCDHControls` + `DCDHResultCard` (Honest-DID block suppressed).
- Capabilities: `dcdh` (group "DID", `requires:["entity","time","treatment_path"]`,
  additive — no schema bump).

## Validation (graded, achieved)

Element-wise vs R `DIDmultiplegtDYN` 2.3.4 (`same_switchers=TRUE`, cluster ~id), across
3 fixtures (non-absorbing w/ switch-backs, baseline=1 exclusion, placebo≈0):

| quantity | target | achieved |
|---|---|---|
| point estimates (effects + placebos) | 1e-6 | ~1e-16 |
| per-ℓ SE reconstructed from IF | 1e-6 (1e-4 fallback) | ~1e-16 (no gap) |
| IF columns mean-zero | 1e-6 | ~1e-15 |

The per-ℓ SE match required a within-cell **Bessel `sqrt(n/(n-1))`** correction (DYN's
finite-sample口径). See `docs/v1.5.9-IMPL-NOTES.md`.

## Deferred

Continuous/multi-valued treatment; covariates; baseline=1 / `1→0` exit effects;
direction-specific event study; irregular time grids. Overall ATT is `experimental`
pending final weighting alignment.

## Dependencies

calls R): `DIDmultiplegtDYN` 2.3.4 + `polars` (from `rpolars.r-universe.dev`, must be
`library()`-loaded before `did_multiplegt_dyn`).
