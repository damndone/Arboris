# V1.7.2 — Agent Analysis Loop

**Theme:** 让 Agent 围绕一个已完成的 OLS source run，完成可审计的检查、诊断、计划、确认、child rerun、验证、比较和解释闭环。

**Branch:** `workbench-v1.7.2`（基于 `f0707f1`）

## What shipped

### Deterministic OLS Analysis Loop

- source contract、exact comparison target、cluster preflight 和 `ols.use_clustered_covariance_v1` recovery action；
- 产品字段 `cluster_variable` 到 OLS wire 字段 `entity_col` 的显式映射；cluster 列不会进入公式、X、样本或 point estimate；
- canonical payload/hash、dataset/sample/point/inference fingerprints 和 OLS result contract；
- `PlanDiff`、`ValidationPacket`、`ComparePacket` 和 primary-target `ConclusionClassification`；
- confirmation 后复用既有 proposal → claim → lease → execute → effect → commit → projection → reconcile 生命周期；
- immutable packet、logical-key 幂等、projection pending、infra recovery 和 semantic repair 证据；
- Agent 只提交不可信 intent、读取后端结构化事实并解释，不自行计算 diff、选择 target、猜 cluster variable、确认或执行。

### Report and diagnostic contract repairs

- 报告 packet 纳入受控的 figure inventory 和数值 source；DeepSeek 报告必须引用事实和全部 supplied figure marker，非法响应 fail closed，并最多进行一次契约纠正重试；
- 补齐 `event_study`、`time_trend` 的 figure AI context；
- Figure Ask-AI 使用现有 Markdown renderer；
- 新增无运行时依赖的 HTML、LaTeX、Word 和 print-oriented PDF 导出路径，图表从 run-owned artifacts 安全解析和嵌入；LaTeX 只生成 `.tex`/figure 包，不负责服务端编译，`pdf-print` 是打印样式路径而不是假装服务端 PDF 渲染；
- 报告诊断状态、Agent bounded diagnostics 和 artifact 索引保持一致。

### Run reliability and lineage consistency

- run 列表会识别后端重启后遗留的 dead `running` run 并显示 `interrupted`；
- 后台运行支持持久化 heartbeat、协作式取消和配置化超时，超时/取消会 terminalize 并释放运行槽位；
- CS/SA-DiD diagnostics、omitted-cell/single-cohort warning 和变量角色投影保持结构化、一致且可见；
- 阶段 timing witness 覆盖 NodeOperationContext、PlanDiff、ValidationPacket、ComparePacket 和 terminal observation。

## Explicit boundaries and deferred work

- 本版本只承诺 OLS conventional/unadjusted source 到 clustered covariance child 的单 child golden flow；不扩展到任意模型参数、数据清洗、custom code 或多 child 自治分支；
- Agent 不拥有状态，不绕过用户 confirmation，也不调用未注册 operation；
- real-provider E2E、honest-DiD 性能优化、真正的服务端 PDF 渲染和 sandbox 缓存/复用不作为本版本 gate 或性能承诺；
- v1.7.3 的后续修订（包括额外的 provider shorthand 和 timeout 独立回归覆盖）不回写到本版本。

Python package metadata 继续遵循仓库既有约定保持 `0.1.0`；`v1.7.2` 是 Workbench release 标识。
