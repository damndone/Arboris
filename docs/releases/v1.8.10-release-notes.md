## 版本定位

v1.8.10 是扩展地基。能力改为按“性质”声明、像积木一样组合，并且都能用自然语言调用：

- 每个结果带完整的推断核心（参数、协方差、参考分布与自由度），Agent、报告、表格、Notebook 读同一份；
- 后估计、前提检查、标准误、组合子按性质匹配，不按模型族名字写死；
- 新模型族必须带齐对照、信封、台账和真机评测才能合入；
- 补上多重插补合并、Newey–West 标准误、按组分别执行三个日常缺口。

## 新增与改进

### 结果与推断

- **结果信封与推断核心**：参数向量、协方差矩阵（≤ 300 个参数时全存，约 1.7 MB；更多时只存关注参数并写明限制）、
  参考分布与自由度、对数似然、`predict` 声明、估计样本指纹。消费者统一数字格式（0.993、p < 0.001）。
- **推断引擎 v2**：稳健 OLS 用 t(N−K)，聚类用 t(G−1)，与 Stata 一致；旧结果不覆盖，界面与 Agent 标为旧版 z。
- **后估计**：Wald、LR、lincom、nlcom、平均边际效应与均值处边际效应都读推断核心，不重拟合。
  首批开放 OLS、logit、probit、Poisson，每个“族 × 操作”都有 R 对照（`car`、`marginaleffects`、`lmtest`）。
  不适用时明确拒绝并说明原因（例如稳健标准误下的 LR）；没有对照的组合回答“尚无对照数据，暂不开放”。

### 检查库与准入

- 模型族声明性质（封闭词表）；检查、后估计、标准误、组合子按性质匹配，共享代码不写族名（lint 测试）。
- 检查库：共线性改用 GVIF（设计矩阵上计算）；新增完全拟合检查（不显示 p 值）；分离检查改用线性规划判定，
  扩展到 probit 等二元结局；IV 第一阶段 F 低于 104.7 时自动附 Anderson–Rubin 区间。对照 R `car::vif`、
  `detectseparation`、`ivmodel`。
- 准入套件：声明、对照（R/Stata 或模拟参数找回）、信封、台账、真机评测五项；20 个族的缺口清单见第 3 步计划附录。

### 组合子与标准误

- **多重插补合并**：m 份插补分别拟合，Rubin 规则合并，Barnard–Rubin 小样本自由度，报告缺失信息比例与相对方差增量；
  只开放对过 R `mice::pool` 的组合（OLS 普通/稳健/聚类、logit）。合并结果不显示单份数据的 R² 和残差；
  合并结果上的后估计（需要 D1）、与抽样设计或按组执行同用，都明确拒绝。
- **Newey–West（HAC）**：OLS 可用，Bartlett 核，滞后阶数可指定或按 ⌊4(T/100)^{2/9}⌋；需要声明时间顺序列，
  有时间缺口或与聚类同用时拒绝。与 Stata `newey`、R `sandwich::NeweyWest` 一致。
- **按组执行**：模型（OLS、logit、probit、Poisson）与检验（t 检验、卡方、相关、描述统计）可按某列分组分别运行；
  缺失值自成一组，样本不足的组写明原因，最多 50 组；抽样设计下按域估计（与 Stata `svy, subpop()` 一致）。
  组间差异用完全交互模型的 Wald 检验，跨组 Holm/BH 校正，每组的检验计入台账与报告披露；
  Agent 说组间“不同”之前必须引用这项检验，由数字核对执行。每个开放的能力都通过“等于先筛选再单独运行”的不变性测试。
- **抽样设计自由度**：系数 t 检验与区间默认用设计自由度（PSU 数 − 层数），联合检验用 Korn–Graubard 调整的 F，
  与 Stata `svy` 逐项一致；可选 R `survey` 惯例（`survey_df: design_minus_p`）。所用惯例记入结果、推断核心与报告。

### Agent

- **焦点上下文**：Agent 作用于用户正在看的对象。Data 页上作用于正在查看的数据集；图上选中别的运行的节点时，
  作用于那个运行。不再出现“只读的项目级 Agent 无法运行分析”的死路。
- 新字段可用自然语言调用：`model.genesis` 的 `by_group`、`multiple_imputations`、HAC 选项、抽样设计自由度；
  `postestimation.*` 只读步骤当场出结果。

### 修复的既有问题（部分从 v1.8.7 起就存在）

- 声明子总体时，系数是全样本的而标准误是子总体的（对 Stata：0.5992 对 0.9150）；R² 等也来自全样本。
- 抽样设计结果在表格视图和 Agent 中被描述为“HC1、t(N−K)”，与实际显示的设计标准误不符。
- 报告证据表显示 16 位小数和 p = 0。
- 选中别的运行的节点时，Agent 仍作用于当前运行的头节点。
- 单独运行 `tests/test_engine_capabilities.py` 时的循环导入。

## 已知限制与延后

- 后估计目前只对 OLS、logit、probit、Poisson 开放；IV、面板、DID、混合效应、GLM 族的对照数据已由 Codex 准备
  （分支 `eval/v1811-admission-oracles`），在 v1.8.11 接入。负二项 GLM 的收敛精度与固定离散参数、面板与 DID
  推断核心缺少协方差声明，同在 v1.8.11 处理。
- 真机评测发现：Agent 不能在一个方案里“先拟合模型、再对新模型做检验”；改变标准误类型时没有说明原因。
- 合并结果上的后估计（D1）、HAC 与聚类同用（Driscoll–Kraay）、其他族的 HAC、多重插补与抽样设计或按组执行同用。
- 方案、报告两种焦点已登记但还没有页面声明；空白画布上的项目 Agent 仍是只读。
- 完整协方差的上限从计划的 500 个参数降到 300（500 个参数约 4.8 MB，超出 2 MB 预算）。
