# Workbench v1.8.6 — 候选发布说明

> 状态：开发线候选版本，尚未 push、合并、打 tag 或发布。以下内容只描述已实现并有本地测试证据的能力。

## 相较 v1.8.5 的主要变化

- **预测研究正确性基础。** 预测流程现在使用显式的 SplitPlan、最终 holdout、baseline、负对照和证据投影；未知数据结构、未声明的 split/权重语义不会静默回退到旧的随机切分路径。
- **四类新模型族。** 普通 Run、Genesis 和 Agent 可达 `ordinal_logit`、`multinomial_logit`、`survival_cox`、`quantile_regression`。结果包含与模型族对应的概率/比值比/相对风险比、边际效应、生存曲线与 log-rank、分位数与跨分位数比较等证据；缺少生存事件列等必要输入会明确拒绝。
- **统计检验补完并接入普通流程。** Cohen's d、单样本/配对 t 检验、Wilcoxon、ANOVA 事后比较、方差/正态性检验、eta squared 和 omega squared 已进入 `run_statistical_tests()` 主循环，并投影到报告、表格、Agent 结果和 XLSX 导出。
- **三种权重语义显式化。** `frequency_weight` 已从 API/Genesis 入口贯通到支持的 sklearn `sample_weight` 执行；`analysis_weight` 在 OLS 中通过分析权重/加权最小二乘执行；`sampling_weight` 在完整 strata/PSU 设计语义落地前保持 fail-closed，并给出复用现有 `entity_col + covariance=clustered` 通道的下一步，不会被静默当成频数权重。
- **FeatureRecipe 与数据操作可达。** 派生变量/重编码以及 merge、append、reshape、subset 等受限数据操作已通过 API、界面和 Graph 节点入口暴露；从可物化的数据节点可直接启动现有 OLS 生命周期，并在 child run 中保留 source run/node/artifact/hash lineage，形成可回溯的 merge → reshape → derive → model 链；未知算子、键冲突、多对多膨胀和非法参数保持拒绝。当前数据节点模型桥接只覆盖数值 OLS。
- **变量和值标签。** Run API 接受严格的 `variable_labels` / `value_labels`；标签会进入数据上下文、报告表格、图形坐标/分类刻度和 XLSX 导出。没有标签时使用明确的列名 fallback，不伪造用户标签。

## 已知限制与明确不宣称

- **MICE 是本版的明确限制，也是部分用户的能力回退。** 当前只支持 prediction 折内、数值缺失特征的 IterativeImputer 路径：插补器在每个训练 fold 内拟合，并分别应用到验证/测试 fold。通用 Run 的全表 MICE 路径、显式传入的全表插补结果，以及不满足前提的场景会 fail-closed；因此依赖 v1.8.5 通用全表 MICE 的用户在本版不会得到同等能力。全表路径的拒绝是边界保护，不应理解为已支持任意 MICE 场景。
- **外部标签格式不宣称自动保留。** 当前可验证的是 Run/API 显式 `labels`（variable/value labels）及其报告、表格、图形消费；`.dta`/`.sav` 等外部格式的标签自动保留没有作为本版交付。
- **数据节点模型桥接范围有限。** 当前入口只启动数值 OLS；其他模型族仍通过普通 Run/Genesis/Agent 入口使用。
- temporal / panel prediction 的实际执行、完整 survey 分层/聚类抽样权重、PIT/quantile 全面研究套件、自动调参、深度学习和任意代码执行仍不属于本版本交付。
- 本地单元/集成测试不等于“所有族都已通过外部 oracle”。Cox survival 已用独立 R `survival::coxph` 清洗后 40 行 fixture 对照：系数、标准误、p 值一致，置信区间在声明的 `1e-14` 跨语言浮点容差内；ordinal、multinomial、quantile 仍只宣称内部一致性，frequency-weight OLS 的 Stata/R 外部验证仍未完成。本轮原生 in-app browser 已实际完成 `merge → reshape → derive → model` 图谱链（`40 → 40 → 240` 行），ordinal logit 的模型节点重跑，以及通过完整 RunForm 配置 `event_column=event` 的 Cox survival 运行；缺少 `event_column` 的模型节点重跑也按契约 fail-closed。Agent 已通过真实 `inspect_result_summary` 对读 prediction、statistics 以及四类模型族证据，并比较精确 hash、数字、符号和可公开的区间端点。
- 本文件不代表已完成发布流程。完整 gate 与本轮浏览器验收已完成；版本整合以及明确的 push/merge/tag 授权仍未执行。

## 模型族验证等级

- `ordinal_logit`：**仅内部一致性测试**；后端契约/运行/消费者测试通过，原生浏览器模型节点重跑已完成；没有把 R `polr` 的求解器差异包装成逐位 oracle 通过。
- `multinomial_logit`：**仅内部一致性测试**；后端契约/运行/消费者测试通过，本轮未做原生浏览器运行；R `nnet::multinom` 对照用于发现并修复基准类别标签错位，但当前优化结果不宣称逐位复现。
- `survival_cox`：**Cox 系数、标准误、p 值和置信区间已对 R `survival::coxph` 做字段级验证（`1e-14` 跨语言浮点容差）**；后端契约/运行/消费者测试通过，RunForm 配置 `event_column=event` 的原生浏览器运行已完成并生成 `survival_evidence`。这不扩展为整个 survival packet 的外部逐位 oracle 声明。
- `quantile_regression`：**仅内部一致性测试**；后端契约/运行/消费者测试通过，本轮未做原生浏览器运行；不宣称与 R `quantreg::rq` 逐位复现。
