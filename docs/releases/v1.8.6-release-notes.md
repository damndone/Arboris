# Workbench v1.8.6 — 候选发布说明

> 状态：开发线候选版本，尚未 push、合并、打 tag 或发布。以下内容只描述已实现并有本地测试证据的能力。

## 相较 v1.8.5 的主要变化

- **预测研究正确性基础。** 预测流程现在使用显式的 SplitPlan、最终 holdout、baseline、负对照和证据投影；未知数据结构、未声明的 split/权重语义不会静默回退到旧的随机切分路径。
- **四类新模型族。** 普通 Run、Genesis 和 Agent 可达 `ordinal_logit`、`multinomial_logit`、`survival_cox`、`quantile_regression`。结果包含与模型族对应的概率/比值比/相对风险比、边际效应、生存曲线与 log-rank、分位数与跨分位数比较等证据；缺少生存事件列等必要输入会明确拒绝。
- **统计检验补完并接入普通流程。** Cohen's d、单样本/配对 t 检验、Wilcoxon、ANOVA 事后比较、方差/正态性检验、eta squared 和 omega squared 已进入 `run_statistical_tests()` 主循环，并投影到报告、表格、Agent 结果和 XLSX 导出。
- **抽样权重语义显式化。** `frequency_weight` 已从 API/Genesis 入口贯通到支持的 sklearn `sample_weight` 执行；`sampling_weight` 与 `analysis_weight` 在当前通用适配器不具备完整设计语义时保持 fail-closed，不会被静默当成频数权重。
- **FeatureRecipe 与数据操作可达。** 派生变量/重编码以及 merge、append、reshape、subset 等受限数据操作已通过 API、界面和 Graph 节点入口暴露；未知算子、键冲突、多对多膨胀和非法参数保持拒绝。
- **变量和值标签。** Run API 接受严格的 `variable_labels` / `value_labels`；标签会进入数据上下文、报告表格、图形坐标/分类刻度和 XLSX 导出。没有标签时使用明确的列名 fallback，不伪造用户标签。
- **折内 MICE。** prediction 与 MICE 同时使用时，数值缺失特征的插补器在每个训练 fold 内拟合，并分别应用到验证/测试 fold，避免先对全表插补再切分造成泄漏。

## 已知限制与明确不宣称

- **MICE 不是“所有场景均支持”。** 不满足当前折内数值插补前提、使用不支持的全表路径或缺少必要数据时，流程会 fail-closed；这表示安全拒绝，不是自动完成插补。发布说明不把 fail-closed 写成新增执行能力。
- temporal / panel prediction 的实际执行、完整 survey 分层/聚类抽样权重、PIT/quantile 全面研究套件、自动调参、深度学习和任意代码执行仍不属于本版本交付。
- 本地单元/集成测试不等于 Stata/R 数值 oracle，也不等于原生 in-app browser 验收；真实浏览器手势与外部统计软件交叉核验仍需单独记录。
- 本文件不代表已完成发布流程。是否发布仍需完成完整 gate、浏览器验收、版本整合和明确的 push/merge/tag 授权。
