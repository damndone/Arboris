# V1.7 — Agent Harness、typed data operations 与 sandbox

**Theme:** 建立可审计、可恢复的 Agent-confirmed Typed Operation lifecycle，补齐图内数据操作与受限代码执行的安全边界。

**Branch:** `workbench-v1.7`（base: `main` at `510ff5a`）

## What shipped

### Agent Harness

- durable Agent session/event storage，以及 Main → Chain hierarchy；
- chain-scoped read-only context/tools；
- typed proposal → confirmation → active-head/precondition revalidation → execution；
- proposal decline/revision、`model.rerun`、`graph.fork`；
- operation lease、claim、effect binding、reconcile、Operation Record、diff 和 verification；
- Agent/Graph/operation/fork/child-run navigation 与 AI Activity projection；
- 后端现在以持久化 `ChainStore.active_head_run_id` 为 authoritative active head，拒绝伪造或过期 head。

### Typed data operations

- `data.column.cast` 与 `data.columns.cast` 的严格 preview/confirm/readback；
- immutable derived artifact、recipe、child data node、schema fingerprint 和 downstream rerun-required 标记；
- source artifact immutable、幂等 effect、failpoint/reconcile recovery；
- `data.columns.cast` 可由自然语言 Agent 生成 typed proposal；单列 `data.column.cast` 保持 NL 关闭。

### Sandboxed code execution

- `code.execute` 作为 typed operation，NL 保持关闭；
- OS sandbox、网络拒绝、项目源文件不可写、输出目录隔离、secret 环境变量清理、超时与 descendant cleanup；
- bounded stdout/stderr、preview/apply determinism check 和 execution-key 幂等；
- UI 展示已完成的捕获输出，不宣称实时流式输出。

## Explicit boundaries and deferred work

- JSONL control plane 只支持 single-worker deployment；不宣称 multi-worker 或跨进程并发安全；
- `risk_level="high"` 当前是展示元数据，不自动触发额外确认或独立 scope；安全性来自 typed confirmation、scope/precondition revalidation 与 sandbox；
- `code.execute` confirm 当前可能重复运行用户代码，属于 v1.7+ 性能债；
- 更多 cleaning/异常值规则、V7 drill-down、multi-step Main Agent 和多租户/RBAC 不属于本版；
- provider-specific E2E 不作为本版离线 gate 的结论，发布时不将其扩大宣传为系统级保证。

Python package metadata 仍遵循仓库既有约定保持 `0.1.0`；`v1.7` 是 Workbench release/branch 版本标识。
