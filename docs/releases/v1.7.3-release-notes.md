# V1.7.3 — Local macOS LMM Workbench and Parallel Development Control

**Theme:** 在本机 macOS Workbench 中交付可运行的 Linear Mixed Model 纵向切片，并把首次多线并行开发、组装、验收和失败经验变成可复用的工程控制面。

## What shipped

### Linear Mixed Model vertical slice

- 版本化 Linear Mixed Effects Model Pack，包含受试者、时间、组别、拟合方法、随机截距/斜率输入约束；
- server-owned model options、稳定的公共结果投影、系数/标准误/置信区间/p 值、诊断和图表事实；
- 普通 RunForm 与 Genesis 参数入口、Table/Report/Graph 结果消费、PDF/XLSX/HTML 导出；
- 只读 Agent 能力读取公共 LMM 事实、诊断、节点上下文、Repeated Measures recipe 和 analysis-loop 状态，不自行重算统计量或绕过确认边界。

### Explicit local execution profile

- `scripts/run-local-contained.sh` 每次启动显式选择 `local_contained`；关闭进程即失效，不持久化为默认设置；
- 启动时运行真实 macOS Seatbelt canary；只有 canary 通过后，本机 LMM 与既有沙箱化 `code.execute` 才获准；
- 默认启动仍 fail closed，不允许浏览器请求或单次 run 参数自行开启高风险能力；
- 本地运行记录明确标记为 local-development evidence，不冒充第三方插件或敌对候选代码的隔离认证。

### Parallel development and failure memory

- 采用 Contract-first Integration Release Train：Agent、Model Pack、UI/UX 三条 Feature Lane，加一条独立 Evaluation Lane；
- 所有 Lane 从同一个 C1.1 contract lock 开始，最终由 Integration 组装，不允许功能分支直接合入 `main`；
- `.agent/devlines/<line_id>/events.jsonl`、自动生成的 `RETROSPECTIVE.md`、Context Pack、回顾索引和 1/2/3 规则提升控制已落地；
- v1.7.3 的正式开发线日志已通过完整性校验，旧格式线路被隔离，不参与新控制面判断。

## Explicit boundaries

- 本版本承诺的是本机 macOS Workbench，不宣称已完成 App 封装、notarization、公共部署或多宿主验收；
- 未接入产品的 C2 hostile-candidate prototype 已删除。只有未来引入不受信任插件、第三方模型包或外部候选代码时，才按新的威胁模型重新立项；
- Prophet、pmdarima、arch 和预测能力不在本版本。下一阶段先完成 Time Series Diagnostics C1，再做诊断运行时，最后才进入预测；
- Python package metadata 延续仓库既有约定保持 `0.1.0`；`v1.7.3` 是 Workbench release 标识。
