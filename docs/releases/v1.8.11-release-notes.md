## 版本定位

v1.8.11 对标 Stata / SPSS：Stata 用户日常会用到的估计、检验和复现，在 Workbench 里数字一致、能导出成脚本复现、Agent 能做。

## 新增与改进

### 后估计与模型族

- **IV、GLM（binomial / Poisson / 负二项）、面板、DID 开放后估计**：Wald、lincom、nlcom，GLM 另有 LR 与边际效应；
  每个“族 × 操作”有 R 或 Stata 对照（IV 双内生对 Stata `ivregress` + `test`；面板 / DID 对 `xtreg, fe vce(cluster)`）。
  2SLS 没有似然，明确拒绝 LR。
- **面板 / DID / 事件研究默认按个体聚类**：CR1 + t(G−1)，K 不计被吸收的固定效应（同 `xtreg`）；聚类数阈值统一到检查库
  （G < 30 警告，G < 10 提示 wild cluster bootstrap，本版未实现 wild bootstrap）；指定其他聚类层级时按实际设置计算；
  旧结果不改写，标注“旧版：异方差稳健、未聚类”，重新运行使用新口径。
- **负二项像 `nbreg` 估计 α**：默认 NB2，可选 NB1 与固定 α（结果写明“未估计”）；α 作为辅助参数单列，报告区间与
  α = 0 的边界 LR（χ̄²）；`glm` 的负二项必须显式给 α，不再静默用 1。
- **线性混合模型**：固定效应推断改用 lme4 `vcov()` 与 Stata `mixed` 共同的 GLS 协方差（`statsmodels_mixedlm_v2`；
  v1 旧结果仍可读）。REML / ML × 随机截距 / 随机斜率四种设定对 lme4 与 Stata 都在 1e-6 内（原口径在随机斜率上差 0.1%）。
  开放 Wald、lincom、nlcom；REML 下的 LR 明确拒绝并说明需用 ML 重拟合；未收敛或诊断失败的拟合不提供后估计。
  Agent 可读取全部固定效应（全精度）。
- **抽样设计单阶段 FPC**：按层 (1 − f) 修正，总体 PSU 数或抽样比例两种单位，certainty 层、子总体与 lonely PSU
  政策一致处理；与重复权重组合、混合单位等明确拒绝。无 FPC 时行为不变。

### 时间序列复现

- ARMA(p,q)–GARCH(r,s) 联合 MLE（q > 0），对 Stata `arch`；不收敛、非平稳、不可逆或非有限参数仍拒绝。
  手动指定阶数照做，残差 Ljung–Box 不通过时以警告披露；短滞后自由度非正时标为不可用而不是拒绝。
  “经典复现”是显式选项（全样本选模型 + 逐期重估 + 留出一步预测），尾部评估明确为回顾性；原训练 / 验证默认
  及其历史哈希保持兼容。用户的 VIX 报告逐项复现，
  ω 与原 Stata 结果的差（2.4e-4）经独立高精度 R 确认来自 Stata 的停止精度，作为已知差异保留。

### 脚本导出（Stata / R / Python）

- 由血缘与运行输入生成可复现脚本；开头是覆盖表（原生 / 附等价说明 / 不能原生导出及原因），不能原生的步骤从
  带 SHA-256 的数据或结果快照接续；末尾自检断言，跑出来与 Workbench 不一致就报错。
- 本版准入族与常用数据操作、后估计、FPC、固定 α GLM 都在本机 Stata 18 / R / Python 实跑通过；用户要求“完全原生”
  而做不到时明确拒绝并列出步骤。基础 DID 原生准备保留 cohort、two_by_two、status 的原定义，合法浮点文本、
  多行 CSV 与极端浮点边界都按原值读取，Stata 无法保持有限 cohort 时明确拒绝。导出走外发管控，界面、HTTP 与
  Agent 的每次导出都记入分析台账。

### Agent

- 一个方案里先拟合再检验，确认一次、按依赖执行；改用常规标准误做 LR 时说明原因，并提供原模型上的 Wald。
- 计算工具给出 15 位有效数字，去掉二进制浮点噪声（例如 33.76 − 32.295 不再显示为 1.4649999999999963）。
- 服务商模型列表可刷新、可手填，代码里不再写死带版本号的模型名。

- 宿主 full gate（`e6cc27bd`，日志 `docs/superpowers/evaluations/gate/2026-10-07-v1.8.11-gate.log`）：
  后端 7912 passed / 5 skipped / 1 xfailed（18:39，上限 20:09），golden 通过，前端 211 个文件 / 1780 个测试，tsc 无错误。
- 对照：每个新数字都有 R 或 Stata（18 MP）对照，比较到最终报告的量（统计量、自由度、p）。
- 脚本导出：同一批 823 个导出测试在“每个脚本一个新进程”和“每种语言一个常驻解释器”两种方式下都通过；
  另有代表性用例始终以新进程实跑。独立复核：完成结果语义 71 项检查（36 次三语言执行、8682 项数值比较）；
  基础 DID 浏览器实际公共 ZIP 4 份共 72 项数值自检。
- 真机评测（deepseek-flash）：17 个模型族各一例全部通过（含 LMM，宿主隔离执行）；分阶段累计，首轮 39 / 53 的原记录保留，
  不宣称单次全绿。故障注入 18 项中 16 项首轮通过，`garbage_chunk` 根因已修并复测通过，`timeout_first` 为真实上游故障、
  失败可见且同会话恢复。
- 独立评估（Codex 评估线 E）：47 / 48，剩余 1 项为 Stata 停止精度差异，独立 R 闭式参考确认。
- 性能：联合估计 < 10 s，509 次滚动重估 48.6 s（< 3 min），NB2 10 万行 0.63 s，面板聚类 10 万行 / 1,000 个体 0.61 s。
  后端测试曾超出预算（22:38），超出部分全部来自本版脚本导出的原生实跑；改为每种语言一个常驻解释器后为 18:39。

## 已知限制与延后

- 仅在本机 macOS 验证；Linux、其他主机与云端为 NOT VERIFIED。
- LMM 的 ML 似然比检验与边际效应尚无对照，暂不开放；LMM 结果卡片仍只显示组 × 时间交互项（完整固定效应表目前只供 Agent 读取）。
- 列名含单引号时，公共项名的转义不一致（各模型族共有的旧问题）。
- 深色面板对比度欠账（`V1811-DARK-PANEL-CONTRAST`）未修；浅色 / 深色 / 跟随系统三档设置可用。
- VIX 原报告的 ω 差 2.44e-4 超出原 1e-4 门槛，原参考与失败记录单独保留；独立高精度复验参数最大绝对差 2.92e-6、
  SE 最大相对差 2.82e-5、LL 差 1.33e-10。
