## 版本定位

v1.9.0 是界面重做版：按研究工作的顺序组织界面，**所有功能不接模型也能点选完成**，Agent 调用同一套能力。同时大幅增强 Agent：长对话压缩、项目指令、本项目会话回忆、会话管理，以及确认执行后的结果回告。

## 界面

- **新工作区（默认）**：Home / Data / Analysis / Tables / Report / Plans 视图，结果优先或谱系优先两种布局，可拖拽、浮动、停靠、收起的 Agent 窗口；旧界面仍可在 设置 › Appearance 切回。
- **主题**：设计令牌为唯一颜色来源（颜色字面量 272 → 0），深浅色对比度由测试保证；保留浅色/自动/深色三档。
- **Analyze**：122 项操作按研究顺序分组，表单由后端声明生成，全部字段有控件，无需手写 JSON；预览 → 确认两步执行，可在同一计划里先做数据操作再拟合模型。
- **结果与后估计**：模型结果、检查、后估计、比较、就地改参重跑与新分支；区间图带刻度与说明。
- **Data**：统一控件与工具卡片（Transform / Export / AI sharing）。
- **手写报告**：读起来像结果段落，每个数字都绑定到证据（值标记），保存时校验；导出 HTML / DOCX / TEX / 打印版。不配置模型也能完成。
- **顶栏**：视图标签居中；窗口变窄时右侧按钮不再换行。
- **右键问 Agent**：节点右键“Ask Agent about this node”；选中文字右键可“问 Agent / 加到消息 / 复制”，表格行带列名。

## Agent

- **对话**：草稿跨视图保留；进行中的回合在对话流里；每条消息有时间与复制 / 回到此处 / 从此分叉 / 设为章节；整回合时限 300 秒。
- **会话管理**：Agent 栏标题即会话列表，可搜索、切换、改名、归档 / 恢复、删除（确认后删除；分析台账、提案与结果保留）；笔形按钮新建会话；会话绑定持久保存。
- **长对话压缩**（参考 pi 与 Codex）：接近工作预算（默认 200k tokens，可用 `WORKBENCH_AGENT_COMPACT_AT` 调整）时把较早的对话换成结构化摘要，最近约 2 万 tokens 原样保留；常驻信息不压缩；**摘要里的数字按回复同样的规则核对**，核对不过的摘要不当作证据。服务商报“超长”时自动压缩并重试一次。可手动“Summarize earlier conversation”。
  - 实测：deepseek-flash 默认支持 1M 上下文（1,048,576 tokens；875k 被接受，1.155M 被拒）。
- **项目指令**（参考 Codex 的 AGENTS.md）：内置通用分析准则 + 个人 `~/.config/econometrics-workbench/AGENTS.md` + 项目 `AGENTS.md`，在 设置 › Agent instructions 编辑；模板适用于任何分析，可“从本项目起草”。
- **本项目会话回忆**（不做跨项目记忆）：新对话收到以往会话索引，并可搜索、阅读本项目以往会话；不搜工具结果。
- **执行结果回告**：确认提案后，Agent 会被告知产出的运行、协方差，以及是否与已有分析完全相同；后台运行结束后下一轮补报。已决提案折叠为一行。
- **身份如实**：按真实服务商与窗口回答“你是谁”；说明哪些会保存。
- 规则：只提议系统能运行的选项；用户笼统同意时提出所提过的全部变体；重跑前先查是否已有相同结果。

## 命令行

- `workbench analyze list | describe | run | confirm`：从命令行使用目录中的全部工作流操作，走同一预览 / 确认服务。

## 性能与体积

- 按需加载：启动页 JS 1653 kB → 205 kB（gzip 507 → 67 kB），无超过 500 kB 的代码块；表格读取库只在预览表格时加载并只保留读取部分。
- 删除约 2,700 行只被自身测试引用的模块与 41 个无用样式类，三个测试防止回潮。
- 手写报告打字：每次按键 173 ms → 约 20 ms。
- Agent 事件日志改为真正的追加：每个流式片段 23 ms → 0.08 ms。
- honest-DID：线性规划直接调用 HiGHS（`highspy==1.12.0`，与 scipy 内置同版本），R 对照样例上 66.5 s → 20.0 s，**输出与原路径逐字节一致**。
- 数据核对证据纳入统一留存（保留最近 3 次，失败的全部保留）；gate 记录同样留存。

## 已知限制

- **OLS 没有 HC3 标准误**：稳健标准误固定为 HC1；Agent 会如实说明，不以近似选项替代。计划在后续版本补齐并对 R / Stata 验证。
- 单个回合本身超过上下文窗口、且之前没有可切分的提问时，压缩无法切分该回合（pi 会拆分回合）；在 1M 窗口与 200k 预算下很难遇到。
- 线性混合模型似然比检验仍关闭；NB1 原生 R 重估未运行（缺 glmmTMB）。
- 仅在 macOS 本机验证；Linux 与会话令牌仍延后。

## 升级说明

- 新依赖：`highspy==1.12.0`（若缺失自动回退到 scipy 路径）。
- 会话与 Agent 设置向后兼容；旧版本的会话绑定会自动迁移一次。
- 新的环境变量：`WORKBENCH_AGENT_COMPACT_AT`（压缩预算）、`WORKBENCH_LLM_CONTEXT_WINDOW`（环境变量方式配置模型时声明窗口）、`WORKBENCH_LP_SOLVER=scipy`（强制旧求解路径）。
