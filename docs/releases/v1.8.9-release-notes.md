## 版本定位

v1.8.9 把日常统计工作接到 SPSS/Stata 用户的习惯上，并让 Agent 的回答可以被信任：

- 读写 `.sav/.zsav/.dta`，变量标签、值标签、测量层级和缺失码贯穿导入、分析、结果与导出；
- 数据编辑和日常分析都能用自然语言驱动，只读分析当场出结果，改动数据要确认；
- Agent 的每个数字都来自计算结果，并在显示前自动核对；
- 每个检验和数据改动都记入分析台账，报告自动披露分析路径。

## 新增与改进

### 数据与元数据

- **变量元数据**：标签、值标签、测量层级（nominal / ordinal / scale）、用户定义缺失码。
  Variable View 编辑后生成新的 run，原结果不变；系数表按值标签显示（如 `region: 南方`）。
- **SPSS / Stata 互通**：统一读写 csv、xlsx、parquet、sav、zsav、dta。导出可选变量、行、格式、
  Stata 版本（默认 118）、值标签和缺失码的写法，信息损失逐条提示。与 Stata 18、R `foreign` 对照验证。
- **数据编辑器**：filter、recode、合并、缺失码等 11 个操作以血缘节点记录。
  sort 只做浏览排序，split 由各分析的“分组”代替（理由见立项文档第 6 步）。

### Agent

- **只读分析自动运行**：描述统计、频数、相关与各类检验不需确认，当轮回答；
  改数据、改模型、写报告、跑代码仍是提案，需确认。
- **数字核对**：回答中的数字逐个对照结果检查（含舍入、百分比、科学计数法）。
  差值、比率等派生数字必须经 `calculate` 工具计算；不通过的草稿撤回重写，仍不通过则附警告显示。
- **分析诚信规则**：拒绝为了“变显著”而改数据或挑设定，只拒绝不正当的部分并照常给出真实结果；
  报告 p 值时说明本会话已做的检验数，并提示多重比较。
- **分析台账与报告披露**：每个检验与数据改动都有记录，报告自动附“分析路径”一节。
- **外发管控 v1**：默认不把原始数据行发给 AI 服务商，可按项目和列调整，审计可查。
- **服务商故障处理**：未产生输出前的失败自动重试两次；key 被拒不重试并指向设置；
  回答中途断开会标注“未写完、数字未核对”；同一会话可接着提问。
- 可读提案（编号句子加变量标签）、按回合刷新的项目上下文、Chain 会话结果表的分组统计可见。

### 修复的既有问题（部分从 v1.8.8 起就存在）

- 默认的 Auto 模型无法保存；重跑修改标签时丢失缺失码，导致 -99 等回到样本；
- 清洗时静默删除完全相同的行；调查设计遇到协变量缺失时报错；
- logit/probit/poisson 的联合 F、White 检验、二次项拐点被当作 OLS 重估（现在明确拒绝，按族实现见 BACKLOG）；
- 一个 run 上后估计结果超过 20 个后，后续工作流全部失败；
- 同一会话的并发写入会丢失记录；同一个只读检验第二次运行报“路径被占用”；
- 与服务商的连接要等垃圾回收才关闭。

## 验证

- 宿主 full gate（`2ec3e016`）：后端 5845 passed / 5 skipped / 1 xfailed（13:02），golden 23 passed，
  前端 203 个文件 / 1710 个测试通过，tsc 无错误。后端耗时为 v1.8.8 的约 1.07 倍（上限 1.5 倍）。
- 立项 8 个验收场景在浏览器中逐条通过。
- 真机评测（DeepSeek）：全量 32 例 × 3 为 88/96，失败为本地代理超时；失败例重跑 24/24。
  反脆弱轮：故障注入 24/24（35 次故障，失败轮次在同一会话中都能恢复），对抗用户 12 例 × 3，
  发现的问题修复后受影响用例 5/5。没有一次回答含无依据的数字。
- 性能：100 万行 × 10 列描述统计 24 s；读取单个结果 0.09 s。
- 证据：`docs/superpowers/evaluations/2026-09-25-v1.8.9-agent-baseline.md`、
  `docs/superpowers/evaluations/2026-09-26-v1.8.9-trust-round.md`、`docs/superpowers/evaluations/gate/`。

- 分组分别执行、排序变量、发表级表格、脚本导出、调查 GLM、分类机器学习与 Quant 方向见 BACKLOG §0.2
