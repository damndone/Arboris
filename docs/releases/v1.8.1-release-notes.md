# Workbench v1.8.1 — Agent Notebook

v1.8.1 makes the Agent Notebook a Graph-first analysis surface. The Graph,
RunFamily, Draft, Run, Artifact, Diagnostic, and Compare objects remain the
execution truth; Notebook is their bounded narrative projection.

## Highlights

- Agent planning produces typed AnalysisOptions, with evidence references,
  assumptions, expected artifacts, freshness fingerprints, and explicit
  recommendation states.
- Selecting an option materializes a PipelineDraft rather than silently
  creating a Run. Deferred siblings remain inspectable and stale options are
  blocked until revalidated.
- The Notebook works with the VIXCLS time-series fixture and supports the
  existing ARMA-GARCH path plus the ETS alternative.
- Selected Agent text can be routed to “Add to task”, “More details”, or
  “Side chat” actions while preserving source references and typed boundaries.
- RunFamily identity, bounded Context Compiler, and Core Agent Trace v1 are
  included as correctness foundations.
