# V1.5.7 — honest-DID (Rambachan-Roth ΔRM 敏感性)

DID Layer 3 的第一块：在 Callaway-Sant'Anna DID 之上加一层 **honest-DID
敏感性分析**（Rambachan-Roth 相对幅度 ΔRM）。它回答"平行趋势要被违背多少，结论才
会翻车"——给出在**有界违背**下仍然有效的稳健置信区间。**点估计不变**（纯后处理）。
0 新运行时依赖、opt-in、degrade-not-fail；golden 仍 0-drift（既有 19 + 新增 1 =
20）。

## 做了什么

- **honest-DID 引擎端口（self-implemented）。** 忠实移植 R `HonestDiD` 0.2.8 的
  核心：ΔRM 约束构造（对每个前期 `s`、每个违背符号取**多面体并集**）、ARP
  conditional 检验、以及 degenerate-dual 退化路径。逐元素对照 R HonestDiD 校验
  （robust CI 端点 ~1e-3，θ-grid 上 element-wise accept/reject 一致）。0 新依赖。
- **adapter（CS → honest-DID）。** `engine/honest_did_adapter.py` 从 CS 的 dynamic
  聚合取出事件研究系数与**cluster-robust 协方差 Σ**（沿用 CS 的 entity/变量聚类
  影响函数），喂给 ΔRM 引擎。
- **Conditional / ARP 决策（为什么不用 C-LF）。** 我们选用 **simulation-free 的
  Conditional / ARP** 变体，**不用** least-favourable / conditional-LF hybrid——
  C-LF 需要靠**模拟（RNG）**抽 least-favourable 临界值，会让输出非确定。
  Conditional/ARP **完全确定**，同输入永远同输出，对可复现性与 0-drift golden 至关
  重要。
- **degrade-not-fail。** honest-DID 永不让 run 失败：内部出错时 `honest_did` 块返回
  `{"skipped": true, "reason": ...}`，CS DID 其余结果照常落地。
- **opt-in + 异步。** 通过 `run_cs_did(honest_did=...)` / API `honest_did=true` /
  GUI 复选框开启。M̄ 网格与分辨率是模块常量（`runner.HONEST_MBAR_GRID =
  [0,.5,1,1.5,2]`、`runner.HONEST_GRID_POINTS = 1000`）。满网格 ~157s，异步运行，不
  阻塞其余 CS 输出。
- **前端 checkbox + 敏感性子面板。** CS 控件新增 "honest-DID 敏感性
  (Rambachan-Roth)" 复选框；CS 诊断卡新增稳健面板：M̄ 网格逐行的稳健 CI + **突破
  M̄**（CI 首次含 0 的最小 M̄）；degrade 时显示 skipped 提示。
- **additive golden。** 新增 `cs_did_honest` golden 钉死开启 honest-DID 的 CS run
  形状（status / artifacts / 点估计 ATT）。注意 golden **不冻结 honest-DID 的 CI
  数字**——`_capture` 只快照 status/artifacts/coef_rounded——所以小网格 golden-safe。

## 为什么安全

- **纯后处理：点估计逐字不变。** ATT(g,t) 与四种聚合就是 CS DID 已经算出的值；
  honest-DID 只**放宽 inference**。
- **确定性：** Conditional/ARP 无 RNG，同输入同输出（golden 两次运行 0-drift 已
  验证）。
- **永不失败：** 内部异常被捕获并降级为 skipped 块。
- **逐元素校验：** robust CI 对照 R HonestDiD 0.2.8（~1e-3）。
