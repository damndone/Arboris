Report review 的标签层级

选择 Report review 与节点标签的共存方式，以及 Float 是否成为跨页面的工作区级面板。

推荐方向：A。它把“正在看的节点”和“正在审阅的报告”分开，不会让报告误绑定到某一个节点；Float / Pin / Collapse 也最容易保持一致。

按钮建议

New 新建报告；Edit 修改写作指令或进入可编辑草稿；Export 导出当前报告；More formats 打开 PDF / HTML / DOCX / TeX / 结果表等导出格式，不把格式选项全部铺在顶部。

已确认的 A 方案行为

Report review 是永久的工作区标签，不关闭；点击 Collapse 会把整个右侧面板收成窄把手，让 Report / Graph / Table 释放宽度，点击把手即可恢复。Float 模式仍保留标题栏和底部 revision 输入框，并跨页面置于 Workbench 最上层。
