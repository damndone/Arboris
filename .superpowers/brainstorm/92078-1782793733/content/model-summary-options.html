角色正名 + model 节点摘要的三种写法

上：角色已正名 Y / X / Z。下：model 节点摘要应承载什么——选 A/B/C。

MODEL INPUTS（正名后）
Outcome Variable (Y)
income
Focal Explanatory Variable (X) · ≥1
education
Covariates (Z) · 0+
age
region
↓ 这些一起流入 ↓

model 节点摘要：A / B / C

A

只承载估计身份（推荐）

ols_robust (primary) OLS · HC1 · n = 36 …021506 · #bb21b · source

变量名不重复（已在上游角色节点）。完整公式 income ~ education + age + region 放在节点详情抽屉里。最精简、零冗余。

B

摘要里带完整公式

ols_robust (primary) income ~ education + age + region OLS · HC1 · n = 36 …021506 · #bb21b · source

节点单看就自含完整规格，但和上游角色节点的变量名重复，图密时显冗长。

C

符号公式 + 角色计数

ols_robust (primary) Y ~ X + Z　(1 focal, 2 covariates) OLS · HC1 · n = 36 …021506 · #bb21b · source

用 Y/X/Z 符号表达设定结构、不重复具体名字，又点明焦点/协变量个数。科学但稍抽象。
