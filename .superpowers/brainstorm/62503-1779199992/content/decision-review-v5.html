前端 dpRegistry.ts · 决策呈现层

每个 decision_id 在前端有一份呈现元数据——把 snake_case + 工程语气翻译成审查任务语言。后端 schema 不动。

// frontend/src/lineage/dpRegistry.ts
export const DP_REGISTRY: Record<string, DPDisplay> = {
  model_type_auto_select: {
    title: 'Model type',
    // selected="continuous" → "OLS" 用户视角
    displaySelected: (s) => ({ continuous: 'OLS', binary: 'Logit', count: 'Poisson' }[s] ?? s),
    displayAlternatives: () => ['OLS', 'Logit', 'Poisson'],
    whyShort: (p) => 'y appears continuous',
    whyLong: (p) => `y has ${p.y_unique} unique values, so the system treated it as continuous.`,
    confirmPrompt: 'Confirm that y should be modeled as a continuous outcome.',
  },
  ols_default_robust_se: {
    title: 'Standard errors',
    displaySelected: (s) => s, // HC1 stays HC1
    displayAlternatives: () => ['non-robust', 'clustered'],
    whyShort: () => 'System default',
    whyLong: () => 'HC1 robust standard errors are applied by default to OLS regressions.',
    confirmPrompt: 'Confirm HC1 is appropriate; revisit if heteroskedasticity assumption is uncertain.',
  },
  // ... 4 more for V1.4.0 DPs
};

后续国际化、文案优化、新增 decision_id 都在这一份文件里改 —— 后端无感。
