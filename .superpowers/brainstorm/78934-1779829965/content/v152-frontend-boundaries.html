V1.5.2 Frontend Boundaries

The current LineageContext is graph-specific. V1.5.2 should add a Workbench layer above it, so future Table, Pipeline, AI, report, and editable rerun features do not depend on React Flow internals.

Proposed ownership model
WorkbenchRouteContainer: run snapshot + URL state + view mode
WorkbenchStateProvider
selection, tabs, search, actions, bottom panel
RunSnapshotAdapter
nodes, variables, models, decisions, artifacts
GraphView
React Flow only
TableView
slot in V1.5.2
PipelineView
slot in V1.5.2
NodeActionRegistry
NodeExtensionRegistry
BottomPanelRegistry

Why this is extensible

  • Graph, Table, and Pipeline share one selection/search/action model.
  • Node AI, edit controls, code, artifacts, and decisions become plugins into the drawer.
  • Partial rerun can land later by enabling actions, not rewriting UI ownership.

What it costs

  • More upfront interface design.
  • Some V1.5.1 Lineage code moves into a new workbench folder.
  • Tests must focus on contracts, not only rendered buttons.
