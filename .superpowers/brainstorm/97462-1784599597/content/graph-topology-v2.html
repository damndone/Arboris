谱系图拓扑（改正）：链式主干 → fork 出多个模型节点 → 对比节点

不同模型 = 不同节点（从"ARMA 均值选型"之后 fork）。对比不是主链里的固定步骤，而是把两个模型节点接进一个对比节点。首跑只落一个被选中的模型节点，其余是你显式 fork 出来的分支。

主干 & 首选模型（首跑落地） fork 出的备选模型节点（显式创建） 对比节点（接入 ≥2 个模型节点）
这样一来
  • 每个模型节点自带完整结果：最终拟合 + 条件序列(mu/h/sd/z) + 滚动验证 + n+1 预测 + 该模型的诊断，全在它的抽屉 dashboard 里（就是上一屏那套一屏式布局）。
  • 换模型 = fork 新节点：改变换/阶数/分布/strategy 都 `model.rerun`/`graph.fork` 出新节点，不覆盖原节点——链式血缘清晰。
  • 对比 = 连接生成：在画布上选两个模型节点 → 生成对比节点，抽屉是四层对比（数据/参数/指标/诊断/结论 + PI 面板 + 宽度差/覆盖/pinball）。复用现有 CompareNodes。
  • "滚动验证 / 预测 / 诊断" 不再是主链里的独立横条，而是每个模型节点结果的一部分——因为它们本就依附于"某一个具体模型"。
  • 主链只到 ARMA 均值选型为止是共享的；方差模型的选择就是分叉点（ARMA-only 也只是"方差=常数"的一个分支）。
