观察到的问题：结果卡（9 胶囊）只在被废弃的 Overview 页出现，不在图里；Table 显示的是通用 EDA 图（直方图/箱线）不是时序视图；节点点开只有 Ask AI / Compare，没有"改 transform / 改阶数"这类时序操作。

方向选择

A

交互式建图（每步一个可操作节点）

列映射 / 时间审计 / 变换确认 / 切分 / 搜索配置都是画布上的节点，你在节点上确认或改参数、逐步推进，取代 run 前的五步表单向导。最贴近"所有步骤都在图里操作"，但改动最大。

B

表单启动 + 图内结果与 rerun

保留 run 前的配置表单；图负责展示每个阶段的结果，并支持从任一节点 rerun / fork（改 transform、阶数、分布、validation_n 等）。结果卡搬进节点抽屉。改动中等。

C

混合：轻量启动 + 图内全操作

首次只选"时间列 + 数值列"这一步轻量启动，其余全部确认与修改（变换/时间语义/切分/阶数/分布/对比）都在图内节点上做。介于 A、B 之间。
