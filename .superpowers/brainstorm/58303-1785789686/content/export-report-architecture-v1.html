两种入口组织方式

A

按上下文放置（推荐）

Run 只负责报告导出；Report 页负责当前报告导出；数据节点负责清洗/变换数据导出。用户在当前任务旁边找到动作。

B

统一 Export Center

所有 PDF、XLSX、CSV 都集中到一个全局导出中心。入口统一，但用户需要先理解“导出对象”与当前页面的关系。

推荐方案的好处

  • 不会再默认生成无用 XLSX
  • 报告与数据的责任边界清楚
  • 导出动作跟当前 artifact / node 绑定

需要补齐的规则

  • 报告要有期刊式结构和最低覆盖要求
  • PDF/Word/HTML 要共享同一份报告内容
  • 导出菜单要显示格式与用途
