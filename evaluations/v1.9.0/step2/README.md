# v1.9.0 第 2 步验收：外壳骨架与布局切换

日期 2026-10-08。对应 objective 第 2 步。新外壳在功能开关后面，默认仍是经典外壳。

## 交付

- 开关：设置 › Appearance › Workspace（New workspace / Classic），或任意项目地址加 `?workspace=new|classic`（会被记住）。
  Appearance 同时放主题（浅色 / 深色 / 跟随系统），新外壳的顶栏不再放主题开关。
- `frontend/src/workspace/`：
  - `WorkspaceShell`：顶栏、地图、舞台、Agent、下方面板五个区域；地图列宽是注册过的 CSS 自定义属性，
    沿弹簧曲线（临界阻尼，350 ms）过渡，可中途反向；分隔线可拖动，松手按动量投影吸附到较近的布局，
    也可双击或用方向键切换；⌘\ 切换布局，⌘. 收起 / 展开 Agent（收起后 Agent 不卸载，对话保留）；
    每个项目记住上次布局；Data、Tables、Report、Plans 在谱系主导下临时使用宽舞台，回到 Analysis 时恢复。
  - `WorkspaceTopbar`：地图显隐（仅结果主导）、Arboris（回项目首页）、项目切换、
    视图 Data · Analysis · Tables · Report · Plans（工作顺序）、布局开关、搜索（⌘K）、New analysis、Rerun、设置。
  - `WorkspaceBottomPanel`：Runs · Logs · Activity；默认收成一行，选标签即展开，可拖高，按项目在会话内记住。
    Runs 由原运行记录栏改为表格：运行、开始时间、内容（因变量与自变量）、状态、Show on map、View all runs。
  - `StageHost`：Analysis 视图的舞台 = 原右侧面板的标签栏 + 当前打开的节点详情或报告审阅；没有打开时提示下一步。
- 经典外壳的状态（标签、浮动面板、焦点）仍由 `WorkbenchShell` 持有，新外壳只是换位置放置同一批部件；
  `WorkbenchRouteContainer.tsx` 2101 → 2098 行（运行记录开关移入 `RunHistoryToggle.tsx`，浮动层只定义一次）。
- 顶栏动作（Rerun）的计算抽成 `useTopbarActions`，新旧顶栏共用。
