## Objective
# Workbench v1.8.9 P0 Legacy Route and Resume Hardening Objective

Remove the remaining executable authority bypasses and make resume trust the
server-owned completion/admission/artifact bindings rather than only persisted
plan fingerprints.

Required outcomes:

- historical executable Notebook confirmation paths use the same server
  AgentNotebookCompilerV1 compile/confirm/execute boundary as the new cutover;
- historical executable Agent proposal confirmation paths cannot call the old
  orchestrator directly without a server compilation record and confirmation;
- resume revalidates persisted artifact IDs, output bindings and lineage
  against the server completion/admission registry before any dependent
  callback or new artifact write;
- persisted model branches are equal to the current compiled model step's
  outcome, predictors, covariance and family declaration, not merely the same
  artifact identity;
- mismatches fail closed with typed errors and do not execute user code or
  write new artifacts.

This line owns legacy Agent/Notebook route adapters and workflow resume/branch
validation plus focused regression tests. It does not modify Report consumer
code, model estimators, provider implementations, browser fixtures, or
release sidecars. Historical response-shape compatibility must remain
explicitly separated from the security/correctness gate.
