- A verified document hash does not establish internal or executed-input coherence; validate family-defined primary projections and typed identities.
- Better likelihood or lower score is not permission to rewrite a frozen comparison, change tolerance, or choose a poorer optimum to match reported parameters.
- Bind actual artifacts to their frozen public owner, and distinguish backend numeric acceptance from newly changed frontend state acceptance.
- Bind each consumer to completed owner artifacts and retain partial/unavailable warnings.
- Bind every completed document role and preserve typed labels and limitations; declared primary-only packets must not fabricate complete coefficient rows.
- Bind every kernel parameter and original model request; use the same directory-FD transaction lock for every existing owner index writer.
- Bind exports to consumed owner records and preserve existing CSV byte compatibility.

- Bind subsequent inference to published run and kernel identities, and test server-owned user-visible summaries separately from provider proposal content.

- Certify each frozen implementation and its actual public exports independently; old passing reports do not certify subsequent edits.
- Certify natural ancillary score and information before reporting ML inference; do not equate successful optimizer status with a validated estimate.
- Check actual theme rendering even when frontend files are unchanged; record inherited failures separately from the feature result.

- Derive editors from the execution contract and bind final numerical quantities to their actual owner. Reuse one preview and only retry affected failures.
- Discover available model IDs from the provider without guessing a default or mutating configuration before user save.
- Equal row labels and schema validity cannot prove the owner or statistical response; verify executed indexed artifacts and transport explicit unavailability reasons across all consumers.
- Equivalent cohort normalization requires matching the source parser lexical domain, not merely testing ordinary decimal strings.
- Exercise the same selected-model context as the browser and keep one runtime answer declaration; correct concrete harness defects without widening numeric tolerances.
- Fix stale consumer assumptions against independently certified final-point reference without loosening tolerances or mutating original review evidence.
